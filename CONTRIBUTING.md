# Contributing to mur-voir

mur-voir is maintained by Melbourne University Motorsport. See [DEVELOPING.md](DEVELOPING.md) for setup, build and run instructions.

- Open an issue on [GitHub](https://github.com/Melbourne-University-Motorsports/mur-voir/issues) before starting large changes.
- Run `npx prettier --check` on changed files before committing. New files get the MUR licence header; files inherited from AdvantageScope keep their original header.
- Avoid renaming internal identifiers inherited from AdvantageScope unless needed, so upstream fixes stay easy to merge.
- By contributing, you agree that your code is distributed under the project's BSD licence ([LICENSE](LICENSE)).
