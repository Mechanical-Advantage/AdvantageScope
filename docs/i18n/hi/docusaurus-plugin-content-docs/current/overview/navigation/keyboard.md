# कीबोर्ड शॉर्टकट {#keyboard-shortcuts}

AdvantageScope में कई कीबोर्ड शॉर्टकट शामिल हैं जो तेज़ नेविगेशन की अनुमति देते हैं। `ctrl` कुंजी का उपयोग करने वाले शॉर्टकट macOS पर ⌘ कुंजी द्वारा प्रतिस्थापित किए जाते हैं।

### डेटा स्रोत {#data-sources}

<table>
<tr><td>`Ctrl+O`</td><td>एक या अधिक लॉग फ़ाइलें खोलें</td></tr>
<tr><td>`Ctrl+Shift+O`</td><td>वर्तमान विज़ुअलाइज़ेशन में एक या अधिक लॉग फ़ाइलें जोड़ें</td></tr>
<tr><td>`Ctrl+K`</td><td>रोबोट से एक लाइव स्रोत के रूप में कनेक्ट करें</td></tr>
<tr><td>`Ctrl+Shift+K`</td><td>सिम्युलेटर से एक लाइव स्रोत के रूप में कनेक्ट करें</td></tr>
<tr><td>`Ctrl+Option+Shift+K`</td><td>ड्राइवर स्टेशन से एक लाइव स्रोत के रूप में कनेक्ट करें</td></tr>
<tr><td>`Ctrl+D`</td><td>रोबोट से लॉग फ़ाइलें डाउनलोड करें</td></tr>
</table>

### डेटा एक्सपोर्ट {#data-export}

<table>
<tr><td>`Ctrl+E`</td><td>लॉग डेटा एक्सपोर्ट करें</td></tr>
<tr><td>`Ctrl+P`</td><td>रोबोट पर NetworkTables सर्वर पर लॉग डेटा पब्लिश करें</td></tr>
<tr><td>`Ctrl+Shift+P`</td><td>सिमुलेशन में NetworkTables सर्वर पर लॉग डेटा पब्लिश करें</td></tr>
<tr><td>`Option+Ctrl+P`</td><td>NetworkTables पर पब्लिशिंग बंद करें</td></tr>
</table>
