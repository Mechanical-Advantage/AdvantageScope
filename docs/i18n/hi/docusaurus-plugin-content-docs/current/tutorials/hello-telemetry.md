# 👋 हैलो, टेलीमेट्री!

AdvantageScope में आपका स्वागत है! टेलीमेट्री और डेटा लॉगिंग शक्तिशाली क्षमताएँ हैं जो रोबोट कोड को समझने, समस्याओं का निदान करने और फ़ील्ड पर तथा फ़ील्ड के बाहर समाधान लागू करने की आपकी क्षमता को बेहतर बना सकती हैं। ये ट्यूटोरियल आपको टेलीमेट्री के साथ शुरुआत करने में मदद करने के लिए डिज़ाइन किए गए हैं ताकि आप AdvantageScope की पूरी क्षमताओं का लाभ उठा सकें।

इस ट्यूटोरियल में, आप सीखेंगे कि कैसे:

- Java WPILib प्रोजेक्ट में बुनियादी रोबोट टेलीमेट्री सेट अप करें।
- AdvantageScope में लाइव डेटा स्ट्रीम से कनेक्ट करें।
- बाद में उपयोग के लिए लॉग फ़ाइलों में डेटा रिकॉर्ड करें।
- AdvantageScope का उपयोग करके टेलीमेट्री डेटा को विज़ुअलाइज़ करें।

:::tip कुछ और खोज रहे हैं?

- **FTC टीमें:** यदि आप मौजूदा FIRST Tech Challenge कंट्रोल सिस्टम का उपयोग कर रहे हैं, तो ✴️ [FTC संगतता](/more-features/ftc-compatibility) गाइड देखें।
- **वेब इंटरफ़ेस:** AdvantageScope का ब्राउज़र-आधारित संस्करण सीधे FIRST ड्राइवर स्टेशन और Systemcore वेब इंटरफ़ेस के अंदर उपलब्ध है। विवरण के लिए 💡 [AdvantageScope लाइट](/more-features/advantagescope-lite) देखें।
- **AdvantageKit:** सिमुलेशन में नियतात्मक (deterministic) रीप्ले के लिए डिज़ाइन किया गया एक उन्नत लॉगिंग फ्रेमवर्क। विवरण के लिए [डॉक्यूमेंटेशन](https://docs.advantagekit.org) देखें। हम WPILib के बिल्ट-इन टेलीमेट्री API से शुरुआत करने की अनुशंसा करते हैं, जिसका वर्णन नीचे किया गया है।
  :::

## 1. नया WPILib प्रोजेक्ट बनाएँ

शुरू करने के लिए, VS Code में एक नया WPILib Java प्रोजेक्ट बनाएँ:

1. VS Code खोलें।
2. ऊपर दाईं ओर WPILib आइकन पर क्लिक करें (या `Ctrl+Shift+P` / `Cmd+Shift+P` दबाएँ और **WPILib: Create a new project** टाइप करें)।
3. **Template** > **Java** > **Command v3 Robot** (या **Command v2 Robot**) चुनें।
4. एक फ़ोल्डर चुनें, अपने प्रोजेक्ट को नाम दें (जैसे `HelloTelemetry`), और अपना टीम नंबर दर्ज करें।
5. **Enable Desktop Support** पर टिक करें और **Create Project** पर क्लिक करें।

<img src="/img/tutorials/hello-telemetry-1.webp" alt="WPILib प्रोजेक्ट क्रिएटर का उपयोग करके VS Code में एक नया WPILib Java प्रोजेक्ट बनाना।" />

_ऊपर अंग्रेजी इंटरफ़ेस दिखाया गया है।_

## 2. डेटा लॉगिंग इनिशियलाइज़ करें

WPILib `DataLogManager` के माध्यम से बिल्ट-इन डेटा लॉगिंग प्रदान करता है। शुरू होने पर, यह स्वचालित रूप से सभी टेलीमेट्री, NetworkTables प्रविष्टियों और ड्राइवर स्टेशन इनपुट को `.wpilog` फ़ाइलों में रिकॉर्ड करता है।

:::info अनुशंसा
यद्यपि लॉग्स को Systemcore के आंतरिक स्टोरेज में सहेजा जा सकता है, आंतरिक फ्लैश मेमोरी सीमित होती है। हम Systemcore के किसी USB पोर्ट में एक मानक **FAT32 फ़ॉर्मेटेड USB फ्लैश ड्राइव** लगाने की दृढ़ता से अनुशंसा करते हैं। `DataLogManager` ड्राइव का पता लगा लेगा और सभी लॉग्स को सीधे USB ड्राइव पर लिखेगा।
:::

`src/main/java/first/robot/Robot.java` खोलें और `Robot()` कंस्ट्रक्टर के अंदर `DataLogManager` को इनिशियलाइज़ करें:

```java
public class Robot extends OpModeRobot {
  // ...

  public Robot() {
    // USB स्टिक पर .wpilog फ़ाइल में सभी टेलीमेट्री रिकॉर्ड करने के लिए DataLogManager शुरू करें
    DataLogManager.start();

    // ड्राइवर स्टेशन डेटा भी रिकॉर्ड करें (जॉयस्टिक, OpMode, इनेबल स्टेट)
    DriverStation.startDataLog(DataLogManager.getLog());
  }

  // ...
}
```

## 3. टेलीमेट्री डेटा पब्लिश करें

WPILib की `Telemetry` क्लास आपको कोड की एक ही पंक्ति से डेटा पब्लिश करने की सुविधा देती है, और फ़ील्ड्स को पदानुक्रमित टेबल्स में व्यवस्थित करती है। यह API संख्यात्मक मान, बूलियन, स्ट्रिंग, एरे और WPILib [ज्योमेट्री प्रकारों](https://docs.wpilib.org/en/stable/docs/software/advanced-controls/geometry/index.html) सहित विभिन्न डेटा प्रकारों का समर्थन करता है।

:::info
WPILib में `Telemetry` क्लास FTC SDK में `Telemetry` क्लास से अलग है। WPILib की `Telemetry` क्लास रोबोट प्रोग्राम से डैशबोर्ड, डिबग टूल्स या लॉग फ़ाइलों में जानकारी भेजती है। बिल्ट-इन ड्राइवर स्टेशन डिस्प्ले को अपडेट करने के लिए WPILib की `DriverStationDisplay` क्लास का उपयोग करें।
:::

`src/main/java/first/robot/ExampleTeleop.java` को अपडेट करें:

```java
@Teleop
public class ExampleTeleop implements OpMode {
  // ...

  @Override
  public void periodic() {
    double currentTime = Timer.getTimestamp();
    double sineWave = Math.sin(currentTime * 2.0);

    // Telemetry API का उपयोग करके टेलीमेट्री मान पब्लिश करें
    Telemetry.log("Time", currentTime);
    Telemetry.log("SineWave/Value", sineWave);
    Telemetry.log("SineWave/Low", sineWave < 0.5);
  }
}
```

अपने रोबोट पर कोड डिप्लॉय करें (या VS Code से `WPILib: Simulate Robot Code` चलाएँ)। सिमुलेशन में, `Teleoperated` > `ExampleTeleop` > `Enable` पर क्लिक करें।

<img src="/img/tutorials/hello-telemetry-2.webp" alt="सिम्युलेटर GUI में ExampleTeleop OpMode को इनेबल करना।" height="200" />

_ऊपर अंग्रेजी इंटरफ़ेस दिखाया गया है।_

:::tip
नया टेलीमेट्री डेटा केवल तभी पब्लिश होता है जब `Telemetry.log` को कॉल किया जाता है। `Robot` क्लास, OpModes, सबसिस्टम्स और मैकेनिज्म में आवधिक (periodic) मेथड्स अलग-अलग स्थितियों में सक्रिय हो सकते हैं; लॉगिंग कॉल कहाँ रखनी है इस पर विचार करते समय API डॉक्यूमेंटेशन को ध्यान से देखें।
:::

## 4. AdvantageScope को लाइव कनेक्ट करें

AdvantageScope डेस्कटॉप एप्लिकेशन लॉन्च करें। शीर्ष मेनू में, `फ़ाइल` > `रोबोट से कनेक्ट करें` > `NetworkTables` चुनें (या यदि सिम्युलेट कर रहे हैं तो `फ़ाइल` > `सिम्युलेटर से कनेक्ट करें`)। कनेक्ट होने के बाद, बायाँ साइडबार `NT:/Telemetry` के अंतर्गत पब्लिश किए गए फ़ील्ड्स से भर जाएगा।

:::tip कीबोर्ड शॉर्टकट्स
रोबोट से तुरंत कनेक्ट करने के लिए `Ctrl+K` / `Cmd+K` दबाएँ, या सिम्युलेटर से कनेक्ट करने के लिए `Ctrl+Shift+K` / `Cmd+Shift+K` दबाएँ।
:::

<img src="/img/tutorials/hello-telemetry-3.webp" alt="साइडबार ट्री में सूचीबद्ध फ़ील्ड्स के साथ लाइव रोबोट स्ट्रीम से जुड़ा AdvantageScope।" />

_ऊपर अंग्रेजी इंटरफ़ेस दिखाया गया है।_

## 5. टेलीमेट्री डेटा विज़ुअलाइज़ करें

### लाइन ग्राफ

📉 [लाइन ग्राफ](/tab-reference/line-graph) AdvantageScope में डिफ़ॉल्ट टैब है और संख्यात्मक तथा डिस्क्रीट मानों की रीयल-टाइम प्लॉटिंग प्रदान करता है।

1. `Telemetry` > `SineWave` के अंतर्गत बाएँ साइडबार में देखें।
2. `Value` को कंट्रोल पेन के "लेफ्ट एक्सिस" क्षेत्र में ड्रैग करें।
3. `Low` को कंट्रोल पेन के "डिस्क्रीट फ़ील्ड्स" क्षेत्र में ड्रैग करें।
4. "डिस्क्रीट फ़ील्ड्स" के बगल में तीन बिंदुओं पर क्लिक करें और फिर "रोबोट मोड दिखाएँ" चुनें।

जैसे ही डेटा स्ट्रीम होगा, आप साइन वेव और रोबोट की स्थिति को रीयल-टाइम में अपडेट होते देखेंगे!

:::info ग्राफ के साथ इंटरैक्ट करना

- **पॉज़ / स्क्रब:** पिछला डेटा देखने के लिए क्षैतिज रूप से स्क्रॉल करें या ग्राफ पर क्लिक करके ड्रैग करें। ऊपर-दाईं ओर लाल तीर इंगित करता है कि लाइव ऑटोस्क्रॉल रुका हुआ है। लाइव ऑटोस्क्रॉल टॉगल करने के लिए तीर पर क्लिक करें या `L` दबाएँ।
- **ज़ूम:** ग्राफ के ऊपर ऊपर/नीचे स्क्रॉल करें, या किसी विशिष्ट समय विंडो में ज़ूम करने के लिए ड्रैग करते समय `Shift` दबाए रखें।
- **मान जाँचें:** समय कर्सर रखने और लेजेंड में सटीक मान देखने के लिए ग्राफ पर कहीं भी क्लिक करें।
  :::

<img src="/img/tutorials/hello-telemetry-4.webp" alt="साइन वेव सिग्नल प्लॉट करता हुआ लाइन ग्राफ।" />

_ऊपर अंग्रेजी इंटरफ़ेस दिखाया गया है।_

### टेबल

🔢 [टेबल](/tab-reference/table) टैब स्थिति और मान परिवर्तनों की एक कालानुक्रमिक स्प्रेडशीट प्रदर्शित करता है, जो ट्रांज़िशन और इवेंट अनुक्रमों का निदान करने के लिए एकदम सही है।

1. शीर्ष टैब बार में **+** बटन पर क्लिक करें और **टेबल** चुनें।
2. साइडबार से, `NT:/Telemetry/SineWave/Value` और `NT:/Telemetry/Low` को टेबल व्यू में ड्रैग करें।
3. जब भी किसी प्रदर्शित फ़ील्ड का मान बदलता है तो स्वचालित रूप से एक नई रो जुड़ जाती है।
4. सभी खुले टैब्स को तुरंत उस सटीक समय पर ले जाने के लिए किसी भी रो पर क्लिक करें!

:::tip
टैब बार का उपयोग करके टैब्स को पुनर्व्यवस्थित और नाम बदला जा सकता है। पॉप-आउट विंडो में टैब खोलने और एक साथ कई टैब्स देखने के लिए टाइटल बार में विंडो बटन पर क्लिक करें।
:::

<img src="/img/tutorials/hello-telemetry-5.webp" alt="साइन वेव डेटा प्रदर्शित करता हुआ टेबल टैब।" />

_ऊपर अंग्रेजी इंटरफ़ेस दिखाया गया है।_

### आंकड़े

📊 [आंकड़े](/tab-reference/statistics) टैब संख्यात्मक मानों का हिस्टोग्राम प्रदर्शित करता है, जो एक या अधिक फ़ील्ड्स के डेटा पर विस्तृत नज़र डालता है।

1. शीर्ष टैब बार में **+** बटन पर क्लिक करें और **आंकड़े** चुनें।
2. साइडबार से, `NT:/Telemetry/SineWave/Value` को "माप" सेक्शन में ड्रैग करें।
3. "डेटा सीमा" को `-1` और `1` पर सेट करें, और "स्टेप साइज़" को `0.1` पर सेट करें।
4. हिस्टोग्राम और सारांश आंकड़ों का उपयोग करके डेटा देखें।
5. शामिल करने के लिए डेटा की रेंज समायोजित करने हेतु शीर्ष पर टाइमलाइन स्क्रॉल करें।

<img src="/img/tutorials/hello-telemetry-6.webp" alt="साइन वेव डेटा प्रदर्शित करता हुआ आंकड़े टैब।" />

_ऊपर अंग्रेजी इंटरफ़ेस दिखाया गया है।_

## 6. लॉग फ़ाइलें डाउनलोड करें और खोलें

परीक्षण या मैच चलाने के बाद, आप बाद में डेटा की समीक्षा करने के लिए रोबोट से `.wpilog` फ़ाइलें डाउनलोड कर सकते हैं:

1. मेनू बार में, `फ़ाइल` > `लॉग्स डाउनलोड करें...` चुनें।
2. AdvantageScope रोबोट से कनेक्ट होता है और सभी रिकॉर्ड की गई लॉग फ़ाइलों को सूचीबद्ध करता है (सबसे नई सबसे ऊपर)।
3. वे लॉग फ़ाइलें चुनें जिनका आप निरीक्षण करना चाहते हैं, डाउनलोड (↓) आइकन पर क्लिक करें, और अपने कंप्यूटर पर एक फ़ोल्डर चुनें।
4. `फ़ाइल` > `लॉग खोलें...` का उपयोग करके या `.wpilog` फ़ाइल को सीधे AdvantageScope में ड्रैग करके डाउनलोड की गई फ़ाइल खोलें।

<img src="/img/overview/log-files/open-file-2.webp" alt="रोबोट स्टोरेज पर उपलब्ध WPILOG फ़ाइलें दिखाता हुआ डाउनलोड डायलॉग।" height="350" />

_ऊपर अंग्रेजी इंटरफ़ेस दिखाया गया है।_

## आगे क्या?

अब जब आपने बुनियादी टेलीमेट्री और लॉगिंग चला ली है, तो अपने विज़ुअलाइज़ेशन को अगले स्तर पर ले जाएँ:

- **🤖 [फील्ड पर चलें: रोबोट विज़ुअलाइज़ेशन](/tutorials/to-the-field):** FRC और FTC फ़ील्ड मॉडल्स पर 2D/3D रोबोट पोज़िशन, ट्रैजेक्टरी और मैकेनिज्म को विज़ुअलाइज़ करना सीखें।
- **[अवलोकन](/category/overview):** फ़ाइलों को प्रबंधित करने, नेविगेशन शॉर्टकट्स और लाइव स्ट्रीमिंग विकल्पों पर एक व्यापक गाइड।
