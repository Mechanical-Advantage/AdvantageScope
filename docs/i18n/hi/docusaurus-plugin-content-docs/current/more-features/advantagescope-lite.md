# 💡 AdvantageScope लाइट {#advantagescope-lite}

AdvantageScope लाइट, AdvantageScope का एक ब्राउज़र-आधारित संस्करण है जिसे FIRST ड्राइवर स्टेशन और Systemcore वेब इंटरफ़ेस से एक्सेस किया जा सकता है। AdvantageScope डेस्कटॉप ऐप के ज़्यादातर बुनियादी फ़ीचर्स AdvantageScope लाइट में शामिल हैं। हालाँकि, कम्पैटिबिलिटी सीमाओं (जैसे कुछ टैब प्रकार, लॉगिंग फ़ॉर्मेट और उनसे जुड़े फ़ीचर्स) के कारण कुछ फ़ीचर्स इसमें नहीं दिए गए हैं।

## इंस्टॉलेशन और एसेट्स {#installation-and-assets}

Systemcore के लिए AdvantageScope लाइट को इंस्टॉल और अपडेट करने के लिए GitHub रिलीज़ पेज से AdvantageScope का "Systemcore" संस्करण डाउनलोड करें। इसके बाद रोबोट पर पैकेज अपलोड करने के लिए Systemcore वेब इंटरफ़ेस पर "Add Package" कार्ड चुनें।

एसेट फ़ाइलें (जैसे फील्ड या रोबोट मॉडल) अपलोड करने के लिए `फ़ाइल` > `एसेट अपलोड करें` चुनें। आप चाहें तो किसी एक एसेट की ज़िप फ़ाइल चुन सकते हैं, या ऐसी ज़िप फ़ाइल भी चुन सकते हैं जिसमें कई एसेट ज़िप फ़ाइलें हों। एसेट फ़ॉर्मेट के बारे में अधिक जानकारी के लिए [कस्टम एसेट्स](/more-features/custom-assets/) पेज देखें।

:::info
सामान्य एसेट्स के संग्रह वाली ज़िप फ़ाइलें नीचे दिए गए लिंक पर क्लिक करके डाउनलोड की जा सकती हैं:

- [**डिफ़ॉल्ट FRC एसेट्स**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFRC.zip): FRC फील्ड्स, FRC उदाहरण रोबोट, और सभी जॉयस्टिक लेआउट।
- [**डिफ़ॉल्ट FTC एसेट्स**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFTC.zip): FTC फील्ड्स, FTC उदाहरण रोबोट, और सभी जॉयस्टिक लेआउट।
- [**FRC 6328 एसेट्स**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsFRC6328.zip): केवल AdvantageScope के [Team 6328 डिस्ट्रीब्यूशन](/overview/installation#team-6328) के लिए विशेष एसेट्स।

:::

:::tip
FIRST ड्राइवर स्टेशन में AdvantageScope लाइट का उपयोग करने के लिए किसी इंस्टॉलेशन की ज़रूरत नहीं है। लाइव कनेक्ट करने या लॉग फ़ाइलें देखने के लिए http://localhost:6768/ascope पर जाएँ। आप बाहरी ड्राइवर स्टेशन लॉग फ़ाइलों को विंडो पर ड्रैग और ड्रॉप करके भी खोल सकते हैं।
:::
