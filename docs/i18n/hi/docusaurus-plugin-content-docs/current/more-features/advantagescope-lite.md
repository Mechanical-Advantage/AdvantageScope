# 💡 AdvantageScope लाइट {#advantagescope-lite}

AdvantageScope लाइट FIRST ड्राइवर स्टेशन और Systemcore वेब इंटरफ़ेस से सुलभ AdvantageScope का एक ब्राउज़र-आधारित संस्करण है। AdvantageScope डेस्कटॉप ऐप के अधिकांश बुनियादी फीचर्स AdvantageScope लाइट में शामिल हैं। हालाँकि, संगतता प्रतिबंधों (कुछ टैब प्रकारों, लॉगिंग स्वरूपों और संबंधित सुविधाओं सहित) के कारण कई फीचर्स छोड़ दिए गए हैं।

## स्थापना और एसेट्स {#installation-and-assets}

Systemcore के लिए AdvantageScope लाइट को GitHub रिलीज़ पेज से AdvantageScope का "Systemcore" संस्करण डाउनलोड करके स्थापित और अपडेट किया जा सकता है। रोबोट पर पैकेज अपलोड करने के लिए Systemcore वेब इंटरफ़ेस पर "Add Package" कार्ड चुनें।

एसेट फ़ाइलें (उदा. फील्ड/रोबोट मॉडल) `फ़ाइल` > `एसेट अपलोड करें` चुनकर अपलोड की जा सकती हैं। चयनित फ़ाइल या तो किसी व्यक्तिगत एसेट के लिए एक ज़िप फ़ाइल हो सकती है, या एकाधिक एसेट ज़िप फ़ाइलों वाली एक ज़िप फ़ाइल हो सकती है। एसेट स्वरूपों के बारे में अधिक जानकारी के लिए [कस्टम एसेट्स](/more-features/custom-assets/) पृष्ठ देखें।

:::info
सामान्य एसेट्स के संग्रह वाली ज़िप फ़ाइलें नीचे दिए गए लिंक पर क्लिक करके डाउनलोड की जा सकती हैं:

- [**डिफ़ॉल्ट FRC एसेट्स**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFRC.zip): FRC फील्ड्स, FRC उदाहरण रोबोट, और सभी जॉयस्टिक लेआउट।
- [**डिफ़ॉल्ट FTC एसेट्स**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFTC.zip): FTC फील्ड्स, FTC उदाहरण रोबोट, और सभी जॉयस्टिक लेआउट।
- [**FRC 6328 एसेट्स**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsFRC6328.zip): AdvantageScope के [Team 6328 वितरण](/overview/installation#team-6328) के लिए विशेष एसेट्स।

:::

:::tip
FIRST ड्राइवर स्टेशन में AdvantageScope लाइट का उपयोग करने के लिए किसी इंस्टॉलेशन की आवश्यकता नहीं है। लाइव कनेक्ट करने या लॉग फ़ाइलें देखने के लिए http://localhost:6768/ascope पर जाएँ।
:::
