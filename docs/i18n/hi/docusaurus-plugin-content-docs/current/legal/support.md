# सहायता {#support}

AdvantageScope या AdvantageScope XR के लिए सहायता प्राप्त करने के लिए, कृपया नीचे दिए गए संपर्क तरीकों में से किसी एक का उपयोग करें।

- फीचर अनुरोधों और बग रिपोर्ट के लिए, GitHub पर [समस्या खोलें (issue open करें)](https://github.com/Mechanical-Advantage/AdvantageScope/issues)।
- अन्य सभी पूछताछ के लिए, software@team6328.org पर संपर्क करें।
