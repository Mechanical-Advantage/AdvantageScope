# सहायता {#support}

AdvantageScope या AdvantageScope XR के लिए सहायता पाने के लिए, कृपया नीचे दिए गए संपर्क माध्यमों में से किसी एक का उपयोग करें।

- फीचर अनुरोधों और बग रिपोर्ट के लिए, GitHub पर [issue खोलें](https://github.com/Mechanical-Advantage/AdvantageScope/issues)।
- अन्य सभी पूछताछ के लिए, software@team6328.org पर संपर्क करें।
