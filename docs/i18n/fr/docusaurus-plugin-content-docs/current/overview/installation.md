# 📦 Installation {#installation}

La version officielle d'AdvantageScope est disponible directement auprès de l'équipe 6328 ou via l'installateur WPILib. Plusieurs distributions non officielles existent également.

## Équipe 6328 {#team-6328}

### Téléchargements : [Version stable](https://github.com/Mechanical-Advantage/AdvantageScope/releases/latest), [Préversion](https://github.com/Mechanical-Advantage/AdvantageScope/releases) {#6328-downloads}

Télécharger AdvantageScope directement auprès de l'équipe 6328 vous permet de bénéficier des avantages suivants :

- Les toutes dernières fonctionnalités et corrections de bogues avant leur arrivée sur les autres canaux.
- Des alertes directement dans l'application dès qu'une mise à jour est disponible.
- Une collection intégrée de modèles de robots récents de l'équipe 6328 pour l'onglet 👀 [Terrain 3D](/tab-reference/3d-field).

:::info
Chaque version majeure d'AdvantageScope sort en janvier avant le coup d'envoi de la saison FRC, avec un numéro de version correspondant à l'année (par exemple, la v26.0.0 en janvier 2026). Des versions alpha et bêta sont parfois publiées dans les mois qui précèdent pour les équipes qui souhaitent tester les nouveautés et nous faire part de leurs retours. **Si vous utilisez ces préversions, attendez-vous à rencontrer des bogues et des problèmes absents des versions stables.**
:::

## WPILib {#wpilib}

### Installation : [Documentation WPILib](https://docs.wpilib.org/fr/stable/docs/zero-to-robot/step-2/wpilib-setup.html) {#wpilib-installation}

L'installateur WPILib inclut une version récente d'AdvantageScope, mais elle peut accuser un léger retard par rapport à la dernière version disponible en téléchargement direct. Vous trouverez [ici](https://docs.wpilib.org/fr/stable/docs/software/dashboards/advantagescope.html) la documentation pour lancer AdvantageScope depuis la version WPILib de VS Code.

## Distributions non officielles {#unofficial-distributions}

Plusieurs distributions non officielles d'AdvantageScope sont proposées par des tiers. Elles ne sont pas prises en charge par les développeurs d'AdvantageScope ni par WPILib, et peuvent avoir du retard par rapport aux versions officielles. En cas de problème, contactez directement leurs responsables.

- [**AdvantageScope Lite pour le système de contrôle REV :**](https://github.com/j5155/AdvantageScope-Lite-FTC) une version adaptée d'[AdvantageScope Lite](/more-features/advantagescope-lite) pour le système de contrôle FTC actuel (avant Systemcore).
- [**Installateur Homebrew :**](https://formulae.brew.sh/cask/advantagescope) un _cask_ Homebrew pour installer AdvantageScope en ligne de commande sur macOS.
- [**Arch User Repository :**](https://aur.archlinux.org/packages/advantagescope) une méthode d'installation alternative pour le gestionnaire de paquets pacman (une distribution Arch officielle est disponible [ici](#6328-downloads)).
