# Assistance {#support}

Pour obtenir de l'aide sur AdvantageScope ou AdvantageScope XR, utilisez l'un des moyens ci-dessous.

- Pour proposer une fonctionnalité ou signaler un bogue, [ouvrez un ticket (*issue*)](https://github.com/Mechanical-Advantage/AdvantageScope/issues) sur GitHub.
- Pour toute autre question, écrivez à software@team6328.org.
