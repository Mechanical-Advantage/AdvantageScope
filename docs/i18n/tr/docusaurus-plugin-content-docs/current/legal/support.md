# Destek

AdvantageScope veya AdvantageScope XR için destek almak üzere lütfen aşağıdaki iletişim yöntemlerinden birini kullanın.

- Özellik istekleri ve hata raporları için GitHub'da [bir sorun açın](https://github.com/Mechanical-Advantage/AdvantageScope/issues).
- Diğer tüm sorular için software@team6328.org adresi ile iletişime geçin.
