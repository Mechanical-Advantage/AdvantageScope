# Destek {#support}

AdvantageScope veya AdvantageScope XR hakkında destek almak için lütfen aşağıdaki iletişim yöntemlerinden birini kullanın.

- Özellik istekleri ve hata raporları için GitHub'da [bir sorun açın](https://github.com/Mechanical-Advantage/AdvantageScope/issues).
- Diğer tüm sorular için software@team6328.org adresiyle iletişime geçin.
