# ⏱️ חותמות זמן {#timestamps}

AdvantageScope מאפשרת להתאים אישית את אופן התצוגה של חותמות הזמן בכל המסכים, כולל ציר הזמן, 📉 [גרף קווי](/tab-reference/line-graph), 🔢 [טבלה](/tab-reference/table) ו-💬 [מסוף](/tab-reference/console).

## מצבי תצוגה {#display-modes}

בחלון ההעדפות אפשר לבחור בין שני מצבי תצוגה עבור חותמות הזמן:

- **התחלה מאפס (ברירת מחדל):** מזיז את כל חותמות הזמן כך שהנתון המוקדם ביותר ביומן יתחיל מאפס (`+0.0s`). במצב זה מופיע הסימן `+` לפני כל חותמת זמן, כדי להראות כמה זמן חלף מתחילת ההקלטה.
- **מקורי:** מציג את חותמות הזמן בערכים המספריים המקוריים שלהן כפי שנשמרו בקובץ היומן, בדיוק כפי שמופיע בקוד הרובוט.

:::info
החל מ-WPILib 2027, חותמות הזמן ב-Systemcore ובסימולציה נמדדות לפי הזמן שחלף מאז אתחול המכשיר (boot). מכיוון שחותמות הזמן הגולמיות עשויות להתחיל ממספרים גדולים ואקראיים למראה, המצב **התחלה מאפס** מציע תצוגה נוחה ואינטואיטיבית יותר.
:::

## סנכרון מספר יומנים {#multi-log-synchronization}

כאשר [פותחים כמה קובצי יומן במקביל](/overview/log-files/#opening-logs), AdvantageScope מסנכרנת ומיישרת את חותמות הזמן שלהם זו לזו. במצב **התחלה מאפס**, נקודת האפס נקבעת לפי חותמת הזמן המוקדמת ביותר מבין כל הקבצים שנטענו. במצב **מקורי**, חותמות הזמן מוצגות לפי בסיס הזמן של היומן הראשון שנפתח, ושאר היומנים מוזזים בהתאם כדי להתיישר איתו.

## התאמה אישית {#customization}

כדי לשנות את מצב תצוגת חותמות הזמן, פתחו את חלון ההעדפות דרך `אפליקציה` > `הצגת העדפות...` (ב-Windows/Linux) או `AdvantageScope` > `הגדרות...` (ב-macOS), או באמצעות קיצור המקלדת `Ctrl+,` / `Cmd+,`. שנו את ההגדרה **חותמות זמן** לאפשרות הרצויה.
