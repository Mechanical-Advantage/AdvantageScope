# 🔢 טבלה {#table}

תצוגת הטבלה מיועדת להציג בפירוט את שינויי הערכים של קבוצת שדות. כדי להוסיף שדה, גוררים אותו לתצוגה הראשית. כדי למחוק שדה, לוחצים על כפתור ה-"X" שליד השם שלו. אפשר לשנות את סדר השדות על ידי גרירה.

<img src="/img/tab-reference/table-1.webp" alt="סקירה כללית" />

_ממשק באנגלית מוצג למעלה._

**בכל פעם שאחד מהשדות המוצגים משתנה, נוצרת שורה חדשה בטבלה.** שורות כפולות לא מוצגות. לדוגמה, טבלה שמציגה את מצב הרובוט במהלך משחק תיראה כך:

<img src="/img/tab-reference/table-2.webp" alt="טבלת מצב הרובוט" />

הזמן שנבחר בטבלה מסונכרן בין כל הכרטיסיות. לוחצים על שורה כדי לבחור אותה, או מרחפים מעל שורה כדי לראות תצוגה מקדימה שלה בכל החלונות הקופצים הפתוחים. לחיצה על כפתור ה-↓ קופצת לזמן שנבחר (או לזמן שהקלדתם בתיבה). חותמות הזמן ושדות הקלט לקפיצה מעוצבים לפי ההעדפה [חותמות זמן](/more-features/timestamps).
