# 🎬 וידאו {#video}

כרטיסיית הווידאו מאפשרת להשוות את נתוני היומן לצד סרטון משחק שצולם בנפרד. השלבים למטה מראים איך לטעון סרטון ולסנכרן אותו עם היומן.

## טעינת הווידאו {#loading-the-video}

AdvantageScope מציעה שלוש דרכים לטעון סרטון:

1. **קובץ מקומי:** לוחצים על סמל הקובץ האפור ובוחרים את קובץ הווידאו. רוב פורמטי הווידאו הנפוצים נתמכים.
2. **YouTube:** מעתיקים קישור YouTube ללוח, ואז לוחצים על סמל הלוח האדום. אחרי כמה שניות הסרטון יתחיל לרדת.
3. **The Blue Alliance:** לוחצים על סמל ה-TBA הכחול כדי לטעון אוטומטית את סרטון המשחק לפי קובץ היומן. אם יש כמה סרטונים זמינים, בוחרים את הסרטון הרצוי מהתפריט הקופץ. תכונה זו דורשת מפתח API של TBA, שאפשר להוציא בכתובת [thebluealliance.com/account](https://www.thebluealliance.com/account) ולהדביק בדף ההעדפות של AdvantageScope תחת "מפתח API של The Blue Alliance".

<img src="/img/tab-reference/video-1.webp" alt="בוחר מקור" />

אחרי שבוחרים סרטון, ציר הזמן בפינה הימנית התחתונה מתחיל להיצבע בכחול כדי להראות אילו פריימים כבר נשמרו במטמון (זה נדרש לניגון חלק). התכונה הזו מיועדת לסרטונים באורך של משחק בלבד, בגלל הצורך להמיר את הפריימים מראש.

:::warning
הורדת סרטונים מ-YouTube ומ-TBA עלולה להיכשל באופן בלתי צפוי בגלל שינויים בשרתים של YouTube. אם נתקלים בבעיות, נסו לעדכן את AdvantageScope או להשתמש בקובץ וידאו מקומי.
:::

:::info
AdvantageScope דורשת את [FFmpeg](https://ffmpeg.org) כדי לעבד קובצי וידאו. אם FFmpeg תקין לא נמצא ב-PATH של המערכת, AdvantageScope תציע להוריד אותו מהאינטרנט כשתטענו סרטון בפעם הראשונה. התקנה אוטומטית של FFmpeg נתמכת רק ב-Windows וב-macOS; משתמשי Linux יצטרכו להתקין אותו ידנית ולהוסיף אותו ל-PATH של המערכת.
:::

## ניווט בווידאו {#navigating-the-video}

כשסרטון נטען לראשונה ועדיין לא מסונכרן עם נתוני היומן, בקרות הניגון של הווידאו והיומן פועלות בנפרד. השתמשו בציר הזמן ובכפתורים בפינה הימנית התחתונה כדי לשלוט בניגון הווידאו. אפשר להשתמש גם בקיצורי המקלדת הבאים:

- / = הפעלה או השהיה של הניגון
- → = קפיצה פריים אחד קדימה
- ← = חזרה פריים אחד אחורה
- \> = קפיצה 5 שניות קדימה
- < = חזרה 5 שניות אחורה

## סנכרון אוטומטי {#automatic-synchronization}

רוב סרטוני המשחק יסתנכרנו אוטומטית עם היומן זמן קצר אחרי שייטענו הפריימים של שלב האוטונומי. אין צורך לעשות כלום; אם הסנכרון מצליח, בקרות הווידאו יינעלו אוטומטית (ראו "ניגון" למטה).

:::warning
סנכרון אוטומטי עובד רק בסרטוני משחק שכוללים שכבת תוצאות (score overlay), וגם אז הוא לא תמיד מצליח. אם בקרות הווידאו לא ננעלו אוטומטית אחרי שכל הפריימים נטענו, צריך לסנכרן ידנית.
:::

## סנכרון ידני {#manual-synchronization}

קודם כל, משתמשים בבקרות הווידאו כדי להגיע לנקודה ברורה במשחק, כמו תחילת האוטונומי. לאחר מכן בוחרים ביומן את נקודת הזמן שתואמת לפריים הנוכחי בווידאו.

:::tip
הסמן בציר הזמן ננעל אוטומטית (snap) לתחילה ולסוף של שלבי המשחק, מה שמקל לבחור במדויק את תחילת המשחק.
:::

ברגע שהווידאו והיומן מיושרים, לוחצים על סמל המנעול ליד ציר הזמן של הווידאו (או לוחצים על **↑ או ↓**). כעת בקרות הווידאו מושבתות. כדי לשחרר את הנעילה, לוחצים שוב על סמל המנעול.

## ניגון {#playback}

אחרי הנעילה, ניגון הווידאו נשאר מסונכרן עם הזמן שנבחר ביומן. שימו לב שאין תמיכה בשמע, כי הסרטון המקורי מומר לרצף של פריימים בודדים כדי לאפשר סנכרון מדויק עם היומן.

<details>
<summary>בקרות ציר זמן</summary>

ציר הזמן משמש לשליטה בניגון ובתצוגה. לחיצה על ציר הזמן בוחרת נקודת זמן, ולחיצה ימנית מבטלת את הבחירה. הזמן שנבחר מסונכרן בין כל הכרטיסיות, כך שקל למצוא מיד את אותה נקודה גם בתצוגות אחרות.

מקטעים צהובים מציינים שהרובוט באוטונומי, מקטעים כחולים מציינים שהוא בטלאופ, ומקטעים אפורים מציינים שהוא במצב שירות.

כדי לעשות זום, ממקמים את הסמן מעל ציר הזמן וגוללים למעלה או למטה. אפשר גם לבחור טווח על ידי לחיצה וגרירה תוך החזקת מקש `Shift`. כדי לזוז שמאלה וימינה, גוללים אופקית (במכשירים תומכים) או לוחצים וגוררים על ציר הזמן. בחיבור חי, גלילה שמאלה משחררת את הנעילה מהזמן הנוכחי, וגלילה עד הסוף ימינה נועלת אליו בחזרה. לחיצה על `Ctrl+\` עושה זום ישירות לזמן שבו הרובוט מאופשר (enabled).
