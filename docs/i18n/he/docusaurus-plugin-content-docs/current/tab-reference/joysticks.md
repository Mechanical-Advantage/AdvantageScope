# 🎮 ג'ויסטיקים {#joysticks}

כרטיסיית הג'ויסטיקים מציגה את המצב של עד שישה בקרים מחוברים. בתמונה למטה מופיעה פריסה לדוגמה עם שני שלטי Xbox וג'ויסטיק גנרי. כל כפתור נדלק בזמן לחיצה עליו, ובמקביל מוצג המצב של הסטיקים והצירים הנוספים.

<img src="/img/tab-reference/joysticks-1.webp" alt="סקירה כללית של כרטיסיית ג'ויסטיקים" />

_ממשק באנגלית מוצג למעלה._

<details>
<summary>בקרות ציר זמן</summary>

ציר הזמן שולט בניגון ובתצוגת הנתונים. לחיצה עליו בוחרת נקודת זמן, ולחיצה ימנית מבטלת את הבחירה. הזמן שנבחר מסונכרן בין כל הכרטיסיות, כך שקל למצוא את אותה נקודה במהירות גם בשאר התצוגות.

מקטעים צהובים מסמנים שהרובוט במצב Auto, מקטעים כחולים מסמנים מצב Teleop, ומקטעים אפורים מסמנים מצב שירות (Utility).

כדי להתקרב או להתרחק (Zoom), מקמו את הסמן מעל ציר הזמן וגללו למעלה או למטה. אפשר גם לבחור טווח זמן על ידי לחיצה וגרירה תוך כדי החזקת `Shift`. כדי לזוז שמאלה וימינה, גללו אופקית (במכשירים תומכים) או לחצו וגררו על ציר הזמן. בחיבור חי, גלילה שמאלה משחררת את הנעילה מהזמן הנוכחי, וגלילה עד הסוף ימינה נועלת אליו שוב. לחיצה על `Ctrl+\` ממקדת את התצוגה לפרק הזמן שבו הרובוט מאופשר (Enabled).

## חלונית בקרה {#control-pane}

בחרו את סוגי הג'ויסטיקים בטבלה שבתחתית הכרטיסייה. מזהי הג'ויסטיקים (IDs) נעים מ-0 עד 5, ותואמים למזהים ב-Driver Station וב-WPILib. למידע נוסף על ג'ויסטיקים, ראו את [תיעוד WPILib](https://docs.wpilib.org/en/stable/docs/software/basic-programming/joystick.html).

AdvantageScope כוללת מגוון ג'ויסטיקים נפוצים, ביניהם "ג'ויסטיק גנרי" שמציג את כל הכפתורים, הצירים וה-POVs ברשת מסודרת (כמו בתמונה למעלה). כדי להוסיף ג'ויסטיק מותאם אישית, ראו [נכסים מותאמים אישית](/more-features/custom-assets).

:::warning
**נתוני ג'ויסטיקים אינם זמינים דרך חיבור NetworkTables ב-WPILib רגיל.** מה שכן נתמך הוא קובצי יומן של WPILib (כאשר [רישום נתוני ג'ויסטיק מופעל](https://docs.wpilib.org/en/stable/docs/software/telemetry/datalog.html#logging-joystick-data)), יומנים של AdvantageKit, סטרימינג של AdvantageKit ונתוני FIRST Driver Station.
:::
