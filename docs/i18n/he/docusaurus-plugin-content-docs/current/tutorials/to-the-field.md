# 🤖 אל המגרש: ויזואליזציית רובוט

כעת כשטלמטריה בסיסית פועלת, הגיע הזמן להציג את הרובוט שלכם! AdvantageScope מציעה תצוגות מגרש עוצמתיות ב-2D וב-3D שמפיחות חיים באודומטריה, הערכות ראייה, מסלולים מתוכננים ומנגנונים מפרקיים על דגמי מגרשי FRC ו-FTC.

במדריך זה תלמדו כיצד:

- לפרסם נתוני תנוחות מובנים באמצעות **Telemetry API**.
- להשתמש בכרטיסיות **🗺️ מגרש 2D** ו-**👀 מגרש 3D** כדי להציג את תנועת הרובוט.
- לפרסם ולהציג מנגנון הן ב-2D והן ב-3D.

## 1. פרסום תנוחות

ב-WPILib, אובייקטים גיאומטריים כמו `Pose2d`, `Pose3d` ו-`Translation2d` משמשים לייצוג מיקום הרובוט ואלמנטים במגרש. באמצעות **Telemetry API**, תוכלו לרשום תנוחות/הזזות ומערכים (כגון מסלולים מתוכננים או יעדי מצלמה) ישירות בקריאת מתודה אחת:

```java
Pose2d poseA = new Pose2d();
Pose2d poseB = new Pose2d();

Telemetry.log("MyPose", poseA);
Telemetry.log("MyPoseArray", new Pose2d[] {poseA, poseB});
```

<details>
<summary>דוגמת OpMode</summary>

רוצים לנסות את יכולות הוויזואליזציה של AdvantageScope בלי פרויקט רובוט מלא? העתיקו את ה-OpMode שלהלן, המפרסם מספר תנוחות 2D ו-3D להדגמה על דגם מגרש FRC. ראו 👋 [שלום, טלמטריה!](/tutorials/hello-telemetry) לפרטים על יצירת פרויקט WPILib חדש והגדרתו לטלמטריה.

```java
@Teleop
public class ExampleTeleop implements OpMode {
  @Override
  public void periodic() {
    double t = Timer.getTimestamp();

    // יצירת מסלול נהיגה מעגלי לדוגמה
    double x = 2.0 * Math.cos(t * 0.5);
    double y = 2.0 * Math.sin(t * 0.5);
    Rotation2d rotation = Rotation2d.fromRadians(t * 0.5 + Math.PI / 2.0);
    Pose2d robotPose2d = new Pose2d(x, y, rotation);

    // יצירת תנוחת 3D לדוגמה (למשל מלוקליזציית ראייה או גלגול/עלרוד של ג'ירוסקופ)
    Pose3d robotPose3d = new Pose3d(x, y, 0.0, new Rotation3d(0.0, 0.0, rotation.getRadians()));

    // יצירת מסלול לדוגמה (מערך של אובייקטי Pose2d)
    Pose2d[] trajectory = new Pose2d[] {
        new Pose2d(8.0, 4.0, Rotation2d.ZERO),
        new Pose2d(10.0, 4.0, Rotation2d.ZERO),
        new Pose2d(10.0, 6.0, Rotation2d.CW_PI_2)
    };

    // רישום תנוחות 2D ו-3D בודדות
    Telemetry.log("Field/RobotPose2d", robotPose2d);
    Telemetry.log("Field/RobotPose3d", robotPose3d);

    // רישום מערך תנוחות (למשל מסלול מתוכנן או תנוחות AprilTag)
    Telemetry.log("Field/Trajectory", trajectory);
  }
}
```

</details>

## 2. הצגת נתונים ב-2D

כרטיסיית 🗺️ [מגרש 2D](/tab-reference/2d-field) מציגה מבט על של הרובוט שלכם על גבי זירת התחרות.

1. ב-AdvantageScope, לחצו על כפתור **+** בשורת הכרטיסיות ובחרו **מגרש 2D** (או בחרו כרטיסיית מגרש 2D קיימת).
2. מהתפריט הנפתח "מגרש" בחלונית הבקרה התחתונה, בחרו את עונת המשחק הנוכחית או מגרש קבוע.
3. בעץ סרגל הצד, מצאו את `NT:/Telemetry/Field/RobotPose2d` וגררו אותו לרשימת "תנוחות" בחלונית הבקרה.
4. הרובוט שלכם יופיע על המגרש!
5. לחצו על הסמל שליד התנוחה בחלונית הבקרה כדי לשנות את צבע הרובוט.

:::info בקרות מצלמה

לחצו לחיצה ימנית בכל מקום על בד המגרש כדי לבחור בין **לא נעול**, **נעול (רובוט)** (זז עם הרובוט) או **נעול (רובוט וסיבוב)** (מסובב את המגרש כך שהרובוט תמיד מצביע למעלה). לחצו על הכפתורים תחת "כיוון" כדי להתאים את הסיבוב.
:::

## 3. החלפת סוגי אובייקטים

AdvantageScope תומכת בסוגי אובייקטים חזותיים רבים מעבר לתנוחות רובוט פשוטות, כולל רובוטי רפאים (רובוטים שקופים למחצה), מסלולים מתוכננים, יעדי מצלמה, מפות חום, AprilTags, אביזרי משחק ועוד! כדי לגלות אילו סוגי אובייקטים AdvantageScope יכולה להציג:

1. לחצו על הסמל `?` (עזרה) הממוקם בחלונית הבקרה.
2. ייפתח חלון המפרט את כל הסוגים החזותיים הנתמכים, סוגי הנתונים הצפויים (למשל `Pose2d`, `Pose3d[]`, `Translation2d`) והאם ניתן להוסיף אותם כפריטים עצמאיים או כפריטים משניים המוצמדים לאובייקט אחר.

לחצו על הסמל שליד כל תנוחה בחלונית הבקרה כדי לשנות את סוג האובייקט. נסו להחליף את תנוחת הרובוט לסוג אובייקט אחר כמו רובוט רפאים, חץ או מפת חום!

## 4. הצגת נתונים ב-3D

כרטיסיית 👀 [מגרש 3D](/tab-reference/3d-field) מציגה מגרש תלת-ממדי מלא עם אלמנטי משחק, תאורה ודגמי רובוט הניתנים להתאמה אישית.

1. לחצו על **+** בשורת הכרטיסיות ובחרו **מגרש 3D** (או בחרו כרטיסיית מגרש 3D קיימת).
2. בחרו את דגם עונת המשחק שלכם מהתפריט הנפתח "מגרש".
3. גררו את `NT:/Telemetry/Field/RobotPose3d` או `NT:/Telemetry/Field/RobotPose2d` למדור "תנוחות" (תנוחות 2D מונחות אוטומטית על רצפת המגרש).
4. גררו את `NT:/Telemetry/Field/Trajectory` לרשימת "תנוחות" והגדירו את סוגו כ-**מסלול מתוכנן** כדי להציג נתיב כסרט לאורך המגרש.
5. לחצו וגררו עם **כפתור העכבר השמאלי** כדי לסובב את המצלמה סביב המגרש. גררו עם **כפתור העכבר הימני** כדי להזיז את התצוגה. גללו כדי לבצע זום.
6. לחלופין, השתמשו ב-**WASD** לתנועה, **IJKL** לסיבוב ו-**Q/E** לתנועה למעלה ולמטה.
7. לחצו לחיצה ימנית בתצוגת ה-3D כדי לעבור בין **הקפת הרובוט**, **עמדת נהגים** (צפייה במשחק מנקודת המבט של הברית שלכם) ו-**מצלמה קבועה** (צפייה ממצלמות הראייה שעל הרובוט).

## 5. פרסום נתוני מנגנונים

אם לרובוט שלכם יש מבנים מפרקיים כמו מעלית, זרוע או פרק יד, תוכלו להציג אותם באמצעות `Mechanism2d` של WPILib. עיינו ב[תיעוד](https://docs.wpilib.org/en/stable/docs/software/dashboards/glass/mech2d-widget.html) של WPILib לפרטים. להלן דוגמה לזרוע בעלת מפרק יחיד.

```java
public class ExampleTeleop implements OpMode {
  // יצירת קנבס מנגנון 2D (רוחב 2 m, גובה 2 m)
  private final Mechanism2d mechanism = new Mechanism2d(2.0, 2.0);
  private MechanismLigament2d arm;

  public ExampleTeleop(Robot robot) {
    // יצירת זרוע המעוגנת ב-(1 m, 0.5 m)
    MechanismRoot2d root = mechanism.getRoot("ArmRoot", 1.0, 0.5);
    arm = root.append(new MechanismLigament2d("Arm", 0.8, 0.0, 6.0, new Color8Bit(255, 100, 0)));
  }

  @Override
  public void periodic() {
    // הנפשת זווית הזרוע
    double angle = 45.0 + 45.0 * Math.sin(Timer.getTimestamp() * 2.0);
    arm.setAngle(angle);

    // פרסום מצב המנגנון בכל מחזור לולאה
    Telemetry.log("Superstructure/Mechanism", mechanism);
  }
}
```

## 6. הצגת מנגנונים ב-2D

ניתן להשתמש בכרטיסיית ⚙️ [מנגנון](/tab-reference/mechanism) כדי להציג מנגנונים ב-2D.

2. גררו את `NT:/Telemetry/Superstructure/Mechanism` לחלונית הבקרה. תראו את הזרוע המונפשת ב-2D נעה בזמן אמת.

## 7. הצגת מנגנונים ב-3D

תוכלו להקרין את אותו `Mechanism2d` ישירות על הרובוט שלכם בכרטיסיית מגרש 3D!

1. בכרטיסיית מגרש 3D, ודאו שתנוחת הרובוט נוספה לרשימת "תנוחות".
2. גררו את `NT:/Telemetry/Superstructure/Mechanism` **על רשומת תנוחת הרובוט** ברשימת האובייקטים (כאובייקט משני).
3. מנגנון ה-2D מוקרן למרחב התלת-ממדי על גבי שלדת הרובוט! לחצו על סמל גלגל השיניים שליד המנגנון כדי לעבור בין המישורים **XZ** (פרופיל צד) ו-**YZ** (פרופיל חזית).

## מה הלאה?

כעת כשאתם יודעים להציג את תנועת הרובוט והמנגנונים שלו ב-2D וב-3D:

- **🕹️ [לוקחים שליטה: DS וג'ויסטיקים](/tutorials/taking-control):** למדו כיצד להשתלב עם FIRST Driver Station, לעבוד עם יומני DS ולהציג קלט בקרים.
- **👀 [מגרש 3D](/tab-reference/3d-field):** מדריך מקיף לכרטיסיית מגרש 3D, כולל הצגת אביזרי משחק, אפשרויות מצלמה ומצבי רינדור.
- **[AdvantageScope XR](/tab-reference/3d-field/advantagescope-xr):** הפיחו חיים בתצוגת מגרש ה-3D במציאות רבודה ב-iPhone וב-iPad.
- **🎬 [וידאו](/tab-reference/video):** השוו את ויזואליזציית המגרש שלכם זה לצד זה עם צילומי משחק אמיתיים.
- **🦀 [סווארב](/tab-reference/swerve):** הציגו את מצב מנגנוני הנעת ה-swerve, כולל שכבות על מגרשי ה-2D וה-3D.
- **⚙️ [נכסים מותאמים אישית](/more-features/custom-assets):** הוסיפו דגמי CAD מותאמים אישית, מנגנונים מפרקיים ותמונות/דגמי מגרש.
