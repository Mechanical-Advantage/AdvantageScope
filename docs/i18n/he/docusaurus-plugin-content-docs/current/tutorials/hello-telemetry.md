# 👋 שלום, טלמטריה!

ברוכים הבאים ל-AdvantageScope! טלמטריה ותיעוד נתונים (Data Logging) הם כלים רבי-עוצמה שיכולים לשפר את היכולת שלכם להבין את קוד הרובוט, לאבחן תקלות וליישם פתרונות על המגרש ומחוצה לו. מדריכים אלה נועדו לעזור לכם להתחיל לעבוד עם טלמטריה כדי שתוכלו לנצל את מלוא היכולות של AdvantageScope.

במדריך זה תלמדו כיצד:

- להגדיר טלמטריית רובוט בסיסית בפרויקט WPILib ב-Java.
- להתחבר לזרמי נתונים חיים ב-AdvantageScope.
- להקליט נתונים לקובצי יומן לגישה מאוחרת יותר.
- להציג נתוני טלמטריה באמצעות AdvantageScope.

:::tip מחפשים משהו אחר?

- **קבוצות FTC:** אם אתם משתמשים במערכת הבקרה הקיימת של FIRST Tech Challenge, בדקו את המדריך ✴️ [תאימות ל-FTC](/more-features/ftc-compatibility).
- **ממשק ווב:** גרסת דפדפן של AdvantageScope זמינה ישירות בתוך ה-FIRST Driver Station ובממשק הווב של Systemcore. ראו 💡 [AdvantageScope Lite](/more-features/advantagescope-lite) לפרטים.
- **AdvantageKit:** מערכת רישום מתקדמת המיועדת לשחזור דטרמיניסטי בסימולציה. עיינו ב[תיעוד](https://docs.advantagekit.org) לפרטים. אנו ממליצים להתחיל עם ממשק הטלמטריה המובנה של WPILib המתואר להלן.
  :::

## 1. צרו פרויקט WPILib חדש

כדי להתחיל, צרו פרויקט WPILib Java חדש ב-VS Code:

1. פתחו את VS Code.
2. לחצו על סמל WPILib בפינה הימנית העליונה (או לחצו `Ctrl+Shift+P` / `Cmd+Shift+P` והקלידו **WPILib: Create a new project**).
3. בחרו **Template** > **Java** > **Command v3 Robot** (או **Command v2 Robot**).
4. בחרו תיקייה, תנו שם לפרויקט (למשל `HelloTelemetry`) והזינו את מספר הקבוצה שלכם.
5. סמנו **Enable Desktop Support** ולחצו על **Create Project**.

<img src="/img/tutorials/hello-telemetry-1.webp" alt="יצירת פרויקט WPILib Java חדש ב-VS Code באמצעות WPILib Project Creator." />

## 2. אתחלו את רישום הנתונים

WPILib מספקת תיעוד נתונים מובנה באמצעות `DataLogManager`. לאחר הפעלתו, הוא מקליט אוטומטית את כל הטלמטריה, רשומות NetworkTables וקלט ה-Driver Station לקובצי `.wpilog`.

:::info המלצה
למרות שניתן לשמור יומנים באחסון הפנימי של Systemcore, זיכרון הפלאש הפנימי מוגבל. אנו ממליצים בחום לחבר **כונן USB סטנדרטי מפורמט ב-FAT32** לאחת מיציאות ה-USB ב-Systemcore. `DataLogManager` יזהה את הכונן ויכתוב את כל היומנים ישירות אליו באופן אוטומטי.
:::

פתחו את `src/main/java/first/robot/Robot.java` ואתחלו את `DataLogManager` בתוך הבנאי `Robot()`:

```java
public class Robot extends OpModeRobot {
  // ...

  public Robot() {
    // הפעלת DataLogManager להקלטת כל הטלמטריה לקובץ .wpilog על כונן ה-USB
    DataLogManager.start();

    // הקלטת נתוני Driver Station בנוסף (ג'ויסטיקים, OpMode, מצב הפעלה)
    DriverStation.startDataLog(DataLogManager.getLog());
  }

  // ...
}
```

## 3. פרסמו נתוני טלמטריה

המחלקה `Telemetry` של WPILib מאפשרת לפרסם נתונים בשורת קוד אחת, תוך ארגון השדות בטבלאות היררכיות. ממשק API זה תומך במגוון רחב של סוגי נתונים, כולל ערכים מספריים, ערכים בוליאניים, מחרוזות, מערכים ו[סוגי גיאומטריה](https://docs.wpilib.org/en/stable/docs/software/advanced-controls/geometry/index.html) של WPILib.

:::info
המחלקה `Telemetry` ב-WPILib שונה מהמחלקה `Telemetry` ב-FTC SDK. המחלקה `Telemetry` של WPILib שולחת מידע מתוכנית הרובוט ללוחות בקרה, כלי ניפוי שגיאות או קובצי יומן. כדי לעדכן את התצוגה המובנית של ה-Driver Station, השתמשו במחלקה `DriverStationDisplay` של WPILib.
:::

עדכנו את `src/main/java/first/robot/ExampleTeleop.java`:

```java
@Teleop
public class ExampleTeleop implements OpMode {
  // ...

  @Override
  public void periodic() {
    double currentTime = Timer.getTimestamp();
    double sineWave = Math.sin(currentTime * 2.0);

    // פרסום ערכי טלמטריה באמצעות Telemetry API
    Telemetry.log("Time", currentTime);
    Telemetry.log("SineWave/Value", sineWave);
    Telemetry.log("SineWave/Low", sineWave < 0.5);
  }
}
```

פרסו את הקוד לרובוט (או הריצו `WPILib: Simulate Robot Code` מתוך VS Code). בסימולציה, לחצו על `Teleoperated` > `ExampleTeleop` > `Enable`.

<img src="/img/tutorials/hello-telemetry-2.webp" alt="הפעלת ה-OpMode ExampleTeleop בממשק הסימולטור." height="200" />

_הממשק בתמונה מוצג באנגלית._

:::tip
נתוני טלמטריה חדשים מתפרסמים רק כאשר קוראים ל-`Telemetry.log`. מתודות מחזוריות במחלקה `Robot`, ב-OpModes, בתתי-מערכות ובמנגנונים עשויות להיות פעילות בתנאים שונים; בדקו היטב את תיעוד ה-API כשאתם מחליטים היכן למקם קריאות רישום.
:::

## 4. התחברו ל-AdvantageScope בשידור חי

הפעילו את אפליקציית שולחן העבודה של AdvantageScope. בתפריט העליון, בחרו `קובץ` > `התחברות לרובוט` > `NetworkTables` (או `קובץ` > `התחברות לסימולטור` אם אתם מריצים סימולציה). לאחר ההתחברות, סרגל הצד השמאלי יתמלא בשדות המפורסמים תחת `NT:/Telemetry`.

:::tip קיצורי מקלדת
לחצו `Ctrl+K` / `Cmd+K` כדי להתחבר במהירות לרובוט, או `Ctrl+Shift+K` / `Cmd+Shift+K` כדי להתחבר לסימולטור.
:::

## 5. הציגו נתוני טלמטריה

### גרף קווי

📉 [גרף קווי](/tab-reference/line-graph) הוא הכרטיסייה המוגדרת כברירת מחדל ב-AdvantageScope ומספק תרשים בזמן אמת של ערכים מספריים ובדידים.

1. הסתכלו בסרגל הצד השמאלי תחת `Telemetry` > `SineWave`.
2. גררו את `Value` לאזור "ציר שמאלי" בחלונית הבקרה.
3. גררו את `Low` לאזור "שדות בדידים" בחלונית הבקרה.
4. לחצו על שלוש הנקודות שליד "שדות בדידים" ולאחר מכן על "הצגת מצב רובוט".

תוכלו לראות את גל הסינוס ומצב הרובוט מתעדכנים בזמן אמת ככל שהנתונים זורמים!

:::info אינטראקציה עם הגרף

- **השהיה / גלילה:** גללו אופקית או לחצו וגררו על הגרף כדי לצפות בנתוני עבר. החץ האדום בפינה הימנית העליונה מציין שגלילה אוטומטית חיה מושהית. לחצו על החץ או הקישו `L` כדי להפעיל או לכבות גלילה אוטומטית חיה.
- **זום:** גללו למעלה/למטה מעל הגרף, או החזיקו `Shift` בזמן גרירה כדי להתמקד בחלון זמן מסוים.
- **בדיקת ערכים:** לחצו בכל מקום על הגרף כדי למקם סמן זמן ולראות ערכים מדויקים במקרא.
  :::

<img src="/img/tutorials/hello-telemetry-4.webp" alt="גרף קווי המשרטט את אות גל הסינוס." />

### טבלה

כרטיסיית 🔢 [טבלה](/tab-reference/table) מציגה גיליון אלקטרוני כרונולוגי של שינויי מצב וערכים, אידיאלי לאבחון מעברים ורצפי אירועים.

1. לחצו על כפתור **+** בשורת הכרטיסיות העליונה ובחרו **טבלה**.
2. מסרגל הצד, גררו את `NT:/Telemetry/SineWave/Value` ואת `NT:/Telemetry/Low` לתצוגת הטבלה.
3. שורה חדשה נוספת אוטומטית בכל פעם שערך של אחד השדות המוצגים משתנה.
4. לחצו על כל שורה כדי לקפוץ מיד בכל הכרטיסיות הפתוחות לאותה נקודת זמן מדויקת!

:::tip
ניתן לסדר מחדש ולשנות שמות של כרטיסיות באמצעות שורת הכרטיסיות. לחצו על כפתור החלון בשורת הכותרת כדי לפתוח כרטיסייה בחלון צף ולצפות במספר כרטיסיות זו לצד זו.
:::

<img src="/img/tutorials/hello-telemetry-5.webp" alt="כרטיסיית טבלה המציגה נתוני גל סינוס." />

### סטטיסטיקה

כרטיסיית 📊 [סטטיסטיקה](/tab-reference/statistics) מציגה היסטוגרמה של ערכים מספריים, ומעניקה מבט מפורט על נתונים משדה אחד או יותר.

1. לחצו על כפתור **+** בשורת הכרטיסיות העליונה ובחרו **סטטיסטיקה**.
2. מסרגל הצד, גררו את `NT:/Telemetry/SineWave/Value` למדור "מדידות".
3. הגדירו את "טווח נתונים" ל-`-1` ו-`1`, ואת "גודל צעד" ל-`0.1`.
4. צפו בנתונים באמצעות ההיסטוגרמה וסיכום הסטטיסטיקות.
5. גללו את ציר הזמן בחלק העליון כדי להתאים את טווח הנתונים שייכלל.

<img src="/img/tutorials/hello-telemetry-6.webp" alt="כרטיסיית סטטיסטיקה המציגה נתוני גל סינוס." />

## 6. הורידו ופתחו קובצי יומן

לאחר בדיקות או משחק, תוכלו להוריד קובצי `.wpilog` מהרובוט כדי לבדוק את הנתונים בדיעבד:

1. בשורת התפריטים, בחרו `קובץ` > `הורדת יומנים...`.
2. AdvantageScope מתחברת לרובוט ומציגה את כל קובצי היומן שהוקלטו (החדשים ביותר בראש הרשימה).
3. בחרו את קובצי היומן שברצונכם לבדוק, לחצו על סמל ההורדה (↓) ובחרו תיקייה במחשב.
4. פתחו את הקובץ שהורד באמצעות `קובץ` > `פתיחת יומן(ים)...` או על ידי גרירת קובץ ה-`.wpilog` ישירות לתוך AdvantageScope.

<img src="/img/overview/log-files/open-file-2.webp" alt="תיבת ההורדה המציגה קובצי WPILOG זמינים באחסון הרובוט." height="350" />

_הממשק בתמונה מוצג באנגלית._

## מה הלאה?

כעת כשטלמטריה בסיסית ורישום נתונים פועלים, קחו את הוויזואליזציה לשלב הבא:

- **🤖 [אל המגרש: ויזואליזציית רובוט](/tutorials/to-the-field):** למדו כיצד להציג מיקומי רובוט ב-2D/3D, מסלולים ומנגנונים על דגמי מגרשי FRC ו-FTC.
- **[סקירה כללית](/category/overview):** מדריך מקיף לניהול קבצים, קיצורי ניווט ואפשרויות הזרמה חיה.
- **[תמיכה ביחידות](/tab-reference/line-graph/units):** כיצד לשלב מטא-דאטה של יחידות ביומנים לוויזואליזציה מדויקת יותר.
- **💬 [מסוף](/tab-reference/console):** הציגו יומני טקסט שנשמרו על ידי `DataLogManager` של WPILib.
- **🔍 [מטא-דאטה](/tab-reference/metadata):** שמרו מידע נוסף כדי לזהות ולסווג קובצי יומן.
- **[Epilogue](https://docs.wpilib.org/en/stable/docs/software/telemetry/robot-telemetry-with-annotations.html):** רשמו טלמטריה ב-Java באמצעות אנוטציות.
