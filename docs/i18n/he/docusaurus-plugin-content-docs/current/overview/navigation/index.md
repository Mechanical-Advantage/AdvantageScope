# 🧭 ניווט באפליקציה {#app-navigation}

צילום המסך למטה מציג את האזורים המרכזיים בחלון הראשי של AdvantageScope. המראה המדויק משתנה מעט בין מערכות ההפעלה.

<img src="/img/overview/navigation/navigation-1.webp" alt="תרשים ניווט" />

_ממשק באנגלית מוצג למעלה._

- האזור האדום הוא [סרגל הצד](#sidebar), שבו מופיעים כל השדות הזמינים.
- האזור החום הוא [סרגל הכרטיסיות](#tab-bar), שמשמש לשליטה באפליקציה ולמעבר בין תצוגות.
- האזור הכחול הוא [חלונית התצוגה](#viewer-pane), שבה מוצגים הנתונים.
- האזור הירוק הוא [חלונית הבקרה](#control-pane), שבה מכווננים את הוויזואליזציה.

:::tip
כדי לצפות בכמה קובצי יומן במקביל, לחצו על `קובץ` > `חלון חדש`.
:::

## סרגל צד {#sidebar}

בצילום המסך, משמאל נמצא סרגל הצד עם רשימת הטבלאות והשדות הזמינים. שדות שאפשר לבחור מוצגים ב*כתב נטוי*, וטבלאות מובנות (של WPILib או AdvantageKit) מסומנות ב<u>קו תחתון</u>. לחצו על החץ כדי לפתוח טבלאות מקוננות. **גררו שדה בודד** כדי להוסיף אותו, או **החזיקו את מקש cmd/ctrl** ולחצו על כמה שדות כדי לבחור קבוצה יחד (כדי לסיים את הבחירה, פשוט התחילו לגרור אותם).

כדי לחפש שדה, התחילו להקליד בתיבת החיפוש. תיפתח רשימת תוצאות, ואחרי שתבחרו שדה הוא יודגש בסרגל הצד והרשימה תיגלל אליו.

:::info
אפשר לגרור את הקצה של סרגל הצד כדי לשנות את הרוחב שלו או להסתיר אותו, ולחיצה כפולה תציג או תסתיר אותו מיד.
:::

## סרגל כרטיסיות {#tab-bar}

בסרגל הכרטיסיות (כחול) עוברים בין התצוגות השונות. את התיעוד הזה אפשר לפתוח בכל רגע בלחיצה על סמל ה-📖. כדי לייצא את פריסת הכרטיסיות הנוכחית (כולל ההגדרות שלה), לחצו על `קובץ` > `ייצוא פריסה...`, וכדי לטעון פריסה מקובץ לחצו על `קובץ` > `ייבוא פריסה...`.

:::info
אפשר לשנות את סדר הכרטיסיות בגרירה, או לשנות את השם בלחיצה ימנית ובחירת `שינוי שם כרטיסייה`.
:::

כפתורי הניווט (ירוק) בחלק העליון מנהלים את הכרטיסיות ושולטים בניגון:

- **כפתור הפלוס:** פותח תפריט להוספת כרטיסייה חדשה.
- **כפתור החלון:** פותח את הכרטיסייה בחלון נפרד (חלוץ) — שימושי כשרוצים לצפות בכמה כרטיסיות במקביל.
- **כפתור ה-X:** סוגר את הכרטיסייה הנוכחית.
- **כפתור הניגון:** מפעיל ועוצר ניגון בזמן אמת. _לחיצה ימנית מאפשרת לשנות את מהירות הניגון או להפעיל ניגון מחזורי (Loop)._

## חלונית תצוגה {#viewer-pane}

בחלונית התצוגה מוצגים הנתונים של כל כרטיסייה. פרטים על התצוגה של כל כרטיסייה תמצאו במדריך הכרטיסיות. אפשר להעביר את התצוגה לחלון נפרד בלחיצה על כפתור החילוץ בסרגל הכרטיסיות.

## חלונית בקרה {#control-pane}

חלונית הבקרה משמשת לבחירת השדות שיוצגו ולשינוי הגדרות התצוגה. פרטים על האפשרויות בכל כרטיסייה מופיעים במדריך הכרטיסיות.

:::info
אפשר לגרור את הקצה העליון של חלונית הבקרה כדי לשנות את הגובה שלה או להסתיר אותה, ולחיצה כפולה תציג או תסתיר אותה מיד.
:::
