# 🌐 תמיכה בשפות {#language-support}

AdvantageScope תומכת במגוון שפות כדי להציע חוויית שימוש מותאמת לקבוצות מכל העולם. השפות הבאות זמינות ונתמכות כיום בתיעוד, באפליקציית שולחן העבודה, באפליקציות המובייל (AdvantageScope XR ו-AdvantageTune) וב-AdvantageScope Lite (ב-Systemcore וב-FIRST Driver Station):

- אנגלית (ארה"ב)
- ספרדית (אמריקה הלטינית)
- צרפתית
- הולנדית
- פורטוגזית (ברזיל)
- רומנית
- טורקית
- רוסית
- קזחית
- עברית
- ערבית
- הינדי
- סינית פשוטה
- סינית מסורתית

## הגדרות {#configuration}

כדי לשנות את שפת הממשק ב-AdvantageScope, פתחו את חלון ההעדפות דרך `אפליקציה` > `הצגת העדפות...` (Windows/Linux) או `AdvantageScope` > `הגדרות...` (macOS). תחת ההגדרה "שפה 🌐", בחרו שפה מהרשימה או סמנו "ברירת המחדל של המערכת" כדי להתאים אוטומטית לשפת מערכת ההפעלה.

## מפתחות רישום יומן {#logging-keys}

כל הפורמטים ש-AdvantageScope תומכת בהם כוללים תמיכה מלאה ב-Unicode עבור מפתחות יומן. כלומר, אפשר לרשום נתונים בשפה שנוחה לכם (כולל תווים מיוחדים, ניקוד ואותיות לא-לטיניות), והם יישמרו ויוצגו ב-AdvantageScope בצורה תקינה.

להלן דוגמה לרישום מחרוזת עם מפתח בעברית:

<TabItem value="wpilib" label="WPILib" default>

```java

```

</TabItem>
<TabItem value="advantagekit" label="AdvantageKit">


</TabItem>

:::tip תמיכה ביחידות
במדריך על [תמיכה ביחידות](/tab-reference/line-graph/units) תמצאו פרטים נוספים על העברת מטא-דאטה של יחידות מידה. חשוב לדעת שאת שמות היחידות חייבים לציין בסימולי SI או באנגלית (איות אמריקאי או בריטי), בלי קשר לשפה שבחרתם בממשק AdvantageScope.
:::

## פיתוח {#development}

התרגום של AdvantageScope לשפות השונות נעשה בשילוב של בינה מלאכותית ותרומה של הקהילה. מכיוון ש-AdvantageScope מתפתחת בקצב מהיר, השימוש ב-AI הכרחי כדי לשמור על סנכרון מלא בין האפליקציה והתיעוד בכל השפות — כך שכל תכונה חדשה ועדכון זמינים תמיד בו-זמנית, בכל שפה שתבחרו.

תהליך התרגום מותאם במיוחד לז'רגון, למילים השאולות ולתעתיקים שקבוצות הרובוטיקה מכירות מהיומיום. עם זאת, תרגומי AI עלולים לכלול לעיתים ניסוחים לא טבעיים או אי-דיוקים. נשמח מאוד למשוב שלכם — אפשר לדווח על בעיות תרגום ישירות מהאפליקציה בלחיצה על הסמל הסגול (כשהממשק מוגדר לשפה שאינה אנגלית).
