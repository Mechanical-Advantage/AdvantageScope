## Bara laterală {#sidebar}

În stânga se află bara laterală cu lista de tabele și câmpuri disponibile. Câmpurile selectabile sunt afișate în _cursiv_ (italics), iar tabelele integrate (din WPILib sau AdvantageKit) sunt <u>subliniate</u>. Dați clic pe săgeată pentru a extinde tabelele imbricate. **Trageți un singur câmp** pentru a-l selecta sau **țineți apăsat cmd/ctrl** pentru a selecta o colecție de câmpuri dând clic pe fiecare. Începeți să trageți colecția de câmpuri pentru a finaliza selecția.

Pentru a căuta un câmp, începeți să tastați în caseta de căutare. Se va afișa un meniu derulant cu câmpuri, iar câmpul selectat va fi evidențiat în bara laterală și derulat în vizualizare.

:::info
Dați clic și trageți pe marginea din dreapta pentru a redimensiona sau ascunde bara laterală. Dați dublu clic pentru a comuta vizibilitatea bării laterale.
:::

## Bara de file {#tab-bar}

Utilizați bara de file (albastră) pentru a comuta între diferite vizualizări. Această documentație este disponibilă în orice moment dând clic pe pictograma 📖 din stânga. Pentru a exporta aranjamentul curent al filelor (și setările asociate), dați clic pe `Fișier` > `Exportă aranjamentul...` Pentru a importa un aranjament dintr-un fișier, dați clic pe `Fișier` > `Importă aranjamentul...`

:::info
Filele pot fi reorganizate prin clic și tragere sau redenumite prin clic dreapta și selectarea opțiunii `Redenumește...`
:::

Butoanele de navigare (verzi) din partea de sus gestionează filele și controlează redarea.

- **Butonul Plus**: Deschide un meniu derulant pentru a crea o filă nouă.
- **Butonul Fereastră:** Creează o fereastră nouă detașată cu fila respectivă. Această caracteristică poate fi utilizată pentru a vizualiza date din mai multe file simultan.
- **Butonul X:** Închide fila curentă.
- **Butonul Redare:** Pornește și oprește redarea în timp real. _Dați clic dreapta pentru a schimba viteza de redare sau pentru a activa redarea în buclă._

## Panoul de vizualizare {#viewer-pane}

Panoul de vizualizare este locul unde sunt prezentate datele pentru fiecare tip de filă. Consultați documentația de referință a filelor pentru detalii despre panoul de vizualizare al fiecărei file. Această vizualizare poate fi mutată într-o fereastră separată dând clic pe butonul de detașare din bara de file.

## Panoul de control {#control-pane}

Panoul de control este utilizat pentru a selecta câmpuri pentru vizualizare și pentru a gestiona alte opțiuni. Consultați documentația de referință a filelor pentru detalii despre opțiunile disponibile pentru fiecare filă.

:::info
Dați clic și trageți pe marginea superioară pentru a redimensiona sau ascunde panoul de control. Dați dublu clic pentru a comuta vizibilitatea panoului de control.
:::
