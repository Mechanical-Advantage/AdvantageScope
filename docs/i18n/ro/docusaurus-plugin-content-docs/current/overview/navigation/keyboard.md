# Scurtături de tastatură {#keyboard-shortcuts}

AdvantageScope include numeroase scurtături de tastatură care permit o navigare mai rapidă. Scurtăturile care folosesc tasta `ctrl` sunt înlocuite de tasta ⌘ pe macOS.

### Surse de date {#data-sources}

<table>
<tr><td>`Ctrl+O`</td><td>Deschide unul sau mai multe fișiere log</td></tr>
<tr><td>`Ctrl+Shift+O`</td><td>Adaugă unul sau mai multe fișiere log la vizualizarea curentă</td></tr>
<tr><td>`Ctrl+K`</td><td>Conectare la robot ca sursă live</td></tr>
<tr><td>`Ctrl+Shift+K`</td><td>Conectare la simulator ca sursă live</td></tr>
<tr><td>`Ctrl+Option+Shift+K`</td><td>Conectare la Driver Station ca sursă live</td></tr>
<tr><td>`Ctrl+D`</td><td>Descarcă fișierele log de pe robot</td></tr>
</table>

### Export de date {#data-export}

<table>
<tr><td>`Ctrl+E`</td><td>Exportă datele de log</td></tr>
<tr><td>`Ctrl+P`</td><td>Publică datele de log pe un server NetworkTables pe robot</td></tr>
<tr><td>`Ctrl+Shift+P`</td><td>Publică datele de log pe un server NetworkTables în simulare</td></tr>
<tr><td>`Option+Ctrl+P`</td><td>Oprește publicarea pe NetworkTables</td></tr>
</table>

### Controale fereastră {#window-controls}

<table>
<tr><td>`Ctrl+N`</td><td>Creează o fereastră nouă</td></tr>
<tr><td>`Ctrl+Shift+N`</td><td>Închide fereastra curentă</td></tr>
<tr><td>`Ctrl+Virgulă`</td><td>Deschide fereastra de preferințe</td></tr>
<tr><td>`Ctrl+Punct`</td><td>Comută vizibilitatea bării laterale</td></tr>
<tr><td>`Ctrl+Bară înclinată`</td><td>Comută vizibilitatea panoului de control</td></tr>
</table>

### Controale file {#tab-controls}

<table>
<tr><td>`Ctrl+T`</td><td>Deschide meniul derulant pentru a adăuga o filă nouă</td></tr>
<tr><td>`Ctrl+Shift+T`</td><td>Creează o fereastră nouă detașată pentru fila curentă</td></tr>
<tr><td>`Ctrl+Stânga` și `Ctrl+Dreapta`</td><td>Comută filele</td></tr>
<tr><td>`Ctrl+[` și `Ctrl+]`</td><td>Reorganizează filele</td></tr>
<tr><td>`Ctrl+W`</td><td>Închide fila curentă</td></tr>
</table>

### Redare {#playback}

<table>
<tr><td>`Spațiu`</td><td>Comută redarea</td></tr>
<tr><td>`Stânga` și `Dreapta`</td><td>Parcurge pas cu pas fișierul log</td></tr>
<tr><td>`L` sau `Ctrl+L`</td><td>Comută blocajul la vizualizarea datelor live</td></tr>
<tr><td>`Ctrl+\`</td><td>Mărește cronologia la intervalul activat</td></tr>
</table>
