# 💡 AdvantageScope Lite {#advantagescope-lite}

AdvantageScope Lite este o versiune bazată pe browser a AdvantageScope accesibilă din interfața web a FIRST Driver Station și Systemcore. Majoritatea caracteristicilor de bază ale aplicației desktop AdvantageScope sunt incluse în AdvantageScope Lite. Cu toate acestea, câteva caracteristici sunt omise din cauza restricțiilor de compatibilitate (inclusiv unele tipuri de file, formate de logare și caracteristici conexe).

## Instalare și resurse {#installation-and-assets}

AdvantageScope Lite pentru Systemcore poate fi instalat și actualizat prin descărcarea versiunii „Systemcore” a AdvantageScope de pe pagina de lansări de pe GitHub. Selectați cardul „Add Package” pe interfața web Systemcore pentru a încărca pachetul pe robot.

Fișierele de resurse (de ex. modele de teren/robot) pot fi încărcate alegând `Fișier` > `Încărcare resursă`. Fișierul selectat poate fi fie un fișier zip pentru o resursă individuală, fie un fișier zip care conține mai multe fișiere zip cu resurse. Consultați pagina [resurse personalizate](/more-features/custom-assets/) pentru mai multe informații despre formatele de resurse.

:::info
Fișierele zip care conțin colecții de resurse comune pot fi descărcate dând clic pe linkurile de mai jos:

- [**Resurse implicite FRC**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFRC.zip): Terenuri FRC, roboți exemplu FRC și toate aranjamentele de joystick-uri.
- [**Resurse implicite FTC**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFTC.zip): Terenuri FTC, roboți exemplu FTC și toate aranjamentele de joystick-uri.
- [**Resurse FRC 6328**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsFRC6328.zip): Resurse exclusive pentru [distribuția Echipei 6328](/overview/installation#team-6328) a AdvantageScope.

:::

:::tip
Nu este necesară nicio instalare pentru a utiliza AdvantageScope Lite în FIRST Driver Station. Navigați la http://localhost:6768/ascope pentru a vă conecta live sau pentru a vizualiza fișierele log.
:::
