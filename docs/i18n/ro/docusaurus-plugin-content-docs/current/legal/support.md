# Suport {#support}

Pentru a primi suport pentru AdvantageScope sau AdvantageScope XR, folosește una dintre metodele de contact de mai jos.

- Pentru solicitări de funcționalități noi și raportări de erori, [deschide o problemă](https://github.com/Mechanical-Advantage/AdvantageScope/issues) pe GitHub.
- Pentru toate celelalte întrebări, contactează software@team6328.org.
