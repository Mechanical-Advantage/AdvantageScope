# Поддержка единиц измерения {#unit-support}

Вкладка линейного графика учитывает единицы измерения, что означает, что числовые значения можно легко преобразовывать между совместимыми типами единиц. Когда информация о единицах доступна, все числовые значения также точно подписываются при отображении на осях или в легендах. См. [здесь](#supported-formats) для получения дополнительной информации о публикации информации о единицах измерения. AdvantageScope предоставляет несколько инструментов для быстрого преобразования между единицами:

- При добавлении **полей на ту же ось с совместимыми типами единиц** AdvantageScope автоматически преобразует оба поля в одну и ту же единицу. Это отражается на маркировке оси Y и легенды.
- Нажмите три точки рядом с заголовком оси, чтобы **быстро переключиться на альтернативные единицы**. Этот список включает самые распространенные единицы, совместимые с выбранными полями.
- Включите **интегрирование или дифференцирование** ([документация](/tab-reference/line-graph/#integration-and-differentiation)), чтобы увидеть точные единицы интеграла или производной. Базовую единицу можно настроить с помощью меню для поддержки фильтрации в неродных единицах.

## Поддерживаемые форматы {#supported-formats}

AdvantageScope поддерживает несколько методов предоставления информации о единицах измерения для каждого поля. Поддерживается большинство распространенных единиц; полный список смотрите во всплывающем меню при настройке [ручного преобразования](#manual-conversion).

Для пунктов (2) и (3) типы единиц разбираются с использованием строк. AdvantageScope поддерживает несколько имен для каждой единицы, включая распространенные аббревиатуры (например, и `ft`, и `feet` подходят), а также написания как в американском, так и в британском английском (например, `meters` и `metres`). Обратите внимание, что имена единиц должны предоставляться с использованием символов СИ или английского языка, независимо от языка, выбранного в AdvantageScope. Если имя единицы разбирается не так, как ожидалось, пожалуйста, [создайте проблему](https://github.com/Mechanical-Advantage/AdvantageScope/issues).

:::tip
Не уверены, правильно ли разбираются единицы? Проверьте, отображается ли тип единицы на оси Y при добавлении поля на линейный график.
:::

### 🥇 Единицы структур (Struct Units) {#struct-units}

AdvantageScope автоматически использует родные единицы измерения для распространенных типов структурированных данных, таких как `Rotation2d` и `Translation3d`. Публикация применимых значений с использованием этих форматов — **всегда лучший способ публикации данных**, который обеспечивает максимальную совместимость при визуализации геометрических данных.

### 🥈 Метаданные полей {#field-metadata}

Форматы WPILOG и NetworkTables поддерживают публикацию дополнительных «метаданных» для каждого поля. AdvantageScope ищет JSON-поля с именем «unit» или «units», содержащие строковое имя типа единицы (с использованием пробелов, camel-case, pascal-case или snake-case). Чтобы проверить метаданные для каждого поля, наведите курсор на имя поля на боковой панели.

:::tip
AdvantageKit включает поддержку метаданных единиц измерения при логировании вводов и выводов, включая логирование аннотаций. Подробности смотрите в документации [здесь](https://docs.advantagekit.org/data-flow/supported-types#units).
:::

### 🥉 Именование полей {#field-naming}

В качестве запасного варианта AdvantageScope пытается определить правильный тип единицы, разбирая имя каждого поля. **Тип единицы должен быть включен в качестве суффикса.** AdvantageScope поддерживает различные схемы именования. Некоторые допустимые варианты приведены ниже:

- **Camel/pascal-case**, например, `PositionMeters`, `velocityRadPerSec` и `TimestampS`
- **Snake-case**, например, `position_meters`, `velocity_rad_per_sec` и `timestamp_s`
- **Разделители пробелами**, например, `position meters`, `velocity rad per sec` и `timestamp s`

Регистр букв _не_ учитывается при использовании snake-case или разделителей пробелами.

:::tip
Если единицы разбираются неверно, нажмите `Задать единицы вручную` > `Отключить автоматические единицы`, чтобы игнорировать информацию о единицах. Затем можно использовать ручное преобразование для переключения на альтернативные единицы.
:::

## Ручное преобразование {#manual-conversion}

Когда метаданные единиц недоступны или неточны, оси также можно вручную настроить для преобразования между единицами (или полностью игнорировать метаданные единиц).

Чтобы настроить ручное преобразование, нажмите три точки рядом с заголовком оси, а затем `Задать единицы вручную` > `Изменить преобразование...`. Выберите тип единицы, исходную единицу и целевую единицу. Каждое значение также умножается на «Дополнительный множитель», что позволяет выполнять пользовательские преобразования (такие как передаточные отношения, преобразования угловых величин в линейные или другие единицы, не предоставляемые AdvantageScope). Множитель также можно ввести с использованием математического выражения, такого как `1.5*pi`.

:::tip
Чтобы быстро включить или отключить преобразование единиц, нажмите три точки рядом с заголовком оси и выберите `Недавние пресеты` или `Сбросить единицы`.
:::
