# 📉 Линейный график {#line-graph}

Линейный график является видом по умолчанию в AdvantageScope. Он поддерживает как непрерывные (числовые), так и дискретные поля.

<img src="/img/tab-reference/line-graph/line-graph-1.webp" alt="Демонстрация линейного графика" />

## Панель просмотра {#viewer-pane}

Чтобы изменить масштаб, поместите курсор на главный график и прокрутите вверх или вниз. Диапазон также можно выбрать щелчком и перетаскиванием с удержанием `Shift`. Перемещайтесь влево и вправо путем горизонтальной прокрутки (на поддерживаемых устройствах) или путем щелчка и перетаскивания на графике. При подключении в реальном времени прокрутка влево отвязывает от текущего времени, а прокрутка до упора вправо снова привязывает к текущему времени.

Щелчок на графике выбирает время, а щелчок правой кнопкой мыши отменяет его выбор. Значение каждого поля на этот момент времени отображается в легенде. Выбранное время синхронизируется на всех вкладках, что позволяет легко найти это место в других видах.

:::tip
Дельта между выбранным временем и временем при наведении отображается в виде наложения на график, что позволяет легко измерять временные диапазоны. Метки времени форматируются в соответствии с настройкой [Временные метки](/more-features/timestamps).
:::

## Панель управления {#control-pane}

Чтобы начать работу, перетащите поле в один из трех разделов (левый, правый или дискретный). Удалите поле с помощью кнопки X или временно скройте его, нажав иконку глаза или дважды щелкнув имя поля. Чтобы удалить все поля, нажмите три точки рядом с заголовком оси, а затем `Очистить все`. Поля можно переупорядочивать в списке путем щелчка и перетаскивания.

Цвет и стиль линии каждого поля можно настроить, нажав на цветную иконку или щелкнув правой кнопкой мыши по имени поля. Данные из API [постоянных оповещений (persistent alerts)](https://docs.wpilib.org/en/latest/docs/software/telemetry/persistent-alerts.html) WPILib можно визуализировать, добавив группу оповещений в качестве дискретного поля. Пример визуализации показан ниже.

:::tip
Чтобы наложить режим робота (автономный, телеуправляемый или служебный), нажмите три точки рядом с «Дискретные поля» и нажмите «Показывать режим робота».

### Настройка осей {#adjusting-axes}

По умолчанию каждая ось настраивает свой диапазон на основе видимых данных. Чтобы отключить автонастройку диапазонов и заблокировать диапазон на текущих минимуме и максимуме, нажмите три точки рядом с заголовком оси, а затем `Заблокировать ось`. Чтобы настроить диапазон вручную, выберите `Изменить диапазон...` и введите желаемые значения.

<img src="/img/tab-reference/line-graph/line-graph-4.webp" alt="Редактирование диапазона оси" height="250" />

### Интегрирование и дифференцирование {#integration-and-differentiation}

Значения могут быть автоматически интегрированы или дифференцированы с помощью AdvantageScope. Дельта времени всегда измеряется в секундах. Нажмите три точки рядом с заголовком оси, а затем выберите `Дифференцировать` или `Интегрировать`.

:::info
Производные вычисляются с использованием [конечных разностей](https://ru.wikipedia.org/wiki/%D0%9A%D0%BE%D0%BD%D0%B5%D1%87%D0%BD%D1%8B%D0%B5_%D1%80%D0%B0%D0%B7%D0%BD%D0%BE%D1%81%D1%82%D0%B8) соседних выборок. Интегралы вычисляются с использованием [метода трапеций](https://en.wikipedia.org/wiki/%D0%A4%D0%BE%D1%80%D0%BC%D1%83%D0%BB%D0%B0_%D1%82%D1%80%D0%B0%D0%BF%D0%B5%D1%86%D0%B8%D0%B9).
:::
