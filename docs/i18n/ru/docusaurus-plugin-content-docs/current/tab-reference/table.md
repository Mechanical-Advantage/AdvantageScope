# 🔢 Таблица {#table}

Представление «Таблица» предназначено для подробного отображения конкретных изменений значений для набора полей. Чтобы добавить поле, перетащите его в главное представление. Чтобы удалить поле, нажмите кнопку «X» рядом с его именем. Поля можно переупорядочивать перетаскиванием.

<img src="/img/tab-reference/table-1.webp" alt="Обзор" />

_Выше показан интерфейс на английском языке._

**Новая строка создаётся для каждого изменения в любом из отображаемых полей.** Повторяющиеся строки не отображаются. Например, таблица, показывающая состояние робота во время матча, будет выглядеть так:

<img src="/img/tab-reference/table-2.webp" alt="Таблица состояния робота" />

Выбранное время в таблице синхронизируется между всеми вкладками. Нажмите на строку, чтобы выбрать её, или наведите курсор на строку для предварительного просмотра в любых видимых всплывающих окнах. Нажатие кнопки ↓ выполняет переход к выбранному времени (или ко времени, введённому в поле). Метки времени и вводимые значения перехода форматируются в соответствии с настройкой [Временные метки](/more-features/timestamps).
