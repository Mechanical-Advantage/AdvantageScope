# 🔢 Таблица {#table}

Вид таблицы предназначен для подробного отображения конкретных изменений значений для набора полей. Чтобы добавить поле, перетащите его в главный вид. Чтобы удалить поле, нажмите кнопку «X» рядом с его именем. Поля можно переупорядочивать путем щелчка и перетаскивания.

<img src="/img/tab-reference/table-1.png" alt="Overview" />

**Новая строка создается для каждого изменения в любом из отображаемых полей.** Повторяющиеся строки не отображаются. Например, таблица, показывающая состояние робота во время матча, будет выглядеть так:

<img src="/img/tab-reference/table-2.png" alt="Robot state table" />

Выбранное время в таблице синхронизируется на всех вкладках. Нажмите на строку, чтобы выбрать ее, или наведите курсор на строку для предварительного просмотра в любых видимых всплывающих окнах. Нажатие кнопки ↓ переходит к выбранному времени (или времени, введенному в поле).
