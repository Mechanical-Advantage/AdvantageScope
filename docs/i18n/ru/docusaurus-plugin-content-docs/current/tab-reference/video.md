# 🎬 Видео {#video}

Вкладка видео позволяет сравнивать данные лога бок о бок с отдельно записанным видео матча. Приведенные ниже шаги показывают, как загрузить видео и синхронизировать его с логом.

## Загрузка видео {#loading-the-video}

AdvantageScope предоставляет три варианта загрузки видео:

1. **Локальный файл:** Нажмите серую иконку файла, затем выберите видеофайл для загрузки. Поддерживаются большинство распространенных видеоформатов.
2. **YouTube:** Скопируйте ссылку YouTube в буфер обмена, затем нажмите красную иконку буфера обмена. Через несколько секунд видео начнет скачиваться.
3. **The Blue Alliance:** Нажмите синюю иконку TBA для автоматической загрузки видео матча на основе файла лога. Если доступно несколько видео, выберите видео для скачивания из всплывающего меню. Эта функция требует API-ключа для TBA, который следует получить на странице [thebluealliance.com/account](https://www.thebluealliance.com/account) и скопировать на страницу настроек AdvantageScope в поле «API-ключ TBA».

<img src="/img/tab-reference/video-1.webp" alt="Выбор источника" />

После выбора видео шкала времени внизу справа начинает становиться синей для индикации кадров, которые были закэшированы (этот шаг необходим для плавного воспроизведения). Эта функция предназначена только для видео длительностью в матч из-за требуемого преобразования кадров.

:::warning
Загрузка видео с YouTube и TBA может неожиданно давать сбой из-за изменений на серверах YouTube. В случае возникновения проблем попробуйте обновить AdvantageScope или использовать локальный видеофайл.
:::

:::info
AdvantageScope требует [FFmpeg](https://ffmpeg.org) для обработки видеофайлов. Если действительная копия FFmpeg не найдена в системной переменной PATH, AdvantageScope предложит скачать FFmpeg из интернета при первой загрузке видео. Автоматическая установка FFmpeg поддерживается только на Windows и macOS; пользователям Linux может потребоваться вручную установить FFmpeg и добавить его в системную переменную PATH.
:::

## Навигация по видео {#navigating-the-video}

Когда видео изначально загружено и еще не синхронизировано с данными лога, элементы управления воспроизведением видео и лога остаются независимыми. Используйте шкалу времени и кнопки внизу справа для управления воспроизведением видео. Также поддерживаются следующие горячие клавиши:

- / = переключить воспроизведение
- → = переместиться вперед на один кадр
- ← = переместиться назад на один кадр
- \> = пропустить вперед на пять секунд
- < = пропустить назад на пять секунд

## Автоматическая синхронизация {#automatic-synchronization}

Большинство видео матчей синхронизируются автоматически с логом вскоре после загрузки кадров для автономного периода матча. Никаких действий не требуется; если синхронизация прошла успешно, элементы управления видео будут автоматически заблокированы (см. «Воспроизведение» ниже).

:::warning
Автоматическая синхронизация работает только для видео матчей, включающих наложение счета, и может пройти не во всех случаях. Если элементы управления видео не заблокировались автоматически после загрузки всех кадров, требуется ручная синхронизация.
:::

## Ручная синхронизация {#manual-synchronization}

Сначала используйте элементы управления видео для навигации к известному месту в матче, например к началу авто. Затем выберите время в файле лога, которое совпадает с текущим кадром видео.

:::tip
Курсор на шкале времени привязывается к началу и концу периодов матча, что облегчает точный выбор начала матча.
:::

Как только видео и лог выровнены, нажмите иконку замка рядом со шкалой времени видео (или нажмите **↑ или ↓**). Элементы управления видео теперь отключены. Нажмите иконку замка снова, чтобы разблокировать воспроизведение видео.

## Воспроизведение {#playback}

После блокировки воспроизведение видео остается выровненным с выбранным временем в логе. Обратите внимание, что воспроизведение звука не поддерживается, так как оригинальное видео преобразуется в покадровое представление для поддержки синхронизации логов.

<details>
<summary>Элементы управления шкалой времени</summary>

Шкала времени используется для управления воспроизведением и визуализацией. Щелчок по шкале времени выбирает время, а щелчок правой кнопкой мыши отменяет его выбор. Выбранное время синхронизируется на всех вкладках, что позволяет легко найти это место в других видах.

Желтые секции указывают, когда робот находится в автономном режиме, синие секции указывают, когда робот находится в телеуправляемом режиме, а серые секции указывают, когда робот находится в служебном режиме.

Чтобы изменить масштаб, поместите курсор на шкалу времени и прокрутите вверх или вниз. Диапазон также можно выбрать щелчком и перетаскиванием с удержанием `Shift`. Перемещайтесь влево и вправо путем горизонтальной прокрутки (на поддерживаемых устройствах) или путем щелчка и перетаскивания на шкале времени. При подключении в реальном времени прокрутка влево отвязывает от текущего времени, а прокрутка до упора вправо снова привязывает к текущему времени. Нажмите `Ctrl+\`, чтобы масштабировать до периода, когда робот включен.
