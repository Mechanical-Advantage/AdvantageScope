# 🎮 Джойстики {#joysticks}

Вкладка джойстиков показывает состояние до шести подключенных контроллеров. На изображении ниже показан пример раскладки с двумя контроллерами Xbox и универсальным джойстиком. Каждая кнопка подсвечивается при нажатии, а также отображаются состояния стиков и других осей.

_Выше показан интерфейс на английском языке._

<details>
<summary>Элементы управления шкалой времени</summary>

Шкала времени используется для управления воспроизведением и визуализацией. Щелчок по шкале времени выбирает момент времени, а щелчок правой кнопкой мыши снимает выбор. Выбранное время синхронизируется между всеми вкладками, что позволяет легко найти этот момент на других вкладках.

Желтые секции указывают, когда робот находится в автономном режиме, синие — когда робот находится в режиме телеуправления, а серые — когда робот находится в служебном режиме.

Чтобы изменить масштаб, наведите курсор на шкалу времени и прокрутите колесико вверх или вниз. Диапазон также можно выбрать, перетаскивая курсор с удержанием `Shift`. Перемещайтесь влево и вправо с помощью горизонтальной прокрутки (на поддерживаемых устройствах) или перетаскивания шкалы времени. При подключении в реальном времени прокрутка влево отвязывает от текущего времени, а прокрутка до упора вправо снова привязывает к текущему времени. Нажмите `Ctrl+\`, чтобы масштабировать до периода, когда робот включен.

## Панель управления {#control-pane}

Выберите типы джойстиков в таблице внизу вкладки. ID джойстиков находятся в диапазоне от 0 до 5 и соответствуют ID в Driver Station и WPILib. Дополнительную информацию о джойстиках можно найти в [документации WPILib](https://docs.wpilib.org/en/stable/docs/software/basic-programming/joystick.html).

AdvantageScope включает набор распространенных джойстиков, включая «Универсальный джойстик» со всеми кнопками, осями и POV в формате сетки (показано выше). Чтобы добавить пользовательский джойстик, смотрите [Пользовательские ресурсы](/more-features/custom-assets).

:::warning
**Данные джойстиков НЕДОСТУПНЫ через подключение NetworkTables в стандартной WPILib.** Поддерживаются файлы логов WPILib (с [включенным логированием джойстиков](https://docs.wpilib.org/en/stable/docs/software/telemetry/datalog.html#logging-joystick-data)), логи AdvantageKit и трансляция AdvantageKit.
:::
