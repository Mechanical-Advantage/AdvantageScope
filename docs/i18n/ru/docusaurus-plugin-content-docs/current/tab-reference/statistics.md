# 📊 Статистика {#statistics}

Вкладка статистики позволяет проводить глубокий статистический анализ числовых полей, анализируя общие тенденции, а не изменения во времени. Выбранные поля анализируются с использованием гистограммы и различных стандартных статистических показателей.

<img src="/img/tab-reference/statistics-1.png" alt="Overview of statistics tab" />

## Панель управления {#control-pane}

Чтобы начать работу, перетащите поле в раздел «Измерения». Удалите поле с помощью кнопки X или временно скройте его, нажав иконку глаза или дважды щелкнув имя поля. Чтобы удалить все поля, нажмите три точки рядом с заголовком оси, а затем `Очистить все`. Поля можно переупорядочивать в списке путем щелчка и перетаскивания.

Чтобы проанализировать разницу между полями, переключите поле в режим «Эталонный» и добавьте дополнительные другие поля в качестве дочерних. Дочерние поля можно переключать между режимами «Относительная ошибка» и «Абсолютная ошибка».

:::info
Цвет каждого поля можно настроить, нажав на цветную иконку или щелкнув правой кнопкой мыши по имени поля.
:::

### Конфигурация {#configuration}

Опция **Временной диапазон** выбирает, какие части лога используются для анализа:

- _Видимый диапазон:_ Анализирует диапазон времени, видимый на шкале времени.
- _Весь лог:_ Анализирует весь диапазон файла лога.
- _Включен:_ Анализирует диапазоны времени, когда робот включен.
- _Авто:_ Анализирует диапазоны времени, когда робот находится в автономном режиме.
- _Телеоп:_ Анализирует диапазоны времени, когда робот находится в телеуправляемом режиме.
- _В реальном времени: 30 секунд:_ Анализирует последние 30 секунд (при подключении к источнику в реальном времени).
- _В реальном времени: 10 секунд:_ Анализирует последние 10 секунд (при подключении к источнику в реальном времени).

Опция **Диапазон данных** выбирает минимальное и максимальное значения для отображения на гистограмме. Данные за пределами этого диапазона не отображаются, но продолжают использоваться для статистических показателей.

Опция **Размер шага** выбирает размер каждого интервала (бин) гистограммы. Меньшие значения дают более подробные графики, но также проявляют больше шума.

## Панель просмотра {#viewer-pane}

### Гистограмма {#histogram}

Гистограмма показывает количество выборок, попадающих в каждый интервал в пределах указанного диапазона. Обратите внимание, что данные за пределами указанного диапазона отбрасываются (а не группируются в отдельный интервал).

### Статистические показатели {#statistical-measures}

Таблица статистических показателей показывает рассчитанные значения каждого показателя для предоставленных полей. Дополнительная информация по каждому показателю приведена ниже.

#### Сводка {#summary}

- **Количество:** Количество сгенерированных дискретных выборок.
- **Мин.:** Наименьшее значение в данных.
- **Макс.:** Наибольшее значение в данных.

#### Центр {#center}

- [**Среднее:**](https://ru.wikipedia.org/wiki/%D0%A1%D1%80%D0%B5%D0%B4%D0%BD%D0%B5%D0%B5_%D0%B0%D1%80%D0%B8%D1%84%D0%BC%D0%B5%D1%82%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B5) Среднее арифметическое (простое среднее) данных.
- [**Медиана:**](<https://ru.wikipedia.org/wiki/%D0%9C%D0%B5%D0%B4%D0%B8%D0%B0%D0%BD%D0%B0_(%D1%81%D1%82%D0%B0%D1%82%D0%B8%D1%81%D1%82%D0%B8%D0%BA%D0%B0)>) «Срединное» значение данных или 50%-й перцентиль.
- [**Мода:**](<https://ru.wikipedia.org/wiki/%D0%9C%D0%BE%D0%B4%D0%B0_(%D1%81%D1%82%D0%B0%D1%82%D0%B8%D1%81%D1%82%D0%B8%D0%BA%D0%B0)>) Наиболее часто встречающееся значение в данных.
- [**Среднее геометрическое:**](https://ru.wikipedia.org/wiki/%D0%A1%D1%80%D0%B5%D0%B4%D0%BD%D0%B5%D0%B5_%D0%B3%D0%B5%D0%BE%D0%BC%D0%B5%D1%82%D1%80%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B5) Показатель центра, рассчитываемый с использованием произведения значений, а не суммы. Применимо при измерении _темпов экспоненциального роста_ (например, процентного изменения между циклами).
- [**Среднее гармоническое:**](https://ru.wikipedia.org/wiki/%D0%A1%D1%80%D0%B5%D0%B4%D0%BD%D0%B5%D0%B5_%D0%B3%D0%B0%D1%80%D0%BC%D0%BE%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B5) Показатель центра, рассчитываемый с использованием суммы обратных величин значений. Применимо при измерении _темпов или скоростей_.
- [**Среднее квадратичное:**](https://en.wikipedia.org/wiki/%D0%A1%D1%80%D0%B5%D0%B4%D0%BD%D0%B5%D0%B5_%D0%BA%D0%B2%D0%B0%D0%B4%D1%80%D0%B0%D1%82%D0%B8%D1%87%D0%BD%D0%BE%D0%B5) Показатель центра, рассчитываемый с использованием квадратов значений. Применимо при измерении данных с как _положительными, так и отрицательными значениями_, например, периодического движения.

#### Разброс {#spread}

- [**Стандартное отклонение:**](https://en.wikipedia.org/wiki/%D0%A1%D1%80%D0%B5%D0%B4%D0%BD%D0%B5%D0%BA%D0%B2%D0%B0%D0%B4%D1%80%D0%B0%D1%82%D0%B8%D1%87%D0%BD%D0%BE%D0%B5_%D0%BE%D1%82%D0%BA%D0%BB%D0%BE%D0%BD%D0%B5%D0%BD%D0%B8%D0%B5) Наиболее распространенный статистический показатель вариации, где меньшее значение указывает на меньшую вариацию. 68% данных попадает в пределы одного стандартного отклонения от среднего.
- [**Медианное абсолютное отклонение:**](https://ru.wikipedia.org/wiki/%D0%90%D0%B1%D1%81%D0%BE%D0%BB%D1%8E%D1%82%D0%BD%D0%BE%D0%B5_%D0%BE%D1%82%D0%BA%D0%BB%D0%BE%D0%BD%D0%B5%D0%BD%D0%B8%D0%B5) Среднее расстояние между каждым значением и средним. Это альтернатива стандартному отклонению.
- [**Межквартильный размах:**](https://ru.wikipedia.org/wiki/%D0%9C%D0%B5%D0%B6%D0%BA%D0%B2%D0%B0%D1%80%D1%82%D0%B8%D0%BB%D1%8C%D0%BD%D1%8B%D0%B9_%D1%80%D0%B0%D0%B7%D0%BC%D0%B0%D1%85) Разница между третьим и первым квартилями (75-й перцентиль и 25-й перцентиль), менее подверженная влиянию выбросов, чем стандартное отклонение или среднее абсолютное отклонение.
- [**Асимметрия:**](https://ru.wikipedia.org/wiki/%D0%9A%D0%BE%D1%8D%D1%84%D1%84%D0%B8%D1%86%D0%B8%D0%B5%D0%BD%D1%82_%D0%B0%D1%81%D0%B8%D0%BC%D0%BC%D0%B5%D1%82%D1%80%D0%B8%D0%B8) Показатель асимметричного скоса данных. Отрицательное значение указывает на хвост влево, положительное значение указывает на хвост вправо, а нулевое значение предполагает симметричное распределение.

#### Перцентили {#percentiles}

[Перцентили](https://ru.wikipedia.org/wiki/%D0%9F%D1%80%D0%BE%D1%86%D0%B5%D0%BD%D1%82%D0%B8%D0%BB%D1%8C) измеряют значения, ниже которых попадает данный процент других значений. Например, 10% значений попадает ниже 10-го перцентиля. Следующие перцентили также известны как:

- 25-й перцентиль = 1-й квартиль (Q1)
- 50-й перцентиль = 2-й квартиль (Q2) = медиана
- 75-й перцентиль = 3-й квартиль (Q3)
