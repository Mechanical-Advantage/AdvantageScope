# 🦀 Swerve {#swerve}

Вкладка swerve показывает состояние четырёх модулей swerve, включая векторы скорости, положения в состоянии покоя, вращение робота и скорости шасси.

_Выше показан интерфейс на английском языке._

<details>
<summary>Элементы управления шкалой времени</summary>

Шкала времени используется для управления воспроизведением и визуализацией. Щелчок по шкале времени выбирает момент времени, а щелчок правой кнопкой мыши снимает выбор. Выбранное время синхронизируется между всеми вкладками, что позволяет легко найти этот момент на других вкладках.

Жёлтые секции указывают, когда робот находится в автономном режиме, синие — когда робот находится в режиме телеуправления, а серые — когда робот находится в служебном режиме.

Чтобы изменить масштаб, наведите курсор на шкалу времени и прокрутите колёсико вверх или вниз. Диапазон также можно выбрать, перетаскивая курсор с удержанием `Shift`. Перемещайтесь влево и вправо с помощью горизонтальной прокрутки (на поддерживаемых устройствах) или перетаскивания шкалы времени. При подключении в реальном времени прокрутка влево отвязывает от текущего времени, а прокрутка до упора вправо снова привязывает к текущему времени. Нажмите `Ctrl+\`, чтобы масштабировать до периода, когда робот включён.

## Добавление источников {#adding-sources}

Чтобы начать работу, перетащите поле в раздел «Источники». Удалите источник с помощью кнопки X или временно скройте его, нажав иконку глаза или дважды щелкнув имя поля. Чтобы удалить все источники, нажмите на мусорную корзину рядом с заголовком оси, а затем `Очистить всё`. Источники можно переупорядочивать в списке перетаскиванием.

**Чтобы настроить каждый источник, нажмите на цветную иконку или щелкните правой кнопкой мыши по имени поля.** AdvantageScope поддерживает три типа источников:

- **Скорости модулей:** Набор состояний четырёх модулей swerve, отображаемых в виде векторов на диаграмме.
- **Скорости робота:** Линейные и угловые скорости, отображаемые в центре диаграммы.
- **Вращение:** Угловая позиция, используемая для вращения диаграммы.

## Формат данных {#data-format}

Данные должны публиковаться в виде закодированных в байты структур (struct) или protobuf с использованием типов `SwerveModuleVelocity[]`, `ChassisVelocities`, `Rotation2d` или `Rotation3d`.

Многие библиотеки поддерживают формат struct, включая WPILib и AdvantageKit. Пример кода ниже показывает, как логировать состояния модулей swerve на Java.

<Tabs groupId="library">
<TabItem value="wpilib" label="WPILib" default>

```java
SwerveModuleVelocity[] states = new SwerveModuleVelocity[] {
  new SwerveModuleVelocity(),
  new SwerveModuleVelocity(),
  new SwerveModuleVelocity(),
  new SwerveModuleVelocity()
};

Telemetry.log("MyStates", states);
```

</TabItem>
<TabItem value="advantagekit" label="AdvantageKit">

```java
SwerveModuleVelocity[] states = new SwerveModuleVelocity[] {
  new SwerveModuleVelocity(),
  new SwerveModuleVelocity(),
  new SwerveModuleVelocity(),
  new SwerveModuleVelocity()
};

Logger.recordOutput("MyStates", states);
```

</TabItem>
</Tabs>

:::note
В 2027 году эта структура данных была переименована из `SwerveModuleState` в `SwerveModuleVelocity`.
Для файлов логов, созданных до WPILib 2027 и Systemcore, устаревшие типы `SwerveModuleState` по-прежнему поддерживаются для визуализации.
:::

## Конфигурация {#configuration}

Доступны следующие параметры конфигурации:

- **Макс. скорость:** Максимально достижимая скорость модулей, используемая для регулировки размера векторов.
- **Размер рамы:** Расстояния между левыми/правыми и передними/задними модулями swerve. Изменяет соотношение сторон диаграммы робота.
- **Ориентация:** Задает направление, в котором ориентирована диаграмма робота. Эта опция часто полезна для выравнивания с данными поз или видео матчей.
