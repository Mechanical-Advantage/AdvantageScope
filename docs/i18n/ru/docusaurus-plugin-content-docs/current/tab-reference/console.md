# 💬 Консоль {#console}

Вид консоли предназначен для просмотра одного строкового поля с данными консоли. Некоторые предлагаемые поля приведены ниже.

- **DS:/Dscomm/Console** - Сохраняется FIRST Driver Station.
- **messages** - Сохраняется встроенным логированием WPILib на основе вызовов метода [`DataLogManager.log`](<https://github.wpilib.org/allwpilib/docs/release/java/edu/wpi/first/wpilibj/DataLogManager.html#log(java.lang.String)>).
- **/RealOutputs/Console** - Автоматически сохраняется AdvantageKit во время работы робота (используйте `System.out.println` как обычно).
- **/ReplayOutputs/Console** - Автоматически сохраняется AdvantageKit во время повторного воспроизведения лога (используйте `System.out.println` как обычно).

Перетащите желаемое поле в главный вид, чтобы начать работу. Каждая строка представляет обновление поля. Для логов WPILib создается новая строка для каждой сохраненной строки. Для логов AdvantageKit создается новая строка для каждого цикла.

<img src="/img/tab-reference/console-1.png" alt="Console view" />

:::info
Нажмите иконку цветовой палитры, чтобы переключить выделение предупреждений и ошибок. Для логов WPILib и AdvantageKit сообщения выделяются, если они содержат текст "warning" или "error".
:::

Элементы управления аналогичны вкладке 🔢 [Таблица](../tab-reference/table). Выбранное время синхронизируется на всех вкладках. Нажмите на строку, чтобы выбрать ее, или наведите курсор на строку для предварительного просмотра в любых видимых всплывающих окнах. Нажатие кнопки ↓ переходит к выбранному времени (или времени, введенному в поле).

Введите текст в поле «Фильтр», чтобы отобразить только строки, содержащие текст фильтра. Нажмите `Ctrl+F`, чтобы быстро выбрать поле «Фильтр». Добавьте «!» в начало текста фильтра, чтобы _исключить_ совпадающие сообщения из главного вида.

:::tip
Нажмите иконку сохранения, чтобы экспортировать данные консоли в текстовый файл.
:::
