# 💬 Консоль {#console}

Представление «Консоль» предназначено для просмотра одного строкового поля с данными консоли. Ниже приведены некоторые рекомендуемые поля.

- **DS:/Dscomm/Console** - Сохраняется FIRST Driver Station.
- **messages** - Сохраняется встроенным логированием WPILib на основе вызовов метода [`DataLogManager.log`](<https://github.wpilib.org/allwpilib/docs/release/java/edu/wpi/first/wpilibj/DataLogManager.html#log(java.lang.String)>).
- **/RealOutputs/Console** - Автоматически сохраняется AdvantageKit во время работы робота (используйте `System.out.println` как обычно).
- **/ReplayOutputs/Console** - Автоматически сохраняется AdvantageKit во время повторного воспроизведения лога (используйте `System.out.println` как обычно).

Перетащите нужное поле в главное представление, чтобы начать работу. Каждая строка представляет обновление поля. Для логов WPILib новая строка создается для каждой сохраненной записи, а для логов AdvantageKit — для каждого цикла.

:::info
Нажмите иконку цветовой палитры, чтобы переключить выделение предупреждений и ошибок. Для логов WPILib и AdvantageKit сообщения выделяются, если они содержат текст «warning» или «error».
:::

Элементы управления аналогичны вкладке 🔢 [Таблица](../tab-reference/table). Выбранное время синхронизируется между всеми вкладками. Нажмите на строку, чтобы выбрать ее, или наведите курсор на строку для предварительного просмотра в любых видимых всплывающих окнах. Нажатие кнопки ↓ выполняет переход к выбранному времени (или ко времени, введенному в поле). Метки времени и вводимые значения перехода форматируются в соответствии с настройкой [Временные метки](/more-features/timestamps).

Введите текст в поле «Фильтр», чтобы отображать только строки, содержащие этот текст. Нажмите `Ctrl+F`, чтобы быстро перейти к полю «Фильтр». Добавьте «!» в начало текста фильтра, чтобы _исключить_ совпадающие сообщения из основного представления.

## Форматирование ANSI {#ansi-formatting}

Модуль рендеринга консоли поддерживает форматирование и цветовые коды с использованием стандартных управляющих последовательностей ANSI:

- **Стили текста:** Полужирный (bold), тусклый (dim), курсив (italic) и подчеркнутый (underline)
- **Цвета текста и фона:** 16 стандартных цветов (стандартные и высокой интенсивности)
- **8-битные и 24-битные цвета:** Таблица поиска на 256 цветов и 24-битный RGB
- **Выборочный сброс:** Сброс определенных стилей или цветов с сохранением остальных

:::tip
Нажмите иконку сохранения, чтобы экспортировать данные консоли в текстовый файл.
:::
