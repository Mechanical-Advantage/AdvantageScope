# 📐 Системы координат {#coordinate-systems}

AdvantageScope поддерживает несколько распространённых систем координат на вкладках [🗺️ 2D-поле](/tab-reference/2d-field) и [👀 3D-поле](/tab-reference/3d-field). Подробнее о соглашениях об осях и вращении, используемых в AdvantageScope, см. в [документации по системам координат WPILib](https://docs.wpilib.org/en/stable/docs/software/basic-programming/coordinate-system.html#wpilib-coordinate-system).

### Настройка {#customization}

По умолчанию система координат выбирается автоматически на основе выбранного изображения или модели поля. Чтобы задать другую систему координат для всех полей, откройте окно настроек, нажав `Приложение` > `Показать настройки...` (Windows/Linux) или `AdvantageScope` > `Настройки...` (macOS), и измените параметр «Система координат».

:::tip
Все варианты систем координат совместимы с полями FRC и FTC.
:::

## Центр/красные (Systemcore) {#center-red}

Начало координат находится в центре поля, причём ось +X направлена в сторону от стены красного альянса, как показано ниже. **Это система координат по умолчанию для полей FRC начиная с 2027 года и полей FTC начиная с сезона 2027–2028 годов.**

## Синяя стена {#blue-wall}

Начало координат находится в крайнем правом углу стены синего альянса, причём ось +X направлена в сторону стены красного альянса, как показано ниже. **Это система координат по умолчанию для полей FRC с 2023 по 2026 год.**

<img src="/img/more-features/coordinate-system-blue-wall.webp" alt="Система координат синяя стена" />

## Стена альянса {#alliance-wall}

Начало координат находится в крайнем правом углу стены альянса для _текущего альянса робота_, причём ось +X направлена к противоположной стене альянса, как показано ниже. **Это система координат по умолчанию для FRC в 2022 году.**

<img src="/img/more-features/coordinate-system-alliance-wall.webp" alt="Система координат стена альянса" />
