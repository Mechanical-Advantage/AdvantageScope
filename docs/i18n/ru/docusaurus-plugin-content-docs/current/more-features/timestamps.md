# ⏱️ Временные метки {#timestamps}

AdvantageScope поддерживает настраиваемые параметры отображения временных меток во всех представлениях, включая шкалу времени, 📉 [Линейный график](/tab-reference/line-graph), 🔢 [Таблицу](/tab-reference/table) и 💬 [Консоль](/tab-reference/console).

## Режимы отображения {#display-modes}

Режим отображения временных меток можно настроить в окне настроек:

- **С нуля (По умолчанию):** Смещает все временные метки таким образом, чтобы самые ранние данные в логе начинались с нуля (`+0.0s`). Временные метки, отображаемые в этом режиме, имеют префикс `+`, указывающий время, прошедшее с момента начала данных.
- **Исходное:** Отображает временные метки с использованием их исходных числовых значений, записанных в файле лога, соответствующих точным значениям, используемым кодом робота.

:::info
Начиная с WPILib 2027, временные метки измеряются с момента загрузки устройства (boot) на Systemcore и в симуляции. Поскольку необработанные временные метки могут начинаться с произвольно больших чисел, режим **С нуля** предоставляется как более интуитивный вариант визуализации.
:::

## Синхронизация нескольких логов {#multi-log-synchronization}

Когда [одновременно открыто несколько файлов логов](/overview/log-files/#opening-logs), AdvantageScope синхронизирует и выравнивает их временные метки. В режиме **С нуля** нулевая точка устанавливается на самую раннюю временную метку среди всех загруженных файлов. В режиме **Исходное** временные метки отображаются с использованием базы времени первого открытого лога, а любые дополнительные логи сдвигаются для выравнивания с ним.

## Настройка {#customization}

Чтобы изменить режим отображения временных меток, откройте окно настроек, выбрав `App` > `Show Preferences...` (Windows/Linux) или `AdvantageScope` > `Настройки...` (macOS), либо нажав `Ctrl+,` / `Cmd+,`. Установите для параметра **Временные метки** желаемое значение.
