# 💡 AdvantageScope Lite {#advantagescope-lite}

AdvantageScope Lite — это браузерная версия AdvantageScope, доступная из FIRST Driver Station и веб-интерфейса Systemcore. Большинство базовых функций десктопного приложения AdvantageScope включены в AdvantageScope Lite. Однако некоторые функции опущены из-за ограничений совместимости (включая некоторые типы вкладок, форматы логирования и связанные функции).

## Установка и ресурсы {#installation-and-assets}

AdvantageScope Lite для Systemcore можно установить и обновить, скачав версию AdvantageScope «Systemcore» со страницы релизов GitHub. Выберите карточку «Добавить пакет» (Add Package) в веб-интерфейсе Systemcore, чтобы загрузить пакет на робота.

Файлы ресурсов (например, модели полей/роботов) можно загрузить, выбрав `Файл` > `Загрузить ресурс`. Выбранный файл может быть либо zip-файлом для отдельного ресурса, либо zip-файлом, содержащим несколько zip-файлов ресурсов. Смотрите страницу [пользовательские ресурсы](/more-features/custom-assets/) для получения дополнительной информации о форматах ресурсов.

:::info
Zip-файлы, содержащие коллекции распространенных ресурсов, можно скачать, перейдя по ссылкам ниже:

- [**Ресурсы FRC по умолчанию**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFRC.zip): поля FRC, примеры роботов FRC и все раскладки джойстиков.
- [**Ресурсы FTC по умолчанию**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFTC.zip): поля FTC, примеры роботов FTC и все раскладки джойстиков.
- [**Ресурсы FRC 6328**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsFRC6328.zip): ресурсы, эксклюзивные для [дистрибутива Команды 6328](/overview/installation#team-6328) AdvantageScope.

:::

:::tip
Для использования AdvantageScope Lite в FIRST Driver Station установка не требуется. Перейдите по адресу http://localhost:6768/ascope для подключения в реальном времени или просмотра файлов логов.
:::
