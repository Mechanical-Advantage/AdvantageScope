# 👋 Привет, телеметрия!

Добро пожаловать в AdvantageScope! Телеметрия и запись данных — это мощные инструменты, которые помогут Вам лучше понимать код робота, диагностировать проблемы и находить решения как на поле, так и за его пределами. Эти руководства помогут Вам начать работу с телеметрией, чтобы Вы могли использовать все возможности AdvantageScope.

В этом руководстве Вы узнаете, как:

- Настроить базовую телеметрию робота в проекте Java WPILib.
- Подключиться к потокам данных в реальном времени в AdvantageScope.
- Записать данные в файлы логов для последующего анализа.
- Визуализировать данные телеметрии с помощью AdvantageScope.

:::tip Ищете что-то другое?

- **Командам FTC:** Если Вы используете существующую систему управления FIRST Tech Challenge, ознакомьтесь с руководством ✴️ [Совместимость с FTC](/more-features/ftc-compatibility).
- **Веб-интерфейс:** Браузерная версия AdvantageScope доступна прямо в FIRST Driver Station и веб-интерфейсе Systemcore. Подробности смотрите в разделе 💡 [AdvantageScope Lite](/more-features/advantagescope-lite).
- **AdvantageKit:** Продвинутый фреймворк логирования, созданный для детерминированного воспроизведения в симуляции. Подробности смотрите в [документации](https://docs.advantagekit.org). Мы рекомендуем начать со встроенного API телеметрии WPILib, описанного ниже.
  :::

## 1. Создайте новый проект WPILib

Для начала создайте новый Java-проект WPILib в VS Code:

1. Откройте VS Code.
2. Нажмите на иконку WPILib в правом верхнем углу (или нажмите `Ctrl+Shift+P` / `Cmd+Shift+P` и введите **WPILib: Create a new project**).
3. Выберите **Template** > **Java** > **Command v3 Robot** (или **Command v2 Robot**).
4. Выберите папку, задайте имя проекта (например, `HelloTelemetry`) и введите номер Вашей команды.
5. Установите флажок **Enable Desktop Support** и нажмите **Create Project**.

## 2. Инициализируйте запись данных

WPILib предоставляет встроенную запись данных через `DataLogManager`. После запуска он автоматически записывает всю телеметрию, записи NetworkTables и ввод с Driver Station в файлы `.wpilog`.

:::info Рекомендация
Хотя логи можно сохранять во внутреннюю память Systemcore, объём внутренней флеш-памяти ограничен. Мы настоятельно рекомендуем подключить стандартный **USB-накопитель, отформатированный в FAT32**, в один из USB-портов Systemcore. `DataLogManager` обнаружит накопитель и автоматически запишет все логи прямо на него.
:::

Откройте `src/main/java/first/robot/Robot.java` и инициализируйте `DataLogManager` внутри конструктора `Robot()`:

```java
public class Robot extends OpModeRobot {
  // ...

  public Robot() {
    // Запустите DataLogManager для записи всей телеметрии в файл .wpilog на USB-накопителе
    DataLogManager.start();

    // Также записывайте данные Driver Station (джойстики, OpMode, состояние включения)
    DriverStation.startDataLog(DataLogManager.getLog());
  }

  // ...
}
```

## 3. Публикуйте данные телеметрии

Класс `Telemetry` в WPILib позволяет публиковать данные одной строкой кода, организуя поля в иерархические таблицы. Этот API поддерживает широкий спектр типов данных, включая числовые значения, логические значения, строки, массивы и [геометрические типы](https://docs.wpilib.org/en/stable/docs/software/advanced-controls/geometry/index.html) WPILib.

:::info
Класс `Telemetry` в WPILib отличается от класса `Telemetry` в FTC SDK. Класс `Telemetry` в WPILib отправляет информацию из программы робота в дашборды, инструменты отладки или файлы логов. Для обновления встроенного дисплея Driver Station используйте класс `DriverStationDisplay` из WPILib.
:::

Обновите `src/main/java/first/robot/ExampleTeleop.java`:

```java
@Teleop
public class ExampleTeleop implements OpMode {
  // ...

  @Override
  public void periodic() {
    double currentTime = Timer.getTimestamp();
    double sineWave = Math.sin(currentTime * 2.0);

    // Публикуйте значения телеметрии с помощью API Telemetry
    Telemetry.log("Time", currentTime);
    Telemetry.log("SineWave/Value", sineWave);
    Telemetry.log("SineWave/Low", sineWave < 0.5);
  }
}
```

Загрузите код на робота (или запустите `WPILib: Simulate Robot Code` из VS Code). В симуляции нажмите `Teleoperated` > `ExampleTeleop` > `Enable`.

<img src="/img/tutorials/hello-telemetry-2.webp" alt="Включение OpMode ExampleTeleop в интерфейсе симулятора." height="200" />

_Выше показан интерфейс на английском языке._

:::tip
Новые данные телеметрии публикуются только при вызове `Telemetry.log`. Периодические методы в классе `Robot`, OpMode, подсистемах и механизмах могут быть активны при разных условиях; внимательно изучите документацию API, решая, где разместить вызовы логирования.
:::

## 4. Подключите AdvantageScope в реальном времени

Запустите настольное приложение AdvantageScope. В верхнем меню выберите `Файл` > `Подключиться к роботу` > `NetworkTables` (или `Файл` > `Подключиться к симулятору`, если Вы используете симуляцию). После подключения левая боковая панель заполнится опубликованными полями в разделе `NT:/Telemetry`.

:::tip Горячие клавиши
Нажмите `Ctrl+K` / `Cmd+K` для быстрого подключения к роботу или `Ctrl+Shift+K` / `Cmd+Shift+K` для подключения к симулятору.
:::

## 5. Визуализируйте данные телеметрии

### Линейный график

📉 [Линейный график](/tab-reference/line-graph) — это вкладка по умолчанию в AdvantageScope, обеспечивающая построение графиков числовых и дискретных значений в реальном времени.

1. Посмотрите в левой боковой панели раздел `Telemetry` > `SineWave`.
2. Перетащите `Value` в область «Левая ось» на панели управления.
3. Перетащите `Low` в область «Дискретные поля» на панели управления.
4. Нажмите на три точки рядом с «Дискретные поля» и выберите «Показывать режим робота».

Вы увидите, как синусоида и состояние робота обновляются в реальном времени по мере поступления данных!

:::info Работа с графиком

- **Пауза / Просмотр истории:** Прокрутите горизонтально или нажмите и перетащите мышью по графику, чтобы посмотреть прошлые данные. Красная стрелка в правом верхнем углу указывает на то, что автоматическая прокрутка в реальном времени приостановлена. Нажмите на стрелку или клавишу `L`, чтобы переключить автопрокрутку.
- **Масштабирование:** Прокрутите колесо мыши вверх/вниз над графиком или удерживайте `Shift` при перетаскивании, чтобы приблизить определённый временной интервал.
- **Просмотр значений:** Нажмите в любом месте графика, чтобы установить курсор времени и увидеть точные значения в легенде.
  :::

### Таблица

Вкладка 🔢 [Таблица](/tab-reference/table) отображает хронологическую таблицу изменений состояний и значений, что идеально подходит для диагностики переходов и последовательностей событий.

1. Нажмите кнопку **+** на верхней панели вкладок и выберите **Таблица**.
2. С боковой панели перетащите `NT:/Telemetry/SineWave/Value` и `NT:/Telemetry/Low` в область таблицы.
3. Новая строка добавляется автоматически каждый раз, когда любое отображаемое поле изменяет своё значение.
4. Нажмите на любую строку, чтобы мгновенно переключить все открытые вкладки к этому точному моменту времени!

:::tip
Вкладки можно переставлять и переименовывать с помощью панели вкладок. Нажмите кнопку окна в строке заголовка, чтобы открыть вкладку в отдельном окне и просматривать несколько вкладок рядом.
:::

### Статистика

Вкладка 📊 [Статистика](/tab-reference/statistics) отображает гистограмму числовых значений, позволяя подробно изучить данные одного или нескольких полей.

1. Нажмите кнопку **+** на верхней панели вкладок и выберите **Статистика**.
2. С боковой панели перетащите `NT:/Telemetry/SineWave/Value` в раздел «Измерения».
3. Установите «Диапазон данных» на `-1` и `1`, а «Размер шага» — на `0.1`.
4. Изучите данные с помощью гистограммы и сводной статистики.
5. Прокрутите шкалу времени вверху, чтобы настроить диапазон включаемых данных.

## 6. Скачайте и откройте файлы логов

После тестирования или проведения матча Вы можете скачать файлы `.wpilog` с робота для последующего анализа данных:

1. В строке меню выберите `Файл` > `Скачать логи...`.
2. AdvantageScope подключится к роботу и покажет список всех записанных файлов логов (самые новые вверху).
3. Выберите файл(ы) лога, которые хотите изучить, нажмите значок скачивания (↓) и выберите папку на компьютере.
4. Откройте скачанный файл через `Файл` > `Открыть лог(и)...` или перетащив файл `.wpilog` прямо в AdvantageScope.

<img src="/img/overview/log-files/open-file-2.webp" alt="Окно загрузки, отображающее доступные файлы WPILOG в памяти робота." height="350" />
