# Экспорт данных лога {#exporting-log-data}

AdvantageScope включает гибкую систему экспорта данных логов в виде файлов CSV, WPILOG или MCAP. Функции экспорта работают как при просмотре файла лога, так и при подключении к источнику данных в реальном времени. Возможные варианты использования включают:

- Преобразование файла WPILOG в CSV или MCAP для анализа в других приложениях.
- Экспорт файла WPILOG на основе данных NetworkTables для последующего доступа.
- Сохранение WPILOG с ограниченным количеством полей (и удаленными повторяющимися значениями) для уменьшения размера файла.

Чтобы просмотреть опции экспорта, нажмите **Файл > Экспортировать данные...**.

:::tip
В дополнение к полному экспорту лога, описанному здесь, вкладка 💬 [Консоль](/tab-reference/console) позволяет экспортировать данные консоли в текстовый файл.
:::

:::warning
**Экспорт данных для SysId**

Мы не рекомендуем использовать эту функцию для экспорта данных логов, **сгенерированных в симуляции**, для использования в [SysId](https://docs.wpilib.org/en/stable/docs/software/advanced-controls/system-identification/introduction.html), поскольку SysId требует дополнительных данных меток времени, несовместимых с опциями экспорта AdvantageScope по умолчанию. Обратите внимание, что данные логов, **сгенерированные _вне_ симуляции**, могут быть экспортированы для использования в SysId с минимальными потерями данных (хотя максимальная точность может быть достигнута использованием _оригинального_ лога данных непосредственно в SysId).

_Это предупреждение **не относится** к логам, созданным AdvantageKit, которые могут быть экспортированы без потери данных путем выбора опции «Циклы AdvantageKit». Подробности см. на [этой странице](https://docs.advantagekit.org/data-flow/sysid-compatibility)._
:::

## Опции {#options}

При экспорте предоставляются следующие опции:

- **Формат:** Задает общий формат экспортируемого файла. См. опции ниже.
  - _CSV (таблица):_ Значения, разделенные запятыми, где каждая строка представляет отдельную метку времени, а каждый столбец представляет поле (плюс столбец для значения метки времени). Каждая строка может представлять значение в нескольких полях.
  - _CSV (список):_ Значения, разделенные запятыми, где каждая строка представляет значение в одном поле со столбцами для метки времени, ключа и значения.
  - _WPILOG:_ Стандартный файл WPILOG, который можно снова открыть в AdvantageScope.
  - _MCAP:_ Стандартный файл [MCAP](https://mcap.dev), который можно открыть в [Foxglove](https://foxglove.dev).
- **Метки времени:** Только для «CSV (таблица)». Задает метод создания новых строк. См. опции ниже.
  - _Все изменения:_ Создавать новые строки/записи только при обновлении значений полей. Минимизирует размер файла экспорта.
  - _Фиксированный период:_ Создавать новые строки/записи через фиксированный интервал, полезно для логов без синхронизации меток времени (когда многие поля записываются с похожими, но не идентичными метками времени). Обратите внимание, что включаются все значения, независимо от того, было ли изменение между точками выборки.
  - _Циклы AdvantageKit:_ Создавать новую строку/запись для каждого синхронизированного цикла AdvantageKit. Обратите внимание, что включаются все значения, независимо от того, было ли изменение между циклами.
- **Период:** Только если выбран «Фиксированный период». Задает период в миллисекундах между каждой выборкой. Обычно он должен соответствовать периоду цикла кода робота.
- **Префиксы:** Если пусто, включаются все поля. В противном случае включаются только поля, соответствующие предоставленным префиксам (разделенным запятыми). См. примеры ниже.
  - «_/DriverStation/Joystick0_»: Включить все поля, начинающиеся с «/DriverStation/Joystick0» (данные с первого джойстика).
  - «_Flywheels,DS:enabled_»: Включить все поля, начинающиеся с «/Flywheels» или «DS:enabled» (все данные маховика плюс статус включения робота).
  - «_Drive/LeftPosition,Drive/RightPosition_»: Включать только поля «/Drive/LeftPosition» и «/Drive/RightPosition».
- **Набор полей:** См. опции ниже. Сгенерированные поля создаются AdvantageScope для разбиения сложных типов и отображаются серым текстом на боковой панели. Сюда входят отдельные компоненты массивов, структур и других схем.
  - _Включить сгенерированные:_ Экспортировать все просматриваемые поля, включая сгенерированные поля. Рекомендуется, если экспортированные данные будут открываться в приложении, неспособном разбирать сложные типы.
  - _Только оригинальные:_ Экспортировать только поля, присутствовавшие в оригинальном файле лога, исключая сгенерированные поля. Рекомендуется, если экспортированные данные будут открываться в AdvantageScope или другом приложении, способном разбирать сложные типы.
