# Экспорт данных лога {#exporting-log-data}

AdvantageScope включает гибкую систему экспорта данных логов в виде файлов CSV, WPILOG или MCAP. Функции экспорта работают как при просмотре файла лога, так и при подключении к источнику данных в реальном времени. Возможные сценарии использования включают:

- Преобразование файла WPILOG в CSV или MCAP для анализа в других приложениях.
- Экспорт файла WPILOG на основе данных NetworkTables для последующего анализа.
- Сохранение WPILOG с ограниченным набором полей (и удалёнными повторяющимися значениями) для уменьшения размера файла.

Чтобы просмотреть параметры экспорта, нажмите **Файл > Экспортировать данные...**.

:::warning
**Экспорт данных для SysId**

Мы не рекомендуем использовать эту функцию для экспорта данных логов, **полученных в симуляции**, для использования в [SysId](https://docs.wpilib.org/en/stable/docs/software/advanced-controls/system-identification/introduction.html), поскольку SysId требует дополнительных данных меток времени, несовместимых с параметрами экспорта AdvantageScope по умолчанию. Обратите внимание, что данные логов, **полученные _вне_ симуляции**, можно экспортировать для использования в SysId с минимальными потерями данных (хотя максимальная точность достигается при использовании _исходного_ лога напрямую в SysId).

_Это предупреждение **не относится** к логам, созданным AdvantageKit, которые можно экспортировать без потери данных путём выбора опции «Циклы AdvantageKit». Подробности см. на [этой странице](https://docs.advantagekit.org/data-flow/sysid-compatibility)._
:::

## Опции {#options}

При экспорте доступны следующие параметры:

- **Формат:** Задаёт общий формат экспортируемого файла. См. варианты ниже.
  - _CSV (таблица):_ Значения, разделённые запятыми, где каждая строка соответствует отдельной метке времени, а каждый столбец — полю (плюс столбец для значения метки времени). Каждая строка может содержать значения нескольких полей.
  - _CSV (список):_ Значения, разделённые запятыми, где каждая строка соответствует значению одного поля со столбцами для метки времени, ключа и значения.
  - _WPILOG:_ Стандартный файл WPILOG, который можно снова открыть в AdvantageScope.
  - _MCAP:_ Стандартный файл [MCAP](https://mcap.dev), который можно открыть в [Foxglove](https://foxglove.dev).
- **Метки времени:** Только для «CSV (таблица)». Задаёт метод создания новых строк. См. варианты ниже.
  - _Все изменения:_ Создавать новые строки/записи только при обновлении значений полей. Минимизирует размер экспортируемого файла.
  - _Фиксированный период:_ Создавать новые строки/записи через фиксированный интервал, что полезно для логов без синхронизации меток времени (когда многие поля записываются с близкими, но не идентичными метками времени). Обратите внимание, что включаются все значения, независимо от того, изменились ли они между точками выборки.
  - _Циклы AdvantageKit:_ Создавать новую строку/запись для каждого синхронизированного цикла AdvantageKit. Обратите внимание, что включаются все значения, независимо от того, изменились ли они между циклами.
- **Период:** Только если выбран «Фиксированный период». Задаёт период в миллисекундах между выборками. Обычно он должен соответствовать периоду цикла кода робота.
- **Префиксы:** Если поле оставлено пустым, включаются все поля. В противном случае включаются только поля, соответствующие указанным префиксам (разделённым запятыми). См. примеры ниже.
  - «_/DriverStation/Joystick0_»: Включить все поля, начинающиеся с «/DriverStation/Joystick0» (данные с первого джойстика).
  - «_Flywheels,DS:enabled_»: Включить все поля, начинающиеся с «/Flywheels» или «DS:enabled» (все данные маховика плюс статус включения робота).
  - «_Drive/LeftPosition,Drive/RightPosition_»: Включить только поля «/Drive/LeftPosition» и «/Drive/RightPosition».
- **Набор полей:** См. варианты ниже. Сгенерированные поля создаются AdvantageScope для разбиения сложных типов и отображаются серым текстом на боковой панели. Сюда входят отдельные компоненты массивов, структур и других схем.
  - _Включить сгенерированные:_ Экспортировать все просматриваемые поля, включая сгенерированные. Рекомендуется, если экспортированные данные будут открываться в приложении, не умеющем разбирать сложные типы.
  - _Только исходные:_ Экспортировать только поля, присутствовавшие в исходном файле лога, исключая сгенерированные. Рекомендуется, если экспортированные данные будут открываться в AdvantageScope или другом приложении, способном разбирать сложные типы.
