# 🛜 Источники реального времени

Все визуализации в AdvantageScope разработаны для приема данных в реальном времени от робота или симулятора в дополнение к файлам логов. В этом разделе описывается, как подключаться к источникам данных в реальном времени. AdvantageScope поддерживает следующие источники данных в реальном времени:

- **NetworkTables:** Это основной сетевой протокол WPILib. См. [документацию WPILib](https://docs.wpilib.org/en/stable/docs/software/networktables/index.html) для получения более подробной информации.
- **NetworkTables (AdvantageKit):** Этот режим разработан для использования с кодом робота, запускающим AdvantageKit, который публикует в таблицу `AdvantageKit` в NetworkTables.
- **Диагностика Systemcore:** Этот режим подключается к встроенному серверу NetworkTables, используемому ОС Systemcore, который включает диагностические данные, такие как состояние робота и ввод-вывод устройств.
- **Диагностика Phoenix:** Этот режим использует HTTP для подключения к [диагностическому серверу](https://pro.docs.ctr-electronics.com/en/latest/docs/troubleshooting/running-diagnostics.html) Phoenix, что позволяет осуществлять потоковую передачу данных с CAN-устройств CTRE с помощью [Phoenix 6](https://pro.docs.ctr-electronics.com/en/latest/). Это похоже на [функцию построения графиков](https://pro.docs.ctr-electronics.com/en/latest/docs/tuner/plotting.html) в Phoenix Tuner. См. [эту страницу](/overview/live-sources/phoenix-diagnostics) для получения дополнительной информации.
- **Сервер RLOG:** Этот протокол поддерживается AdvantageKit в качестве альтернативы NetworkTables. Соединение инициируется по порту 5800 по умолчанию.
- **FTC Dashboard:** Этот режим интегрируется с роботами FTC, публикующими данные в [FTC Dashboard](https://acmerobotics.github.io/ftc-dashboard).

:::info
AdvantageScope может подключаться к FIRST Driver Station для просмотра диагностических данных при запуске на том же устройстве, что и приложение DS. Конфигурация не требуется (см. инструкции ниже).
:::

## Запуск подключения

Чтобы запустить подключение в реальном времени, выполните следующие шаги:

- **Робот:** Нажмите **Файл > Подключиться к роботу > По умолчанию** или конкретный источник в реальном времени
- **Симулятор:** Нажмите **Файл > Подключиться к симулятору > По умолчанию** или конкретный источник в реальном времени
- **Driver Station:** Нажмите **Файл > Подключиться к Driver Station**

В заголовке окна отображается IP-адрес и текст «Поиск», пока цель не подключена. AdvantageScope пытается автоматически переподключиться, используя те же настройки после отключения.

## Просмотр данных в реальном времени

При подключении к источнику в реальном времени AdvantageScope по умолчанию привязывает все вкладки к текущему времени. Виды, такие как 📉 [Линейный график](/tab-reference/line-graph) и 🔢 [Таблица](/tab-reference/table), автоматически прокручиваются, а виды, такие как поле и джойстики, отображают текущие значения каждого поля. Нажатие красной кнопки со стрелкой на панели навигации переключает эту привязку, позволяя просматривать и воспроизводить прошлые данные.

<img src="/img/overview/live-sources/open-live-1.png" alt="Live lock/unlock button" />

:::tip
Прокрутка влево на линейном графике или шкале времени отвязывает от текущего времени, а прокрутка до упора вправо снова привязывает к текущему времени.
:::

## Конфигурация

Откройте окно настроек, нажав **Приложение > Показать настройки...** (Windows/Linux) или **AdvantageScope > Настройки...** (macOS).

<img src="/img/prefs.png" alt="Diagram of preferences" height="350" />

### Адрес робота

Введите адрес робота, используя IP-адрес вида 10.TE.AM.2, как описано в [документации WPILib](https://docs.wpilib.org/en/stable/docs/networking/networking-introduction/ip-configurations.html#te-am-ip-notation). При подключении к Systemcore через USB или встроенную точку доступа Wi-Fi нажмите **Файл > Использовать USB-адрес Systemcore** / **Использовать Wi-Fi-адрес Systemcore**, чтобы временно использовать правильный статический IP-адрес.

### Режим реального времени

Когда NetworkTables используется в качестве источника в реальном времени, можно выбрать следующие режимы в реальном времени:

- **Низкая пропускная способность (по умолчанию):** AdvantageScope запрашивает данные у сервера только для полей, которые активно используются. Данные, опубликованные до выбора поля, будут недоступны. Этот режим **настоятельно рекомендуется** при работе в среде с ограниченной пропускной способностью сети или при публикации большого количества полей.
- **Логирование:** AdvantageScope запрашивает данные для всех полей независимо от того, используются ли они активно. Это означает, что поля можно просматривать задним числом, приостановив поток данных в реальном времени (см. ниже). Этот режим часто полезен во время разработки, но **НЕ должен использоваться при ограниченной пропускной способности**.

### История реального времени

Во время подключения в реальном времени данные сохраняются локально для воспроизведения прошлых данных (см. «Просмотр данных в реальном времени» выше). Чтобы избежать очень высокого использования памяти, данные отбрасываются через 20 минут по умолчанию. Можно выбрать более короткий период для уменьшения использования памяти или выберите «Никогда» для бессрочного хранения данных в реальном времени.
