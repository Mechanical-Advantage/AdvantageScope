# Диагностика Phoenix {#phoenix-diagnostics}

AdvantageScope поддерживает потоковую передачу сигналов в реальном времени с устройств Phoenix 6 **без необходимости настройки в пользовательском коде**. Это позволяет легко отлаживать и настраивать устройства Phoenix, используя знакомый интерфейс и все возможности AdvantageScope:

- Гибкие параметры визуализации, включая поддержку таблиц и статистического анализа
- Полная поддержка построения графиков с учётом единиц измерения, включая неявное преобразование и преобразование в один клик ([документация](/tab-reference/line-graph/units))
- Расшифровка значений enum в виде понятных человеку строк (режимы управления, статус моста, состояние магнита CANcoder и т. д.)
- Встроенные всплывающие подсказки на боковой панели с описаниями и единицами измерения для каждого сигнала
- Иерархическая организация сигналов, сгруппированных по шине CAN, устройству и типу сигнала
- Расширенный анализ данных со встроенными функциями интегрирования и дифференцирования ([документация](/tab-reference/line-graph/#adjusting-axes))

:::tip
Для подключения выберите «Диагностика Phoenix» при подключении к роботу или симулятору из панели меню.
:::
