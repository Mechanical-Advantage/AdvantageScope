# Диагностика Phoenix

AdvantageScope поддерживает потоковую передачу сигналов в реальном времени с устройств Phoenix 6 **без необходимости настройки в пользовательском коде**. Это позволяет легко отлаживать и настраивать устройства Phoenix, используя знакомый интерфейс и полную мощность AdvantageScope:

- Гибкие опции визуализации, включая поддержку нескольких осей и дискретных полей
- Полная поддержка построения графиков с учетом единиц измерения, включая неявное и однощелчковое преобразование единиц ([документация](/tab-reference/line-graph/units))
- Предварительный просмотр всех значений в реальном времени на боковой панели для удобного просмотра
- Поддержка построения графиков и предварительного просмотра сигналов от нескольких устройств одновременно
- Декодирование значений enum в виде читаемых человеком строк (режимы управления, статус моста, состояние магнита CANcoder и т. д.)
- Встроенные всплывающие подсказки на боковой панели с описаниями и единицами измерения для каждого сигнала
- Иерархическая организация сигналов, сгруппированных по шине CAN, устройству и типу сигнала
- Расширенный анализ данных с встроенными опциями интегрирования и дифференцирования ([документация](/tab-reference/line-graph/#adjusting-axes))

:::tip
Для подключения выберите «Диагностика Phoenix» при подключении к роботу или симулятору из панели меню.
:::
