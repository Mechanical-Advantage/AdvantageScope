# Публикация данных NetworkTables {#publishing-networktables-data}

AdvantageScope поддерживает публикацию данных NetworkTables, сохранённых в файле лога, обратно на сервер NetworkTables (например, в симулятор или на робот). Возможные сценарии использования включают:

- Воспроизведение матчей в симуляции для отладки.
- Имитация данных с сопроцессора на реальном роботе.
- Отладка панелей управления (дашбордов) оператора на реалистичных данных матча.

Для этой функции требуется файл лога с полной записью данных NetworkTables, который можно создать с помощью встроенного [логгера данных](https://docs.wpilib.org/en/stable/docs/software/telemetry/datalog.html) WPILib. Обратите внимание, что AdvantageKit не поддерживает эту функцию, так как вместо этого обеспечивает более полное детерминированное воспроизведение в симуляции.

## Начало работы {#getting-started}

Чтобы начать публикацию, откройте файл лога, содержащий данные NetworkTables, затем выполните следующие действия:

- **Публикация на робот:** Нажмите **Файл > Опубликовать данные NT > Подключиться к роботу**.
- **Публикация в симулятор:** Нажмите **Файл > Опубликовать данные NT > Подключиться к симулятору**.

В заголовке окна отображается текст «Поиск» или «Публикация», показывающий текущий статус. При разрыве соединения AdvantageScope пытается автоматически переподключиться с теми же настройками.

Все поля публикуются с использованием их сохранённых значений на _выбранной метке времени_, которая используется на многих вкладках AdvantageScope. Это позволяет воспроизводить данные по сети в реальном времени тем же способом, что и внутри AdvantageScope (подробнее см. в разделе [Навигация по приложению](/overview/navigation)). Если метка времени не выбрана, поля публикуются с использованием их сохранённых значений на _метке времени при наведении_.

Чтобы остановить публикацию, нажмите **Файл > Опубликовать данные NT > Остановить публикацию**.

## Фильтрация полей {#filtering-fields}

По умолчанию AdvantageScope публикует все поля NetworkTables, сохранённые в файле лога (за исключением мета-топиков, опубликованных сервером). Некоторые сценарии, такие как имитация сопроцессора, требуют публикации только ограниченного набора полей или подтаблиц. Чтобы настроить набор разрешённых префиксов полей, откройте окно настроек, нажав **Приложение > Показать настройки...** (Windows/Linux) или **AdvantageScope > Настройки...** (macOS).

Опция «Префиксы публикации NT» задаёт допустимые префиксы для полей, публикуемых в NetworkTables. Если оставить поле пустым, будут включены все поля. В противном случае можно указать список префиксов или полей, разделённых запятыми. См. примеры ниже.

- «_Telemetry_»: Включить все поля в таблице «Telemetry».
- «_Telemetry/Drive_»: Включить только таблицу «Telemetry/Drive».
- «_limelight/tx,limelight/ty_»: Включить только поля «limelight/tx» и «limelight/ty».

## Ограничения {#limitations}

:::warning

- Поля публикуются каждые 20 мс, поэтому данные NetworkTables, первоначально опубликованные с более высокой частотой, будут пропускать выборки.
- Метки времени опубликованных выборок не сохраняются. Это было бы невозможно при перемотке назад и вперёд во времени или воспроизведении с разной скоростью.
  :::
