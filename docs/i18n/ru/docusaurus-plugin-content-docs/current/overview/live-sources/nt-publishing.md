# Публикация данных NetworkTables {#publishing-networktables-data}

AdvantageScope поддерживает публикацию данных NetworkTables, сохраненных в файле лога, обратно на сервер NetworkTables, такой как симулятор или робот. Возможные варианты использования включают:

- Повторное воспроизведение матчей в симуляции для отладки.
- Имитация данных с сопроцессора на реальном роботе.
- Отладка приложений дашборда водителя с использованием реалистичных данных матча.

Эта функция требует файла лога с полным захватом данных NetworkTables, который может быть сгенерирован с использованием встроенного [логирования данных](https://docs.wpilib.org/en/stable/docs/software/telemetry/datalog.html) WPILib. Обратите внимание, что AdvantageKit не поддерживает эту функцию, так как вместо этого он обеспечивает более полное детерминированное повторное воспроизведение в симуляции.

## Начало работы {#getting-started}

Чтобы начать публикацию, должен быть открыт файл лога, содержащий данные NetworkTables. Затем выполните следующие шаги:

- **Публикация на робот:** Нажмите **Файл > Опубликовать данные NT > Подключиться к роботу**.
- **Публикация в симулятор:** Нажмите **Файл > Опубликовать данные NT > Подключиться к симулятору**.

В верхней части окна отображается текст «Поиск» или «Публикация» для индикации статуса публикации данных. AdvantageScope пытается автоматически переподключиться, используя те же настройки после отключения.

Все поля будут публиковаться с использованием их сохраненных значений на _выбранной метке времени_, используемой многими вкладками AdvantageScope. Это позволяет осуществлять сетевое воспроизведение в реальном времени через тот же механизм, что и воспроизведение внутри AdvantageScope. См. [Навигация по приложению](/overview/navigation) для получения более подробной информации. Если метка времени не выбрана, поля публикуются с использованием их сохраненных значений на _метке времени при наведении_.

Чтобы остановить публикацию, нажмите **Файл > Опубликовать данные NT > Остановить публикацию**.

## Фильтрация полей {#filtering-fields}

По умолчанию AdvantageScope публикует все поля NetworkTables, сохраненные в файле лога (за исключением мета-топиков, опубликованных сервером). Некоторые варианты использования, такие как имитация сопроцессора, требуют публикации только ограниченного набора полей или подтаблиц. Чтобы настроить набор разрешенных префиксов полей, откройте окно настроек, нажав **Приложение > Показать настройки...** (Windows/Linux) или **AdvantageScope > Настройки...** (macOS).

Опция «Префиксы публикации NT» задает допустимые префиксы для полей, публикуемых в NetworkTables. Если оставить поле пустым, будут включены все поля. В противном случае может быть предоставлен список префиксов или полей, разделенных запятыми. См. примеры ниже.

- «_SmartDashboard_»: Включить все поля в таблице «SmartDashboard».
- «_SmartDashboard/Auto Selector_»: Включить только таблицу «SmartDashboard/Auto Selector».
- «_limelight/tx,limelight/ty_»: Включить только поля «limelight/tx» и «limelight/ty».

## Ограничения {#limitations}

:::warning

- Поля публикуются каждые 20 мс, поэтому данные NetworkTables, первоначально опубликованные с более высокой частотой, будут пропускать выборки.
- Метки времени опубликованных выборок не сохраняются. Это было бы невозможно при перемотке назад и вперед во времени или воспроизведении с разной скоростью.
  :::
