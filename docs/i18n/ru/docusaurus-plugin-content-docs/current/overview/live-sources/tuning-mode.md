# Режим настройки

Некоторые источники в реальном времени поддерживают настройку числовых и логических значений в реальном времени. Например, эта функция может быть использована для [настройки коэффициентов регулятора](https://docs.wpilib.org/en/stable/docs/software/advanced-controls/introduction/tutorial-intro.html) при подключении к источнику NetworkTables. Обратите внимание, что код робота должен поддерживать получение коэффициентов через NetworkTables.

По умолчанию все значения в AdvantageScope предназначены только для чтения. Чтобы переключить режим настройки, **нажмите иконку ползунка** справа от строки поиска при подключении к поддерживаемому источнику в реальном времени. Когда иконка фиолетовая, режим настройки активен и редактирование полей включено.

- Чтобы отредактировать **числовое поле**, введите новое значение в текстовое поле справа от поля на боковой панели. Значение публикуется после снятия выделения с ввода или нажатия клавиши «Enter». Оставьте текстовое поле пустым, чтобы использовать значение, опубликованное роботом.
- Чтобы переключить **логическое поле**, нажмите на красный или зеленый круг справа от поля на боковой панели.

:::warning
Эта функция не предназначена для управления роботом на поле. Вводы в стиле дашборда, такие как селекторы (choosers), кнопки запуска и т. д., не поддерживаются.
:::

## Настройка с AdvantageKit

Поля, опубликованные AdvantageKit в подтаблицу `AdvantageKit`, предназначены только для вывода и не могут редактироваться. Однако пользователи могут публиковать поля из пользовательского кода, которые настраиваются из AdvantageScope. **Любые поля, опубликованные в таблицу "/Tuning" в NetworkTables, будут отображаться в таблице "Tuning" при использовании источника в реальном времени "NetworkTables (AdvantageKit)".**

Например, настраиваемое число может быть опубликовано с использованием класса [`LoggedNetworkNumber`](https://docs.advantagekit.org/data-flow/recording-inputs/dashboard-inputs):

```java
LoggedNetworkNumber tunableNumber = new LoggedNetworkNumber("/Tuning/MyTunableNumber", 0.0);
```

:::warning
Подтаблица `NetworkInputs` **не может редактироваться**, так как она используется AdvantageKit для записи сетевых значений для логирования и повторного воспроизведения. Используйте таблицу `Tuning` для взаимодействия с сетевыми вводами в реальном времени.
:::
