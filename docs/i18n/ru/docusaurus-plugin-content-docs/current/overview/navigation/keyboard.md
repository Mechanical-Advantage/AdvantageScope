# Горячие клавиши {#keyboard-shortcuts}

AdvantageScope включает множество горячих клавиш, обеспечивающих более быструю навигацию. Сочетания клавиш, использующие клавишу `ctrl`, заменяются клавишей ⌘ на macOS.

### Источники данных {#data-sources}

<table>
<tr><td>`Ctrl+O`</td><td>Открыть один или несколько файлов логов</td></tr>
<tr><td>`Ctrl+Shift+O`</td><td>Добавить один или несколько файлов логов к текущей визуализации</td></tr>
<tr><td>`Ctrl+K`</td><td>Подключиться к роботу в качестве источника в реальном времени</td></tr>
<tr><td>`Ctrl+Shift+K`</td><td>Подключиться к симулятору в качестве источника в реальном времени</td></tr>
<tr><td>`Ctrl+Option+Shift+K`</td><td>Подключиться к Driver Station в качестве источника в реальном времени</td></tr>
<tr><td>`Ctrl+D`</td><td>Скачать файлы логов с робота</td></tr>
</table>

### Экспорт данных {#data-export}

<table>
<tr><td>`Ctrl+E`</td><td>Экспортировать данные лога</td></tr>
<tr><td>`Ctrl+P`</td><td>Опубликовать данные лога на сервере NetworkTables на роботе</td></tr>
<tr><td>`Ctrl+Shift+P`</td><td>Опубликовать данные лога на сервере NetworkTables в симуляции</td></tr>
<tr><td>`Option+Ctrl+P`</td><td>Остановить публикацию в NetworkTables</td></tr>
</table>

</table>

### Управление вкладками {#tab-controls}

<table>
<tr><td>`Ctrl+T`</td><td>Открыть выпадающий список для добавления новой вкладки</td></tr>
<tr><td>`Ctrl+Shift+T`</td><td>Создать новое открепленное окно для текущей вкладки</td></tr>
<tr><td>`Ctrl+Влево` и `Ctrl+Вправо`</td><td>Переключить вкладки</td></tr>
<tr><td>`Ctrl+[` и `Ctrl+]`</td><td>Переупорядочить вкладки</td></tr>
<tr><td>`Ctrl+W`</td><td>Закрыть текущую вкладку</td></tr>
</table>
