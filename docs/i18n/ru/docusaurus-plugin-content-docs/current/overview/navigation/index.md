## Боковая панель

Слева находится боковая панель со списком доступных таблиц и полей. Выбираемые поля показаны _курсивом_, а встроенные таблицы (из WPILib или AdvantageKit) <u>подчеркнуты</u>. Нажмите стрелку, чтобы развернуть вложенные таблицы. **Перетащите одно поле**, чтобы выбрать его, или **удерживайте cmd/ctrl**, чтобы выбрать коллекцию полей, нажимая на каждое из них. Начните перетаскивание коллекции полей, чтобы завершить выбор.

Чтобы найти поле, начните вводить текст в поле поиска. Отобразится выпадающий список полей, затем выбранное поле будет выделено на боковой панели и прокручено в поле зрения.

:::info
Нажмите и потяните за правый край, чтобы изменить размер или скрыть боковую панель. Двойной щелчок переключает видимость боковой панели.
:::

## Панель вкладок

Используйте панель вкладок (синюю) для переключения между различными видами. Эта документация доступна в любое время при нажатии на иконку 📖 слева. Чтобы экспортировать текущий макет вкладок (и связанные настройки), нажмите **Файл > Экспортировать макет...**. Чтобы импортировать макет из файла, нажмите **Файл > Импортировать макет...**

:::info
Вкладки можно переупорядочивать нажатием и перетаскиванием или переименовывать, щелкнув правой кнопкой мыши и выбрав **Переименовать вкладку**
:::

Кнопки навигации (зеленые) вверху управляют вкладками и воспроизведением.

- **Кнопка «Плюс»**: Открывает выпадающее меню для создания новой вкладки.
- **Кнопка «Окно»:** Создает новое открепленное окно с этой вкладкой. Эта функция может использоваться для одновременного просмотра данных из нескольких вкладок.
- **Кнопка «X»:** Закрывает текущую вкладку.
- **Кнопка «Воспроизвести»:** Запускает и останавливает воспроизведение в реальном времени. _Щелкните правой кнопкой мыши, чтобы изменить скорость воспроизведения или включить зацикливание._

## Панель просмотра

Панель просмотра — это место, где данные представляются для каждого типа вкладок. Ознакомьтесь со справочником вкладок для получения подробной информации о панели просмотра для каждой вкладки. Этот вид можно переместить в отдельное окно, нажав кнопку открепления на панели вкладок.

## Панель управления

Панель управления используется для выбора полей для визуализации и управления другими опциями. Ознакомьтесь со справочником вкладок для получения подробной информации об опциях, доступных для каждой вкладки.

:::info
Нажмите и потяните за верхний край, чтобы изменить размер или скрыть панель управления. Двойной щелчок переключает видимость панели управления.
:::
