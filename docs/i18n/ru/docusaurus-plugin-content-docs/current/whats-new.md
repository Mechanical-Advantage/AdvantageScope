## 🍋‍🟩 Совместимость с Systemcore {#systemcore-compatibility}

AdvantageScope 2027 создан для бесперебойной работы с новым контроллером робота Systemcore и WPILib 2027:

- Адрес робота по умолчанию теперь `robot.local`, что позволяет подключаться в реальном времени или скачивать логи без настройки номера команды. USB- и Wi-Fi-адреса Systemcore также можно выбрать из строки меню.
- [Загрузка логов](/overview/log-files#downloading-from-the-robot) теперь поддерживает SFTP для Systemcore наряду с устаревшей загрузкой логов roboRIO.
- Добавлена система координат [Центр/красные](/more-features/coordinate-systems#center-red), используемая на полях FRC начиная с 2027 года и на полях FTC начиная с сезона 2027–2028.
- Добавлена поддержка API `Telemetry` и `Tunables` из WPILib 2027, обновлены цвета предупреждений и добавлена новая [настройка отображения временных меток](/more-features/timestamps), чтобы временные метки Systemcore оставались легко читаемыми.
- Новый режим реального времени [Диагностика Systemcore](/overview/live-sources) подключается напрямую ко встроенному серверу NetworkTables на Systemcore для мониторинга состояния робота и аппаратного ввода-вывода без необходимости пользовательского кода.

## 🎮 FIRST Driver Station {#first-driver-station}

AdvantageScope тесно интегрируется с новой [FIRST Driver Station](https://docs.wpilib.org/en/latest/docs/software/firstdriverstation) для упрощения диагностики матчей:

- [AdvantageScope Lite](/more-features/advantagescope-lite) доступен непосредственно из меню настроек FIRST Driver Station для анализа файлов WPILOG, созданных DS.
- Используйте настольное приложение для потоковой передачи в реальном времени состояния матча, метрик связи, напряжения батареи и ввода с джойстиков из локальной Driver Station без какой-либо настройки.
- При открытии файла `.wpilog` от Driver Station на компьютере AdvantageScope предлагает открыть отдельное окно, предварительно настроенное с вкладками для вывода консоли, метрик связи, питания, загрузки ЦП и джойстиков ([документация](/overview/log-files#driver-station-layout)). Этот макет также используется по умолчанию в AdvantageScope Lite для Driver Station.
- Просматривайте логи консоли Driver Station на вкладке 💬 [Консоль](/tab-reference/console) с автоматической подсветкой предупреждений/ошибок и полной поддержкой [управляющих последовательностей ANSI](/tab-reference/console#ansi-formatting) (цвета и стили текста).

## 📱 AdvantageTune {#advantagetune}

AdvantageTune — это новое автономное приложение для iPhone и iPad, предоставляющее лёгкий мобильный интерфейс для настройки в дополнение к AdvantageScope. Вы можете просматривать и изменять топики [NetworkTables](https://docs.wpilib.org/en/stable/docs/software/networktables/index.html) в реальном времени (включая примитивы, массивы, структуры WPILib и Protobuf) прямо со своего телефона, что упрощает участие каждого в настройке кода робота.

И AdvantageTune, и AdvantageScope упрощают экспорт настроенных значений обратно в код робота с помощью кнопок для сохранения всех настроенных значений в текстовый файл для удобного обмена ([документация](/overview/live-sources/tuning-mode)).

## 🪐 Универсальное логирование WPILOG {#wpilog-universal-logging}

Благодаря [универсальному логированию](/more-features/universal-logging) один файл WPILOG теперь может служить универсальным контейнером для нескольких потоков и форматов логов, включая логи устройств от производителей, данные CSV и дочерние файлы WPILOG. Универсальное логирование заменяет URCL гибким подходом, не зависящим от производителя: данные из каждого источника автоматически синхронизируются и объединяются в единое дерево на боковой панели. Подробности о захвате логов производителей в AdvantageKit и WPILib (скоро появится) смотрите в [документации по универсальному логированию](/more-features/universal-logging#experimental-vendor-logging).

## 🗺️ Улучшения вкладок поля {#field-tab-improvements}

На вкладки 🗺️ [2D-поле](/tab-reference/2d-field) и 👀 [3D-поле](/tab-reference/3d-field) добавлено несколько улучшений удобства использования:

- Панорамируйте и масштабируйте 2D-поле, или нажмите правой кнопкой мыши, чтобы зафиксировать камеру для слежения за положением и вращением робота ([документация](/tab-reference/2d-field#camera-controls)).
- Добавлена возможность плавного затухания 2D- и 3D-призраков, если поля давно не обновлялись (полезно при отображении поз компьютерного зрения).
- Добавлены линии сетки плиток на 2D- и 3D-полях FTC для более удобной пространственной ориентации.
- AdvantageScope теперь запоминает, какое поле — FRC или FTC — использовалось последним при открытии новых вкладок 2D- или 3D-поля.

## 📉 Улучшения линейного графика {#line-graph-improvements}

📉 [Линейный график](/tab-reference/line-graph) и шкала времени получили ряд визуальных улучшений для более наглядного анализа:

- При включении «Показывать режим робота» теперь отображается цветная полоса для автономного, управляемого, служебного (utility) и отключённого периодов.
- Графики в виде точек автоматически масштабируют размер точек для лучшей видимости при любом уровне приближения.
- На линейном графике и шкале времени появляются полезные подсказки, помогающие новым пользователям освоить жесты прокрутки и масштабирования.
- Улучшена отрисовка и читаемость больших значений временных меток на осях шкалы времени и линейного графика.

## 🤝 Улучшения доступности {#accessibility-enhancements}

AdvantageScope 2027 включает несколько обновлений, повышающих доступность приложения:

- Добавлена навигация с клавиатуры по клавише Tab для всех полей ввода и описательные всплывающие подсказки для всех элементов управления в приложении.
- AdvantageScope теперь учитывает настройки операционной системы «уменьшение прозрачности» и «уменьшение движения».
- Логические индикаторы на боковой панели теперь различают состояния не только за счёт цвета.

## 🥔 Новые типы единиц измерения {#new-unit-types}

Функция [графиков с учётом единиц измерения](/tab-reference/line-graph/units) в AdvantageScope расширена дополнительными типами единиц и параметрами разбора:

- Мощность (ватты, лошадиные силы и т. д.)
- Отношения (безразмерные, проценты)
- Температура в кельвинах
- Энергия картофеля
- Британские варианты написания единиц (например, `metres`)
- Суффиксы для библиотеки единиц измерения WPILib

## 🧱 Улучшения стабильности {#stability-improvements}

Этот релиз включает множество исправлений ошибок, оптимизаций производительности и улучшений стабильности по всему приложению. Полный список можно найти в [журнале изменений](https://github.com/Mechanical-Advantage/AdvantageScope/releases), а основные моменты перечислены ниже:

- Официальные сборки для Windows теперь имеют цифровую подпись, что снижает частоту предупреждений SmartScreen при установке.
- Значительно повышена производительность загрузки и построения графиков логов, особенно при работе с логами Hoot (`.hoot`) и большими массивами структур.
- Исправлена обработка временных меток при просмотре логов AdvantageKit совместно с высокочастотными источниками данных.
- Улучшен алгоритм синхронизации временных меток нескольких логов при выравнивании логов из разных источников.
- Повышена надёжность подключения для [Диагностики Phoenix](/overview/live-sources/phoenix-diagnostics).
- Исправлены ошибки интерфейса со строкой меню в откреплённых окнах и всплывающим окном записи в [AdvantageScope XR](/tab-reference/3d-field/advantagescope-xr).
- Доработаны тексты и формулировки интерфейса по всему приложению для повышения ясности.
