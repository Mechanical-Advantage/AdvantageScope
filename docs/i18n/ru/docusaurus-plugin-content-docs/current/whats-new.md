## ✴️ Экспериментально: поддержка FTC {#ftc-support}

В рамках подготовки к полной поддержке Systemcore в сезоне 2027–2028 годов этот релиз добавляет несколько функций для улучшения совместимости с существующей системой управления FIRST Tech Challenge:

- Поля и модели роботов FTC на 🗺️ [2D-поле](/tab-reference/2d-field) и 👀 [3D-поле](/tab-reference/3d-field)
- Новые опции [системы координат](/more-features/coordinate-systems) для совместимости со [стандартными координатами FTC](https://ftc-docs.firstinspires.org/en/latest/game_specific_resources/field_coordinate_system/field-coordinate-system.html)
- Поддержка файлов логов [Road Runner](https://rr.brott.dev/docs/v1-0/installation/)
- Поддержка формата потоковой передачи в реальном времени [FTC Dashboard](https://github.com/acmerobotics/ftc-dashboard)

:::tip
Командам FTC следует проявлять осторожность при использовании экспериментального программного обеспечения во время официального сезона. Поддержка FTC в AdvantageScope всё ещё находится в активной разработке.
:::

Несколько сторонних библиотек логирования/телеметрии FTC поддерживают другие форматы, совместимые с AdvantageScope, такие как WPILOG и RLOG. Документацию по этим библиотекам можно найти в соответствующих проектах; разработчики AdvantageScope не рекламируют и не рекомендуют какое-либо конкретное решение для логирования FTC для использования с AdvantageScope.

:::info
AdvantageScope разработано для обеспечения наилучшего опыта при использовании совместно с фреймворком WPILib и сопутствующими инструментами логирования. Вы можете столкнуться с проблемами совместимости или ограниченными возможностями при использовании неофициальных решений для логирования.

Все функции AdvantageScope будут официально поддерживаться в FTC после перехода на Systemcore в сезоне 2027–2028 годов.
:::

## 🧮 Построение графиков с учётом единиц измерения {#unit-aware-graphing}

Вкладка 📉 [Линейный график](/tab-reference/line-graph/) была обновлена и теперь полностью учитывает единицы измерения. Это открывает несколько новых возможностей при построении графиков числовых полей:

- Точные обозначения осей Y и отображаемых значений
- Быстрое преобразование в совместимые единицы (без всплывающих окон)
- Неявное преобразование совместимых типов единиц в пределах одной оси
- Точное отображение [интегрированных и дифференцированных](/tab-reference/line-graph/#integration-and-differentiation) единиц

На скриншоте ниже показана работа всех этих функций. Обратите внимание, что левая ось включает поля с различными единицами угловой скорости, а правая ось включает значения, которые дифференцированы и отображаются в неродных единицах (градусах). Выбор единиц стал проще, чем когда-либо: параметры совместимых единиц интегрированы непосредственно в меню управления для каждой оси.

_Дополнительную информацию о поддержке единиц измерения можно найти в [документации](/tab-reference/line-graph/units)._

## 🏁 Более быстрое скачивание логов {#faster-log-downloads}

[Скачивание логов с roboRIO](/overview/log-files/#downloading-from-the-robot) теперь происходит в **2–4 раза быстрее**, чем в предыдущих релизах. Это достигается за счёт перехода на новый протокол (FTP), который позволяет roboRIO передавать данные логов с меньшими затратами ресурсов ЦП.

В таблице ниже показана измеренная скорость передачи в релизах AdvantageScope 2025 и 2026 годов при подключении через Ethernet (максимальная пропускная способность 100 Мбит/с). Обратите внимание, что на производительность релиза 2025 года сильно влияет нагрузка на ЦП roboRIO.

|                                                            | 2025 (SFTP) | 2026 (FTP) | Ускорение                                        |
| ---------------------------------------------------------- | ----------- | ---------- | ------------------------------------------------ |
| Высокая нагрузка на ЦП<br /><sub>Сложный код робота</sub>  | 25 Мбит/с   | 80 Мбит/с  | <span style={{fontSize: '24px'}}>**3.2x**</span> |
| Средняя нагрузка на ЦП<br /><sub>Обычный код робота</sub>  | 40 Мбит/с   | 90 Мбит/с  | <span style={{fontSize: '22px'}}>**2.3x**</span> |
| Минимальная нагрузка на ЦП<br /><sub>Без кода робота</sub> | 90 Мбит/с   | 95 Мбит/с  | <span style={{fontSize: '20px'}}>**1.1x**</span> |

## 📁 Скачивание логов из подпапок {#download-logs-from-subfolders}

Окно скачивания теперь поддерживает сохранение логов, хранящихся в подпапках. Каждую подпапку с логами можно скачать как группу, что обеспечивает оптимизированный подход для скачивания логов, сгенерированных релизом 2026 года CTRE [Signal Logger](https://v6.docs.ctr-electronics.com/en/stable/docs/api-reference/api-usage/signal-logging.html) (который использует подпапки в качестве обходного пути из-за невозможности сохранения данных в одном файле лога).

## 🌈 Новые опции визуализации {#new-visualization-options}

Несколько новых опций визуализации поддерживаются на 🗺️ [2D-поле](/tab-reference/2d-field) и 👀 [3D-поле](/tab-reference/3d-field):

- На 2D-поле теперь доступен более широкий выбор цветов бамперов робота, и каждый объект может быть настроен с использованием собственного цвета. Это обеспечивает большую гибкость при объединении призраков с несколькими объектами роботов.
- При [визуализации 2D-механизмов на 3D-поле](/tab-reference/3d-field/#2d-mechanisms) механизмы теперь можно размещать в плоскости YZ в дополнение к плоскости XZ. Это облегчает визуализацию сложных механизмов с движением по нескольким осям.
- 3D-поле теперь поддерживает опциональное сглаживание для улучшения качества рендеринга краёв.

## 🪵 Поддержка CAN-логов REV Robotics {#rev-robotics-can-log-support}

Теперь вы можете открывать файлы `.revlog`, созданные [`StatusLogger`](https://codedocs.revrobotics.com/java/com/revrobotics/util/statuslogger) от REV Robotics, непосредственно в AdvantageScope. Эти файлы записывают сигналы CAN от устройств Spark Max и Spark Flex, предлагая официальную альтернативу библиотеке [URCL](/more-features/urcl) от AdvantageScope.

И URCL, и официальный `StatusLogger` останутся доступными в течение сезона 2026 года для обеспечения плавного перехода и сохранения функционального паритета с предыдущими сезонами. Позже мы поделимся более подробной информацией о вариантах логирования в 2027 году и далее.

## 📋 Упрощённые меню {#streamlined-menus}

Панель меню и связанные с ней элементы управления были упрощены и реорганизованы, чтобы сделать элементы управления более доступными и единообразными на всех платформах. Среди заметных функций:

- Щелчок правой кнопкой мыши по боковой панели для быстрого копирования имени поля (или полного ключа поля).
- Реорганизация окна настроек, что облегчает быстрый поиск опций.

## 🐛 Улучшения стабильности {#stability-improvements}

Этот релиз включает различные исправления ошибок и улучшения стабильности по всему приложению. Полный список можно найти в [списке изменений](https://github.com/Mechanical-Advantage/AdvantageScope/releases) релиза, но некоторые наиболее заметные исправления приведены ниже:

- Производительность AdvantageScope при потоковой передаче данных в течение длительного времени была значительно улучшена, особенно при использовании вкладки линейного графика.
- AdvantageScope теперь лучше справляется с нестандартными данными логов, включая файлы логов большого размера и большие значения полей.
- Исправлены различные визуальные сбои при просмотре данных логов, особенно при использовании фильтров на вкладке линейного графика.
- Исправлен порядок файлов логов AdvantageKit в окне скачивания; логи без меток времени теперь находятся внизу списка, аналогично другим форматам.
- На вкладке 3D-поля камеры робота с ненулевым вращением по оси крена теперь визуализируются правильно.
- Стабильность AdvantageScope XR была улучшена, особенно при работе на iOS/iPadOS 26. Для автономных установок проверьте App Store на наличие доступных обновлений.
