# 📦 Instalação {#installation}

A versão com suporte oficial do AdvantageScope pode ser baixada diretamente da Equipe 6328 ou obtida pelo instalador da WPILib. Também existem várias distribuições não oficiais.

## Equipe 6328 {#team-6328}

### Downloads: [estável](https://github.com/Mechanical-Advantage/AdvantageScope/releases/latest), [pré-lançamento](https://github.com/Mechanical-Advantage/AdvantageScope/releases) {#6328-downloads}

Baixar o AdvantageScope diretamente da Equipe 6328 garante:

- Os recursos e correções de bugs mais recentes antes que cheguem a outros canais.
- Avisos dentro do próprio aplicativo sempre que houver uma atualização disponível.
- Uma coleção integrada de modelos de robôs recentes da 6328 para usar na guia 👀 [Campo 3D](/tab-reference/3d-field).

:::info
Cada versão principal do AdvantageScope é lançada em janeiro, antes do kickoff da FRC, com o número da versão correspondendo ao ano (por exemplo, a v26.0.0 foi lançada em janeiro de 2026). Nos meses que antecedem cada lançamento, também podem sair versões beta e alpha para equipes que queiram testar novos recursos e enviar feedback. **Equipes que usarem essas versões de pré-lançamento podem encontrar problemas e bugs que não existem nas versões estáveis.**
:::

## WPILib {#wpilib}

### Instalação: [Documentação da WPILib](https://docs.wpilib.org/pt/stable/docs/zero-to-robot/step-2/wpilib-setup.html) {#wpilib-installation}

O instalador da WPILib já inclui uma versão recente do AdvantageScope, mas ela pode estar um pouco desatualizada em relação ao lançamento mais recente disponível para download direto. Você encontra a documentação sobre como abrir o AdvantageScope pelo VS Code da WPILib [aqui](https://docs.wpilib.org/pt/stable/docs/software/dashboards/advantagescope.html).

## Distribuições não oficiais {#unofficial-distributions}

Existem distribuições não oficiais do AdvantageScope mantidas por terceiros, que não contam com suporte oficial dos desenvolvedores do AdvantageScope ou da WPILib. Elas também podem ficar desatualizadas em relação à versão mais recente dos canais oficiais. Se encontrar algum problema, entre em contato diretamente com os responsáveis por cada distribuição.

- [**AdvantageScope Lite para Sistema de controle REV:**](https://github.com/j5155/AdvantageScope-Lite-FTC) Uma modificação do [AdvantageScope Lite](/more-features/advantagescope-lite) feita para o sistema de controle atual do FTC (anterior ao Systemcore).
- [**Instalador Homebrew:**](https://formulae.brew.sh/cask/advantagescope) Um cask do Homebrew para instalar o AdvantageScope pela linha de comando no macOS.
- [**Arch User Repository (AUR):**](https://aur.archlinux.org/packages/advantagescope) Um método alternativo de distribuição para o gerenciador de pacotes pacman (também há uma distribuição oficial do AdvantageScope para Arch [aqui](#6328-downloads)).
