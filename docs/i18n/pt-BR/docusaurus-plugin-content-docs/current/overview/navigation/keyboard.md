# Atalhos de teclado {#keyboard-shortcuts}

O AdvantageScope conta com vários atalhos de teclado para agilizar a navegação. Nos atalhos que usam a tecla `ctrl`, ela é substituída pela tecla ⌘ no macOS.

### Fontes de dados {#data-sources}

<table>
<tr><td>`Ctrl+O`</td><td>Abrir um ou mais arquivos de log</td></tr>
<tr><td>`Ctrl+Shift+O`</td><td>Adicionar um ou mais arquivos de log à visualização atual</td></tr>
<tr><td>`Ctrl+K`</td><td>Conectar ao robô como fonte ao vivo</td></tr>
<tr><td>`Ctrl+Shift+K`</td><td>Conectar ao simulador como fonte ao vivo</td></tr>
<tr><td>`Ctrl+Option+Shift+K`</td><td>Conectar à Driver Station como fonte ao vivo</td></tr>
<tr><td>`Ctrl+D`</td><td>Baixar arquivos de log do robô</td></tr>
</table>

### Exportação de dados {#data-export}

<table>
<tr><td>`Ctrl+E`</td><td>Exportar dados do log</td></tr>
<tr><td>`Ctrl+P`</td><td>Publicar dados do log em um servidor NetworkTables no robô</td></tr>
<tr><td>`Ctrl+Shift+P`</td><td>Publicar dados do log em um servidor NetworkTables em simulação</td></tr>
<tr><td>`Option+Ctrl+P`</td><td>Parar de publicar no NetworkTables</td></tr>
</table>

### Controles de janela {#window-controls}

<table>
<tr><td>`Ctrl+N`</td><td>Criar nova janela</td></tr>
<tr><td>`Ctrl+Shift+N`</td><td>Fechar janela atual</td></tr>
<tr><td>`Ctrl+Vírgula`</td><td>Abrir janela de preferências</td></tr>
<tr><td>`Ctrl+Ponto`</td><td>Mostrar ou ocultar barra lateral</td></tr>
<tr><td>`Ctrl+Barra`</td><td>Mostrar ou ocultar painel de controle</td></tr>
</table>

### Controles de guias {#tab-controls}

<table>
<tr><td>`Ctrl+T`</td><td>Abrir menu suspenso para adicionar nova guia</td></tr>
<tr><td>`Ctrl+Shift+T`</td><td>Destacar guia atual em uma nova janela</td></tr>
<tr><td>`Ctrl+Esquerda` e `Ctrl+Direita`</td><td>Alternar entre guias</td></tr>
<tr><td>`Ctrl+[` e `Ctrl+]`</td><td>Reorganizar guias</td></tr>
<tr><td>`Ctrl+W`</td><td>Fechar guia atual</td></tr>
</table>

### Reprodução {#playback}

<table>
<tr><td>`Espaço`</td><td>Iniciar ou pausar reprodução</td></tr>
<tr><td>`Esquerda` e `Direita`</td><td>Avançar ou retroceder pelo arquivo de log</td></tr>
<tr><td>`L` ou `Ctrl+L`</td><td>Ativar ou desativar trava ao visualizar dados ao vivo</td></tr>
