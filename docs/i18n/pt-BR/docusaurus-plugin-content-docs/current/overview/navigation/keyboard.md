# Atalhos de teclado {#keyboard-shortcuts}

O AdvantageScope inclui inúmeros atalhos de teclado que permitem uma navegação mais rápida. Os atalhos que usam a tecla `ctrl` são substituídos pela tecla ⌘ no macOS.

### Fontes de dados {#data-sources}

<table>
<tr><td>`Ctrl+O`</td><td>Abrir um ou mais arquivos de log</td></tr>
<tr><td>`Ctrl+Shift+O`</td><td>Adicionar um ou mais arquivos de log à visualização atual</td></tr>
<tr><td>`Ctrl+K`</td><td>Conectar ao robô como uma fonte ao vivo</td></tr>
<tr><td>`Ctrl+Shift+K`</td><td>Conectar ao simulador como uma fonte ao vivo</td></tr>
<tr><td>`Ctrl+Option+Shift+K`</td><td>Conectar à Driver Station como uma fonte ao vivo</td></tr>
<tr><td>`Ctrl+D`</td><td>Baixar arquivos de log do robô</td></tr>
</table>

### Exportação de dados {#data-export}

<table>
<tr><td>`Ctrl+E`</td><td>Exportar dados de log</td></tr>
<tr><td>`Ctrl+P`</td><td>Publicar dados de log em um servidor NetworkTables no robô</td></tr>
<tr><td>`Ctrl+Shift+P`</td><td>Publicar dados de log em um servidor NetworkTables em simulação</td></tr>
<tr><td>`Option+Ctrl+P`</td><td>Parar de publicar no NetworkTables</td></tr>
</table>

### Controles de janela {#window-controls}

<table>
<tr><td>`Ctrl+N`</td><td>Criar uma nova janela</td></tr>
<tr><td>`Ctrl+Shift+N`</td><td>Fechar a janela atual</td></tr>
<tr><td>`Ctrl+Vírgula`</td><td>Abrir janela de preferências</td></tr>
<tr><td>`Ctrl+Ponto`</td><td>Alternar visibilidade da barra lateral</td></tr>
<tr><td>`Ctrl+Barra`</td><td>Alternar visibilidade do painel de controle</td></tr>
</table>

### Controles de guias {#tab-controls}

<table>
<tr><td>`Ctrl+T`</td><td>Abrir menu suspenso para adicionar uma nova guia</td></tr>
<tr><td>`Ctrl+Shift+T`</td><td>Criar uma nova janela destacável para a guia atual</td></tr>
<tr><td>`Ctrl+Esquerda` e `Ctrl+Direita`</td><td>Alternar guias</td></tr>
<tr><td>`Ctrl+[` e `Ctrl+]`</td><td>Reorganizar guias</td></tr>
<tr><td>`Ctrl+W`</td><td>Fechar guia atual</td></tr>
</table>
