# 💡 AdvantageScope Lite {#advantagescope-lite}

AdvantageScope Lite 是 AdvantageScope 的网页版，可通过 FIRST Driver Station 和 Systemcore Web 界面访问。它包含了 AdvantageScope 桌面应用的大多数基础功能；不过受兼容性限制，部分功能有所精简（包括某些选项卡类型、日志格式及相关功能）。

## 安装与资源 {#installation-and-assets}

你可以从 GitHub Releases 页面下载“Systemcore”版本的 AdvantageScope，来安装或更新适用于 Systemcore 的 AdvantageScope Lite。下载后，在 Systemcore Web 界面中选择“Add Package”卡片，将软件包上传到机器人即可。

选择 `文件` > `上传资源` 即可上传资源文件（例如场地或机器人模型）。你可以上传单个资源的 zip 文件，也可以上传包含多个资源 zip 文件的压缩包。有关资源格式的详细信息，请参阅 [自定义资源](/more-features/custom-assets/) 页面。

:::info
点击下方链接即可下载常用资源合集（Zip 格式）：

- [**默认 FRC 资源**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFRC.zip)：FRC 场地、FRC 示例机器人以及所有控制器布局。
- [**默认 FTC 资源**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFTC.zip)：FTC 场地、FTC 示例机器人以及所有控制器布局。
- [**FRC 6328 资源**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsFRC6328.zip)：[6328 团队分发版](/overview/installation#team-6328) AdvantageScope 专属资源。

:::

:::tip
在 FIRST Driver Station 中使用 AdvantageScope Lite 无需安装，直接访问 http://localhost:6768/ascope 即可连接实时数据或查看日志文件。此外，你也可以直接将外部操控站日志文件拖放到窗口中打开。
:::
