# 📦 安装 {#installation}

AdvantageScope 官方版本可直接从 6328 团队获取，或通过 WPILib 安装程序下载；此外，社区也提供了一些非官方分发版。

## 6328 团队 {#team-6328}

### 下载：[稳定版](https://github.com/Mechanical-Advantage/AdvantageScope/releases/latest)，[预发布版](https://github.com/Mechanical-Advantage/AdvantageScope/releases) {#6328-downloads}

直接从 6328 团队下载 AdvantageScope 具有以下优势：

- 抢先获取其他渠道尚未同步的最新功能与 Bug 修复。
- 有新版本可供下载时，应用内会自动弹出提醒。
- 内置多款 6328 团队近年的机器人模型，可在 👀 [3D 场地](/tab-reference/3d-field) 选项卡中直接使用。

:::info
AdvantageScope 每年 1 月 FRC 赛季揭幕战 (kickoff) 前都会发布一个主版本，版本号与年份对应（例如 v26.0.0 于 2026 年 1 月发布）。在正式版发布前的几个月里，我们可能会推出 Beta 和 Alpha 测试版，供愿意尝鲜并提供反馈的队伍试用。**使用这些预发布版本时，你可能会遇到稳定版中不存在的问题或 Bug。**
:::

## WPILib {#wpilib}

### 安装：[WPILib 文档](https://docs.wpilib.org/zh-cn/stable/docs/zero-to-robot/step-2/wpilib-setup.html) {#wpilib-installation}

WPILib 安装程序内置了较新的 AdvantageScope 版本，但更新节奏可能略慢于直接下载的最新版。想了解如何从 WPILib 版 VS Code 启动 AdvantageScope，可参阅 [这份文档](https://docs.wpilib.org/en/stable/docs/software/dashboards/advantagescope.html)。

## 非官方分发版 {#unofficial-distributions}

以下非官方分发版来自不同渠道，不由 AdvantageScope 或 WPILib 开发团队提供官方支持，版本更新也可能落后于官方渠道。如遇问题，请直接联系对应维护者。

- [**适用于 REV 控制系统的 AdvantageScope Lite：**](https://github.com/j5155/AdvantageScope-Lite-FTC) 专为现有（Systemcore 之前的）FTC 控制系统修改的 [AdvantageScope Lite](/more-features/advantagescope-lite) 版本。
- [**Homebrew 安装程序：**](https://formulae.brew.sh/cask/advantagescope) 用于在 macOS 上通过命令行安装 AdvantageScope 的 Homebrew cask。
- [**Arch User Repository：**](https://aur.archlinux.org/packages/advantagescope) 配合 pacman 包管理器使用的另一种安装方式（官方 Arch 版 AdvantageScope 可在 [此处](#6328-downloads) 下载）。
