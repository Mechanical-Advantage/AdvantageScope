## 侧边栏 {#sidebar}

左侧是包含可用表格和字段列表的侧边栏。可选择的字段以 _斜体_ 显示，内置表格（来自 WPILib 或 AdvantageKit）带有 <u>下划线</u>。点击箭头可展开嵌套的表格。**拖动单个字段** 即可选择它，或 **按住 cmd/ctrl** 并依次点击每个字段来选择一组字段。开始拖动该组字段即可完成选择。

要搜索字段，请开始在搜索框中键入。系统将显示字段下拉列表，然后选中的字段将在侧边栏中高亮显示并滚动到视图中。

:::info
在右侧边缘上点击并拖动可以调整大小或隐藏侧边栏。双击可切换侧边栏的可见性。
:::

## 选项卡栏 {#tab-bar}

使用选项卡栏（蓝色）在不同的视图之间切换。随时可以通过点击左侧的 📖 图标来查看本文档。要导出当前的选项卡布局（及相关设置），请点击 `文件` > `导出布局...`。要从文件导入布局，请点击 `文件` > `导入布局...`。

:::info
可以通过点击并拖动来重新排列选项卡，或通过右键单击并选择 `重命名选项卡` 来进行重命名。
:::

顶部的导航按钮（绿色）用于管理选项卡和控制播放。

- **加号按钮**：打开下拉菜单以创建新选项卡。
- **窗口按钮**：使用该选项卡创建一个新的弹出窗口。此功能可用于同时查看来自多个选项卡的数据。
- **X 按钮**：关闭当前选项卡。
- **播放按钮**：开始和停止实时播放。_右键单击可更改播放速度或启用循环播放。_

## 视图面板 {#viewer-pane}

视图面板是每种选项卡类型展示数据的地方。有关每个选项卡视图面板的详细信息，请查看选项卡参考文档。点击选项卡栏中的弹出按钮可以将此视图移动到独立窗口中。

## 控制面板 {#control-pane}

控制面板用于选择需要可视化的字段并管理其他选项。有关每个选项卡可用选项的详细信息，请查看选项卡参考文档。

:::info
在顶部边缘上点击并拖动可以调整大小或隐藏控制面板。双击可切换控制面板的可见性。
:::
