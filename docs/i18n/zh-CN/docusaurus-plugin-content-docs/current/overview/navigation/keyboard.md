# 快捷键

AdvantageScope 包含众多允许更快速导航的键盘快捷键。使用 `ctrl` 键的快捷键在 macOS 上将被 ⌘ 键取代。

### 数据源

<table>
<tr><td>`Ctrl+O`</td><td>打开一个或多个日志文件</td></tr>
<tr><td>`Ctrl+Shift+O`</td><td>添加一个或多个日志文件到当前可视化</td></tr>
<tr><td>`Ctrl+K`</td><td>连接到机器人作为实时数据源</td></tr>
<tr><td>`Ctrl+Shift+K`</td><td>连接到模拟器作为实时数据源</td></tr>
<tr><td>`Ctrl+Option+Shift+K`</td><td>连接到驾驶站作为实时数据源</td></tr>
<tr><td>`Ctrl+D`</td><td>从机器人下载日志文件</td></tr>
</table>

### 数据导出

<table>
<tr><td>`Ctrl+E`</td><td>导出日志数据</td></tr>
<tr><td>`Ctrl+P`</td><td>发布日志数据到机器人上的 NetworkTables 服务器</td></tr>
<tr><td>`Ctrl+Shift+P`</td><td>发布日志数据到模拟器中的 NetworkTables 服务器</td></tr>
<tr><td>`Option+Ctrl+P`</td><td>停止发布到 NetworkTables</td></tr>
</table>

### 窗口控制

<table>
<tr><td>`Ctrl+N`</td><td>新建窗口</td></tr>
<tr><td>`Ctrl+Shift+N`</td><td>关闭当前窗口</td></tr>
<tr><td>`Ctrl+Comma`</td><td>打开首选项窗口</td></tr>
<tr><td>`Ctrl+Period`</td><td>切换侧边栏可见性</td></tr>
<tr><td>`Ctrl+Slash`</td><td>切换控制面板可见性</td></tr>
</table>

### 选项卡控制

<table>
<tr><td>`Ctrl+T`</td><td>打开下拉菜单以添加新选项卡</td></tr>
<tr><td>`Ctrl+Shift+T`</td><td>为当前选项卡创建新的弹出窗口</td></tr>
<tr><td>`Ctrl+Left` 和 `Ctrl+Right`</td><td>切换选项卡</td></tr>
<tr><td>`Ctrl+[` 和 `Ctrl+]`</td><td>重新排列选项卡</td></tr>
<tr><td>`Ctrl+W`</td><td>关闭当前选项卡</td></tr>
</table>

### 播放控制

<table>
<tr><td>`Space`</td><td>切换播放状态</td></tr>
<tr><td>`Left` 和 `Right`</td><td>按步长游览日志文件</td></tr>
<tr><td>`L` 或 `Ctrl+L`</td><td>在查看实时数据时切换锁定状态</td></tr>
<tr><td>`Ctrl+\`</td><td>将时间轴缩放到启用状态范围</td></tr>
</table>
