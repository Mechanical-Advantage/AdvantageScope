# 快捷键 {#keyboard-shortcuts}

AdvantageScope 提供了丰富的键盘快捷键，助你更高效地浏览与操作。以下快捷键中的 `Ctrl` 键在 macOS 上对应 `⌘` 键。

### 数据源 {#data-sources}

<table>
<tr><td>`Ctrl+O`</td><td>打开一个或多个日志文件</td></tr>
<tr><td>`Ctrl+Shift+O`</td><td>向当前视图追加一个或多个日志文件</td></tr>
<tr><td>`Ctrl+K`</td><td>连接到机器人实时数据源</td></tr>
<tr><td>`Ctrl+Shift+K`</td><td>连接到模拟器实时数据源</td></tr>
<tr><td>`Ctrl+Option+Shift+K`</td><td>连接到操控站实时数据源</td></tr>
<tr><td>`Ctrl+D`</td><td>从机器人下载日志文件</td></tr>
</table>

### 数据导出 {#data-export}

<table>
<tr><td>`Ctrl+E`</td><td>导出日志数据</td></tr>
<tr><td>`Ctrl+P`</td><td>将日志数据发布到机器人上的 NetworkTables 服务器</td></tr>
<tr><td>`Ctrl+Shift+P`</td><td>将日志数据发布到模拟器中的 NetworkTables 服务器</td></tr>
<tr><td>`Option+Ctrl+P`</td><td>停止发布到 NetworkTables</td></tr>
</table>

### 窗口控制 {#window-controls}

<table>
<tr><td>`Ctrl+N`</td><td>新建窗口</td></tr>
<tr><td>`Ctrl+Shift+N`</td><td>关闭当前窗口</td></tr>
<tr><td>`Ctrl+Comma`</td><td>打开首选项窗口</td></tr>
<tr><td>`Ctrl+Period`</td><td>切换侧边栏显隐</td></tr>
<tr><td>`Ctrl+Slash`</td><td>切换控制面板显隐</td></tr>
</table>

### 选项卡控制 {#tab-controls}

<table>
<tr><td>`Ctrl+T`</td><td>打开下拉菜单以新建选项卡</td></tr>
<tr><td>`Ctrl+Shift+T`</td><td>为当前选项卡创建独立弹出窗口</td></tr>
<tr><td>`Ctrl+Left` 和 `Ctrl+Right`</td><td>切换选项卡</td></tr>
<tr><td>`Ctrl+[` 和 `Ctrl+]`</td><td>调整选项卡顺序</td></tr>
<tr><td>`Ctrl+W`</td><td>关闭当前选项卡</td></tr>
</table>

### 播放控制 {#playback}

<table>
<tr><td>`Space`</td><td>切换播放/暂停</td></tr>
<tr><td>`Left` 和 `Right`</td><td>单步浏览日志文件</td></tr>
<tr><td>`L` 或 `Ctrl+L`</td><td>查看实时数据时切换锁定状态</td></tr>
<tr><td>`Ctrl+\`</td><td>将时间轴缩放到启用状态范围</td></tr>
</table>
