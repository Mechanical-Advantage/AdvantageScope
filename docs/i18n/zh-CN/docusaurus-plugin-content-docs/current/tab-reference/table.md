# 🔢 表格 {#table}

表格视图用于详细展示一组字段的具体数值变化。将字段拖入主视图即可添加，点击字段名称旁的 “X” 按钮可删除，点击并拖动字段则可调整排列顺序。

<img src="/img/tab-reference/table-1.webp" alt="概览" />

_上图所示为英文界面。_

**每当所显示字段中的任意值发生变化时，表格都会新增一行。** 重复的行不会显示。例如，展示比赛期间机器人状态的表格如下图所示：

<img src="/img/tab-reference/table-2.webp" alt="机器人状态表格" />

表格中选中的时间点会在所有选项卡之间同步。点击某一行即可选中该时间点，将光标悬停在某一行上则可在所有可见的弹出窗口中预览该时刻的状态。点击 ↓ 按钮可跳转到所选时间（或输入框中填写的时间）。时间戳和跳转输入框的格式遵循 [时间戳](/more-features/timestamps) 首选项设置。

<img src="/img/tab-reference/table-3.webp" alt="跳转到指定时间" />
