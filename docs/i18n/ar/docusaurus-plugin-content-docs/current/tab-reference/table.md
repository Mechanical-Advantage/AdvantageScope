# 🔢 جدول

تم تصميم عرض الجدول لإظهار التغييرات المحددة في القيمة لمجموعة من الحقول بالتفصيل. لإضافة حقل، اسحبه إلى العرض الرئيسي. لحذف حقل، انقر فوق زر "X" بجوار اسمه. يمكن إعادة ترتيب الحقول بالنقر والسحب.

<img src="/img/tab-reference/table-1.png" alt="Overview" />

**يتم إنشاء صف جديد لكل تغيير في أي من الحقول المعروضة.** الصفوف المكررة لا تُعرض. على سبيل المثال، فإن الجدول الذي يظهر حالة الروبوت أثناء المباراة سيبدو هكذا:

<img src="/img/tab-reference/table-2.png" alt="Robot state table" />

يتم مزامنة الوقت المحدد في الجدول عبر جميع علامات التبويب. انقر فوق صف لتحديده، أو حوم فوق صف لمعاينته في أي نوافذ منبثقة مرئية. يؤدي النقر فوق زر ↓ إلى الانتقال إلى الوقت المحدد (أو الوقت أدخل في المربع).
