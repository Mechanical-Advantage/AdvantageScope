# دعم الوحدات {#unit-support}

علامة تبويب الرسم البياني الخطي داعمة للوحدات، مما يعني أنه يمكن تحويل القيم الرقمية بسهولة بين أنواع الوحدات المتوافقة. عند توفر معلومات الوحدات، تتم تسمية جميع القيم الرقمية بدقة عند عرضها في المحاور أو المفاتيح. راجع [هنا](#supported-formats) لمزيد من المعلومات حول نشر معلومات الوحدات. يوفر AdvantageScope عدة أدوات للتحويل السريع بين الوحدات:

- عند إضافة **حقول على نفس المحور مع أنواع وحدات متوافقة**، يقوم AdvantageScope تلقائياً بتحويل كلا الحقلين إلى نفس الوحدة. ينعكس هذا في تسمية المحور Y والمفتاح.
- انقر فوق النقاط الثلاث بالقرب من عنوان المحور لـ **التبديل السريع إلى وحدات بديلة**. تتضمن هذه القائمة أكثر الوحدات شيوعاً المتوافقة مع الحقول المحددة.
- مَكّن **التكامل أو التفاضل** ([الوثائق](/tab-reference/line-graph/#integration-and-differentiation)) لرؤية وحدات التكامل أو المشتق الدقيقة. يمكن ضبط الوحدة الأساسية باستخدام القائمة لدعم التصفية بوحدات غير أصلية.

## التنسيقات المدعومة {#supported-formats}

يدعم AdvantageScope طرقاً عديدة لتوفير معلومات الوحدات حول كل حقل. يتم دعم معظم الوحدات الشائعة؛ للاطلاع على قائمة كاملة، تحقق من القائمة المنبثقة عند تكوين [التحويل اليدوي](#manual-conversion).

بالنسبة لـ (2) و (3)، يتم تحليل أنواع الوحدات باستخدام النصوص. يدعم AdvantageScope أسماء متعددة لكل وحدة، بما في ذلك الاختصارات الشائعة (على سبيل المثال `ft` و `feet` كلاهما مقبول). لاحظ أنه يجب توفير أسماء الوحدات باستخدام رموز SI أو الإنجليزية الأمريكية، بغض النظر عن اللغة المحددة في AdvantageScope. إذا لم يتم تحليل اسم الوحدة كما هو متوقع، يرجى [فتح مشكلة (issue)](https://github.com/Mechanical-Advantage/AdvantageScope/issues).

:::tip
لست متأكداً مما إذا كان يتم تحليل الوحدات بشكل صحيح؟ تحقق مما إذا كان يتم عرض نوع الوحدة على المحور Y عند إضافة حقل إلى الرسم البياني الخطي.
:::

### 🥇 وحدات التركيب (Struct Units) {#struct-units}

يستخدم AdvantageScope تلقائياً الوحدات الأصلية لأنواع البيانات الهيكلية الشائعة مثل `Rotation2d` و `Translation3d`. نشر القيم المطبقة باستخدام هذه التنسيقات هو **دائماً أفضل طريقة لنشر البيانات** ويضمن أقصى قدر من التوافق عند عرض بيانات الهندسة.

### 🥈 البيانات الوصفية للحقل {#field-metadata}

تدعم تنسيقات WPILOG و NetworkTables نشر «بيانات وصفية» إضافية لكل حقل. يبحث AdvantageScope عن حقول JSON المسماة "unit« أو »units" التي تحتوي على اسم نصي لنوع الوحدة (باستخدام المسافات، أو camel-case، أو pascal-case، أو snake-case). للتحقق من البيانات الوصفية لكل حقل، حوم بالمؤشر فوق اسم الحقل في الشريط الجانبي.

:::tip
يتضمن AdvantageKit دعماً للبيانات الوصفية للوحدات عند تسجيل المدخلات والمخرجات، بما في ذلك تسجيل الملاحظات التوضيحية. تحقق من الوثائق [هنا](https://docs.advantagekit.org/data-flow/supported-types#units) للحصول على التفاصيل.
:::

### 🥉 تسمية الحقل {#field-naming}

كخيار بديل، يحاول AdvantageScope تحديد نوع الوحدة الصحيح عن طريق تحليل اسم كل حقل. **يجب تضمين نوع الوحدة كلاحقة (suffix).** يدعم AdvantageScope التنوع في مخططات التسمية. بعض الخيارات الصالحة مدرجة أدناه:

- **Camel/pascal-case**، مثل `PositionMeters` و `velocityRadPerSec` و `TimestampS`
- **Snake-case**، مثل `position_meters` و `velocity_rad_per_sec` و `timestamp_s`
- **مفصلية بمسافات**، مثل `position meters` و `velocity rad per sec` و `timestamp s`

التسمية _ليست_ حساسة لحالة الأحرف عند استخدام snake-case أو الفواصل بمسافات.

:::tip
إذا تم تحليل الوحدات بشكل غير صحيح، انقر فوق `وحدات يدوية` > `تعطيل الوحدات التلقائية` لتجاهل معلومات الوحدات. يمكن استخدام التحويل اليدوي بعد ذلك للتبديل إلى وحدات بديلة.
:::

## التحويل اليدوي {#manual-conversion}

عندما تكون البيانات الوصفية للوحدات غير متاحة أو غير دقيقة، يمكن أيضاً تكوين المحاور يدوياً للتحويل بين الوحدات (أو تجاهل البيانات الوصفية للوحدات تماماً).

لتكوين التحويل اليدوي، انقر فوق النقاط الثلاث بالقرب من عنوان المحور ثم `وحدات يدوية` > `تعديل التحويل...`. حدد نوع الوحدة، والوحدة المصدر، والوحدة الهدف. يتم ضرب كل قيمة أيضاً في «العامل الإضافي»، مما يسمح بالتحويلات المخصصة (مثل نسب التروس، والتحويلات الزاوية إلى خطية، أو الوحدات الأخرى غير الموفرة بواسطة AdvantageScope). يمكن أيضاً إدخال العامل باستخدام تعبير رياضي مثل `1.5*pi`.

:::tip
لتمكين تحويل الوحدات أو تعطيله بسرعة، انقر فوق النقاط الثلاث بالقرب من عنوان المحور واختر `الإعدادات المسبقة الأخيرة` أو `إعادة تعيين الوحدات`.
:::
