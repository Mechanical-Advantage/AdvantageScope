# تشخيصات Phoenix {#phoenix-diagnostics}

يدعم AdvantageScope البث المباشر للإشارات من أجهزة Phoenix 6 **دون الحاجة إلى أي إعداد في كود المستخدم**. يتيح ذلك تصحيح الأخطاء وضبط أجهزة Phoenix بسهولة باستخدام الواجهة المألوفة والقوة الكاملة لـ AdvantageScope:

- خيارات عرض مرئي مرنة، بما في ذلك دعم الجداول والتحليل الإحصائي
- دعم كامل للرسم البياني المدرك للوحدات، بما في ذلك التحويل الضمني والتحويل بنقرة واحدة للوحدات ([الوثائق](/tab-reference/line-graph/units))
- فك تشفير قيم التعداد (enum) إلى نصوص مفهومة للبشر (أوضاع التحكم، وحالة الجسر، وحالة مغناطيس CANcoder، وغيرها)
- تلميحات مدمجة في الشريط الجانبي تحتوي على أوصاف ووحدات لكل إشارة
- تنظيم هرمي للإشارات، مجمّعة حسب ناقل CAN والجهاز ونوع الإشارة
- تحليل بيانات متقدم مع خيارات التكامل والتفاضل المدمجة ([الوثائق](/tab-reference/line-graph/#adjusting-axes))

:::tip
للاتصال، حدد «تشخيصات Phoenix» عند الاتصال بالروبوت أو المحاكي من شريط القوائم.
:::
