# تشخيصات Phoenix {#phoenix-diagnostics}

يدعم AdvantageScope البث المباشر للإشارات من أجهزة Phoenix 6 مع **عدم وجود إعداد في كود المستخدم**. يتيح ذلك سهولة تصحيح الأخطاء وضبط أجهزة Phoenix باستخدام الواجهة المألوفة والقوة الكاملة لـ AdvantageScope:

- خيارات عرض مرئي مرنة، بما في ذلك دعم محاور متعددة وحقول منفصلة
- دعم كامل للرسم البياني الداعم للوحدات، بما في ذلك التحويل الضمني والتحويل بنقرة واحدة للوحدات ([الوثائق](/tab-reference/line-graph/units))
- معاينة مباشرة لجميع القيم في الشريط الجانبي للتصفح السهل
- دعم الرسم البياني ومعاينة الإشارات من أجهزة متعددة في نفس الوقت
- فك تشفير قيم التعداد (enum) كنصوص قابلة للقراءة بواسطة الإنسان (أوضاع التحكم، حالة الجسر، حالة مغناطيس CANcoder، إلخ)
- تلميحات شريط جانبي مدمجة تحتوي على أوصاف ووحدات لكل إشارة
- تنظيم هرمي للإشارات، مجمعة حسب ناقل CAN، والجهاز، ونوع الإشارة
- تحليل بيانات متقدم مع خيارات التكامل والتفاضل المدمجة ([الوثائق](/tab-reference/line-graph/#adjusting-axes))

:::tip
للاتصال، حدد "تشخيصات Phoenix" عند الاتصال بالروبوت أو المحاكي من شريط القوائم.
:::
