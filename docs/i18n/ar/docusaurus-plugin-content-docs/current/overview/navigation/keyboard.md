# اختصارات لوحة المفاتيح {#keyboard-shortcuts}

يتضمن AdvantageScope العديد من اختصارات لوحة المفاتيح التي تتيح التصفح السريع. تُمستبدل الاختصارات التي تستخدم مفتاح `ctrl` بالمفتاح ⌘ على macOS.

### مصادر البيانات {#data-sources}

<table>
<tr><td>`Ctrl+O`</td><td>فتح ملف سجل واحد أو أكثر</td></tr>
<tr><td>`Ctrl+Shift+O`</td><td>إضافة ملف سجل واحد أو أكثر إلى العرض المرئي الحالي</td></tr>
<tr><td>`Ctrl+K`</td><td>الاتصال بالروبوت كمصدر مباشر</td></tr>
<tr><td>`Ctrl+Shift+K`</td><td>الاتصال بالمحاكي كمصدر مباشر</td></tr>
<tr><td>`Ctrl+Option+Shift+K`</td><td>الاتصال بمحطة السائق كمصدر مباشر</td></tr>
<tr><td>`Ctrl+D`</td><td>تنزيل ملفات السجل من الروبوت</td></tr>
</table>

### تصدير البيانات {#data-export}

<table>
<tr><td>`Ctrl+E`</td><td>تصدير بيانات السجل</td></tr>
<tr><td>`Ctrl+P`</td><td>نشر بيانات السجل إلى خادم NetworkTables على الروبوت</td></tr>
<tr><td>`Ctrl+Shift+P`</td><td>نشر بيانات السجل إلى خادم NetworkTables في المحاكاة</td></tr>
<tr><td>`Option+Ctrl+P`</td><td>إيقاف النشر إلى NetworkTables</td></tr>
</table>

### عناصر تحكم النافذة {#window-controls}

<table>
<tr><td>`Ctrl+N`</td><td>إنشاء نافذة جديدة</td></tr>
<tr><td>`Ctrl+Shift+N`</td><td>إغلاق النافذة الحالية</td></tr>
<tr><td>`Ctrl+Comma`</td><td>فتح نافذة التفضيلات</td></tr>
<tr><td>`Ctrl+Period`</td><td>تبديل رؤية الشريط الجانبي</td></tr>
<tr><td>`Ctrl+Slash`</td><td>تبديل رؤية جزء التحكم</td></tr>
</table>

### عناصر تحكم علامة التبويب {#tab-controls}

<table>
<tr><td>`Ctrl+T`</td><td>فتح القائمة المنسدلة لإضافة علامة تبويب جديدة</td></tr>
<tr><td>`Ctrl+Shift+T`</td><td>إنشاء نافذة منبثقة جديدة لعلامة التبويب الحالية</td></tr>
<tr><td>`Ctrl+Left` و `Ctrl+Right`</td><td>التبديل بين علامات التبويب</td></tr>
<tr><td>`Ctrl+[` و `Ctrl+]`</td><td>إعادة ترتيب علامات التبويب</td></tr>
<tr><td>`Ctrl+W`</td><td>إغلاق علامة التبويب الحالية</td></tr>
</table>

### التشغيل {#playback}

<table>
<tr><td>`Space`</td><td>تبديل التشغيل</td></tr>
<tr><td>`Left` و `Right`</td><td>التنقل عبر ملف السجل خطوة بخطوة</td></tr>
<tr><td>`L` أو `Ctrl+L`</td><td>تبديل القفل عند عرض البيانات المباشرة</td></tr>
<tr><td>`Ctrl+\`</td><td>تكبير المخطط الزمني إلى النطاق الممكّن</td></tr>
</table>
