# Пернетақта пернелер тіркесімдері {#keyboard-shortcuts}

AdvantageScope тезірек навигация жасауға мүмкіндік беретін көптеген пернетақта пернелер тіркесімдерін қамтиды. `ctrl` пернесін пайдаланатын тіркесімдер macOS жүйесінде ⌘ пернесімен ауыстырылады.

### Дереккөздер {#data-sources}

<table>
<tr><td>`Ctrl+O`</td><td>Бір немесе бірнеше журнал файлын ашу</td></tr>
<tr><td>`Ctrl+Shift+O`</td><td>Ағымдағы визуализацияға бір немесе бірнеше журнал файлын қосу</td></tr>
<tr><td>`Ctrl+K`</td><td>Тікелей дереккөз ретінде роботқа қосылу</td></tr>
<tr><td>`Ctrl+Shift+K`</td><td>Тікелей дереккөз ретінде симуляторға қосылу</td></tr>
<tr><td>`Ctrl+Option+Shift+K`</td><td>Тікелей дереккөз ретінде Driver Station қолданбасына қосылу</td></tr>
<tr><td>`Ctrl+D`</td><td>Роботтан журнал файлдарын жүктеп алу</td></tr>
</table>

### Деректерді экспорттау {#data-export}

<table>
<tr><td>`Ctrl+E`</td><td>Журнал деректерін экспорттау</td></tr>
<tr><td>`Ctrl+P`</td><td>Журнал деректерін роботтағы NetworkTables серверіне жариялау</td></tr>
<tr><td>`Ctrl+Shift+P`</td><td>Журнал деректерін симуляциядағы NetworkTables серверіне жариялау</td></tr>
<tr><td>`Option+Ctrl+P`</td><td>NetworkTables жүйесіне жариялауды тоқтату</td></tr>
</table>

### Терезені басқару элементтері {#window-controls}

<table>
<tr><td>`Ctrl+N`</td><td>Жаңа терезе жасау</td></tr>
<tr><td>`Ctrl+Shift+N`</td><td>Ағымдағы терезені жабу</td></tr>
<tr><td>`Ctrl+Comma`</td><td>Қалаулар терезесін ашу</td></tr>
<tr><td>`Ctrl+Period`</td><td>Бүйірлік тақтаның көрінуін ауыстыру</td></tr>
<tr><td>`Ctrl+Slash`</td><td>Басқару тақтасының көрінуін ауыстыру</td></tr>
</table>

### Қойындыларды басқару элементтері {#tab-controls}

<table>
<tr><td>`Ctrl+T`</td><td>Жаңа қойынды қосу үшін ашылмалы мәзірді ашу</td></tr>
<tr><td>`Ctrl+Shift+T`</td><td>Ағымдағы қойынды үшін жаңа қалқымалы терезе жасау</td></tr>
<tr><td>`Ctrl+Left` және `Ctrl+Right`</td><td>Қойындыларды ауыстыру</td></tr>
<tr><td>`Ctrl+[` және `Ctrl+]`</td><td>Қойындыларды қайта орналастыру</td></tr>
<tr><td>`Ctrl+W`</td><td>Ағымдағы қойындыны жабу</td></tr>
</table>
