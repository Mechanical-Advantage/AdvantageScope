# 🌐 Тілдерді қолдау {#language-support}

AdvantageScope дүниежүзіндегі командаларға ыңғайлы болу үшін бірнеше тілді қолдайды. Қазіргі уақытта келесі тілдер AdvantageScope құжаттамасында, жұмыс үстелі қолданбасында, мобильді қолданбаларда (AdvantageScope XR және AdvantageTune) және AdvantageScope Lite нұсқасында (Systemcore жүйесі мен FIRST Driver Station ішінде) қолжетімді:

- Ағылшын (АҚШ)
- Испан (Латын Америкасы)
- Француз
- Нидерланд
- Португал (Бразилия)
- Румын
- Түрік
- Орыс
- Қазақ
- Иврит
- Араб
- Хинди
- Қарапайым қытай
- Дәстүрлі қытай

## Баптау {#configuration}

AdvantageScope интерфейсінің тілін өзгерту үшін `Қолданба` > `Қалауларды көрсету...` (Windows/Linux) немесе `AdvantageScope` > `Параметрлер...` (macOS) тармағын басып, баптаулар терезесін ашыңыз. «Тіл» параметрінен қолдау көрсетілетін тілдер тізімінен қажетті тілді таңдауға немесе операциялық жүйенің тіліне автоматты түрде бейімделу үшін «Жүйенің әдепкі тілі» нұсқасын қоюға болады.

## Журнал кілттері {#logging-keys}

AdvantageScope қолдайтын барлық пішімдер журнал кілттерін анықтауда Unicode стандартын толық қолдайды. Яғни деректерді өз қалауыңызша кез келген тілде (соның ішінде диакритикалық белгілерді, арнайы таңбаларды және латын емес әліпбилерді пайдаланып) тіркей аласыз — олар AdvantageScope қолданбасында дұрыс жазылып, көрсетіледі.

Төменде қазақ тіліндегі кілтпен жолды тіркеу мысалы берілген:

</TabItem>
<TabItem value="advantagekit" label="AdvantageKit">

Logger.recordOutput("Қозғалыс/Оң жақ мотор жылдамдығы", "Жылдам");

:::tip Өлшем бірліктерін қолдау
Өлшем бірліктерінің метадеректерін беру туралы толығырақ [өлшем бірліктерін қолдау](/tab-reference/line-graph/units) бетінен қараңыз. AdvantageScope қолданбасында таңдалған тілге қарамастан, өлшем бірлігінің атаулары SI белгілерімен немесе ағылшын тілінде (америкалық немесе британдық емлемен) көрсетілуі тиіс.
:::

## Әзірлеу {#development}

AdvantageScope қолданбасын локализациялау жасанды интеллект пен қауымдастықтың ынтымақтастығы арқылы жүзеге асырылады. AdvantageScope қарқынды дамып келе жатқан жоба болғандықтан, барлық тілдегі қолданба мен құжаттаманы үнемі синхрондап отыру үшін ЖИ қолдану өте маңызды. Осының арқасында таңдаған тіліңізге қарамастан, жаңа мүмкіндіктер мен жаңартулар әрқашан бір уақытта қолжетімді болады.

Біздің үдеріс жергілікті командаларға таныс арнайы терминдерге, кірме сөздерге және транслитерацияларға сай болуға бағытталған. Дегенмен ЖИ аудармаларында кейде жасанды сөз тіркестері немесе басқа да дәлсіздіктер кездесуі мүмкін. Сондықтан пікіріңізді қуана қабылдаймыз: аудармалар бойынша кері байланыс жіберу үшін қолданбадағы күлгін белгішені басыңыз (ағылшын тілінен басқа кез келген тіл таңдалған кезде).
