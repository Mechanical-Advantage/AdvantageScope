# 🌐 Тілдерді қолдау {#language-support}

AdvantageScope бүкіл әлемдегі командаларға оқшауланған тәжірибе ұсыну үшін бірнеше тілді қолдайды. Қазіргі уақытта келесі тілдер қолжетімді:

- Ағылшын (АҚШ)
- Испан (Латын Америкасы)
- Француз
- Португал (Бразилия)
- Түрік
- Румын
- Иврит
- Қазақ
- Орыс
- Араб
- Қарапайым қытай
- Дәстүрлі қытай

## Баптау {#configuration}

AdvantageScope қолданбасында интерфейс тілін өзгерту үшін `App` > `Баптауларды көрсету...` (Windows/Linux) немесе `AdvantageScope` > `Параметрлер...` (macOS) батырмасын басу арқылы баптаулар терезесін ашыңыз. «Тіл» баптауының астында қолдау көрсетілетін тілдер тізімінен таңдауға немесе операциялық жүйеңіздің тіліне автоматты түрде сәйкестендіру үшін «Жүйелік әдепкі» опциясын таңдауға болады.

## Журнал кілттері {#logging-keys}

AdvantageScope қолдайтын барлық форматтар журнал кілттерін анықтау кезінде толық Unicode үйлесімділігіне ие. Бұл өз ана тіліңізді (соның ішінде арнайы таңбаларды, диакритикалық белгілерді және латын емес әліпбилерді) пайдаланып деректерді тіркей алатыныңызды және олар AdvantageScope қолданбасында дұрыс жазылып, көрсетілетінін білдіреді.

Төменде қазақша кілтпен жолды тіркеу мысалы келтірілген:

<Tabs groupId="library">
<TabItem value="wpilib" label="WPILib" default>

```java
SmartDashboard.putString("Қозғалыс/Оң жақ мотор жылдамдығы", "Жылдам");
```

</TabItem>
<TabItem value="advantagekit" label="AdvantageKit">

```java
Logger.recordOutput("Қозғалыс/Оң жақ мотор жылдамдығы", "Жылдам");
```

</TabItem>
</Tabs>

:::tip Өлшем бірліктерін қолдау
Өлшем бірліктерінің метадеректерін беру туралы қосымша ақпаратты [өлшем бірліктерін қолдау](/tab-reference/line-graph/units) бетінен қараңыз. AdvantageScope қолданбасында таңдалған тілге қарамастан, өлшем бірлігінің атаулары SI символдары немесе ағылшын тілі (американдық немесе британдық емле) арқылы берілуі керек.
:::

## Әзірлеу {#development}

AdvantageScope қолданбасын оқшаулау жасанды интеллект пен қоғамдастық ынтымақтастығының үйлесімі арқылы жүзеге асырылады. AdvantageScope қарқынды дамып келе жатқан жоба болғандықтан, әр тілдегі аударылған қолданба мен құжаттаманы синхрондалған күйде ұстау үшін ЖИ-ді пайдалану өте маңызды. Бұл таңдалған тіліңізге қарамастан, жаңа мүмкіндіктер мен жаңартулардың әрқашан бір уақытта қолжетімді болуын қамтамасыз етеді.

Аудармалардың ең жоғары сапасын қамтамасыз ету үшін біздің процесіміз әр тілге арналған егжей-тегжейлі глоссарийлер мен нұсқаулықтарды құрастыру мақсатында FIRST қауымдастығындағы ана тілінде сөйлейтіндердің кең көлемді анықтамалық материалдарына негізделеді. Бұл аудармалардың жергілікті командаларға таныс арнайы лексикаға, кірме сөздерге және транслитерацияларға сәйкес келуіне көмектеседі.

Негізгі аудармалар маңызды шешімдерге (мысалы, FIRST терминдерін аудару) адамның бақылауымен ЖИ көмегімен итеративті түрде жасалады. Содан кейін алынған мәтіннің дәлдігін қамтамасыз ету үшін бұл аудармаларды FIRST қауымдастығының ана тілінде сөйлейтін мүшелері тексереді және өңдейді. Пайдаланушылар сондай-ақ қолданбадағы күлгін белгішені басу арқылы аудармалар туралы кері байланыс бере алады (ағылшын тілінен басқа кез келген тіл таңдалған кезде).
