# 📦 Орнату {#installation}

AdvantageScope қолданбасының ресми қолдау көрсетілетін нұсқасын тікелей 6328 командасынан немесе WPILib орнатушысы арқылы жүктеп алуға болады. Сонымен қатар бірнеше бейресми дистрибутив де қолжетімді.

## 6328 командасы {#team-6328}

### Жүктеп алу: [Тұрақты нұсқа](https://github.com/Mechanical-Advantage/AdvantageScope/releases/latest), [Алдын ала шығарылым](https://github.com/Mechanical-Advantage/AdvantageScope/releases) {#6328-downloads}

AdvantageScope қолданбасын тікелей 6328 командасынан жүктеп алудың артықшылықтары:

- Басқа арналарда жарияланбай тұрып-ақ жаңа мүмкіндіктер мен қате түзетулеріне қол жеткізу.
- Жаңа нұсқа шыққан кезде қолданба ішінде ескерту алу.
- 👀 [3D алаңы](/tab-reference/3d-field) қойындысында пайдалануға арналған 6328 командасының соңғы робот үлгілерінің кірістірілген жинағы.

:::info
AdvantageScope қолданбасының әрбір негізгі нұсқасы қаңтар айында FRC маусымының ашылуы алдында шығарылады және нұсқа нөмірі жылға сәйкес келеді (мысалы, v26.0.0 нұсқасы 2026 жылдың қаңтарында шықты). Жаңа мүмкіндіктерді сынап көріп, кері байланыс бергісі келетін командалар үшін әр шығарылымның алдындағы айларда AdvantageScope бета және альфа нұсқалары жариялануы мүмкін. **Осы алдын ала шығарылым нұсқаларын пайдаланатын командалар тұрақты шығарылымдарда кездеспейтін ақаулар мен қателерге тап болуы мүмкін екенін ескеруі керек.**
:::

## WPILib {#wpilib}

### Орнату: [WPILib құжаттамасы](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/wpilib-setup.html) {#wpilib-installation}

WPILib орнатушысы AdvantageScope қолданбасының жақында шыққан нұсқасын қамтиды, бірақ тікелей жүктеп алуға болатын ең соңғы нұсқадан сәл ескірек болуы мүмкін. AdvantageScope қолданбасын VS Code бағдарламасының WPILib нұсқасынан іске қосу туралы нұсқаулықты [осы жерден](https://docs.wpilib.org/en/stable/docs/software/dashboards/advantagescope.html) қараңыз.

## Бейресми дистрибутивтер {#unofficial-distributions}

AdvantageScope қолданбасының AdvantageScope/WPILib әзірлеушілері ресми түрде қолдамайтын бірнеше бейресми дистрибутиві бар. Бұл дистрибутивтер ресми көздердегі соңғы нұсқадан артта қалуы мүмкін. Мәселелер туындаса, тікелей солардың авторларына хабарласыңыз.

- [**REV басқару жүйесіне арналған AdvantageScope Lite:**](https://github.com/j5155/AdvantageScope-Lite-FTC) Қолданыстағы (Systemcore жүйесіне дейінгі) FTC басқару жүйесінде пайдалануға арналған [AdvantageScope Lite](/more-features/advantagescope-lite) модификациясы.
- [**Homebrew орнатушысы:**](https://formulae.brew.sh/cask/advantagescope) macOS жүйесінде пәрмен жолы арқылы AdvantageScope орнатуға арналған Homebrew cask пакеті.
- [**Arch пайдаланушылар репозиторийі:**](https://aur.archlinux.org/packages/advantagescope) `pacman` пакет менеджерімен пайдалануға арналған баламалы орнату тәсілі (AdvantageScope қолданбасының ресми Arch дистрибутиві [осы жерде](#6328-downloads) қолжетімді).
- [**FRC-Nix:**](https://github.com/frc4451/frc-nix) Nix пакет менеджері мен NixOS Linux дистрибутивімен пайдалануға арналған, AdvantageScope қолданбасын қамтитын FIRST-ке қатысты Nix пакеттері мен декларативті NixOS модульдерінің жиынтығы.
