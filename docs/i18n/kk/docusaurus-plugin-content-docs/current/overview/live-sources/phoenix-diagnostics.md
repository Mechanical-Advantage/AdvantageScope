# Phoenix диагностикасы

AdvantageScope бағдарламасы **пайдаланушы кодында ешқандай баптаусыз** Phoenix 6 құрылғыларынан сигналдарды тікелей трансляциялауды қолдайды. Бұл AdvantageScope бағдарламасының таныс интерфейсі мен толық мүмкіндіктерін пайдалана отырып, Phoenix құрылғыларын оңай отладкалауға және баптауға мүмкіндік береді:

- Көптеген осьтерді және дискретті өрістерді қолдауды қамтитын икемді визуализация параметрлері
- Өлшем бірліктерін жанама және бір рет басу арқылы түрлендіруді қамтитын, өлшем бірлігін ескеретін графикті толық қолдау ([құжаттама](/tab-reference/line-graph/units))
- Оңай шолу үшін бүйірлік тақтадағы барлық мәндерді тікелей алдын ала қарау
- Бір уақытта бірнеше құрылғыдан график салуды және сигналды алдын ала қарауды қолдау
- Enum мәндерін адам оқи алатын жолдар ретінде декодтау (басқару режимдері, көпір күйі, CANcoder магнит күйі, т.б.)
- Әрбір сигнал үшін сипаттамалары мен өлшем бірліктері бар кірістірілген бүйірлік тақта кеңестері
- CAN шинасы, құрылғы және сигнал түрі бойынша топтастырылған сигналдарды иерархиялық ұйымдастыру
- Кірістірілген интегралдау және дифференциалдау параметрлері бар деректерді кеңейтілген талдау ([құжаттама](/tab-reference/line-graph/#adjusting-axes))
