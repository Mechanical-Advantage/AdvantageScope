# Phoenix диагностикасы {#phoenix-diagnostics}

AdvantageScope **пайдаланушы кодында ешқандай баптаусыз** Phoenix 6 құрылғыларынан сигналдарды тікелей трансляциялауды қолдайды. Бұл AdvantageScope қолданбасының таныс интерфейсі мен толық мүмкіндіктерін пайдалана отырып, Phoenix құрылғыларын оңай жөндеуге және баптауға мүмкіндік береді:

- Кестелерді және статистикалық талдауды қолдауды қамтитын икемді визуализация параметрлері
- Өлшем бірліктерін жанама және бір рет басу арқылы түрлендіруді қамтитын, өлшем бірлігін ескеретін графикті толық қолдау ([құжаттама](/tab-reference/line-graph/units))
- Enum мәндерін адам оқи алатын жолдарға декодтау (басқару режимдері, көпір күйі, CANcoder магнит күйі, т.б.)
- Әр сигнал үшін сипаттамалары мен өлшем бірліктері бар бүйірлік тақтадағы кірістірілген кеңестер
- CAN шинасы, құрылғы және сигнал түрі бойынша топтастырылған сигналдарды иерархиялық ұйымдастыру
- Кірістірілген интегралдау және дифференциалдау параметрлері арқылы деректерді кеңейтілген талдау ([құжаттама](/tab-reference/line-graph/#adjusting-axes))

:::tip

:::
