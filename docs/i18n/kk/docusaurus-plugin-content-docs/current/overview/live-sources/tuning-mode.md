# Баптау режимі

Кейбір тікелей дереккөздер сандық және логикалық мәндерді тікелей баптауды қолдайды. Мысалы, бұл мүмкіндікті NetworkTables дереккөзіне қосылған кезде [контроллер коэффициенттерін баптау](https://docs.wpilib.org/en/stable/docs/software/advanced-controls/introduction/tutorial-intro.html) үшін пайдалануға болады. Ескерту: робот коды NetworkTables арқылы коэффициенттерді қабылдауды қолдауы керек.

Әдепкі бойынша AdvantageScope қолданбасындағы барлық мәндер тек оқуға арналған. Баптау режимін ауыстыру үшін қолдау көрсетілетін тікелей дереккөзге қосылған кезде іздеу жолағының оң жағындағы **ползунок белгішесін басыңыз**. Белгіше күлгін болған кезде баптау режимі белсенді болады және өрісті өңдеу қосылады.

- **Сандық өрісті** өңдеу үшін бүйірлік тақтадағы өрістің оң жағындағы мәтіндік жолақты пайдаланып жаңа мәнді енгізіңіз. Мән енгізу таңдаудан босатылғаннан кейін немесе «Enter» пернесі басылғаннан кейін жарияланады. Робот жариялаған мәнді пайдалану үшін мәтіндік жолақты бос қалдырыңыз.
- **Логикалық өрісті** ауыстыру үшін бүйірлік тақтадағы өрістің оң жағындағы қызыл немесе жасыл шеңберді басыңыз.

:::warning
Бұл мүмкіндік алаңда роботты басқаруға арналмаған. Таңдау құралдары (choosers), триггер түймелері, т.б. сияқты бақылау тақтасы стиліндегі енгізулерге қолдау көрсетілмейді.
:::

## AdvantageKit арқылы баптау

AdvantageKit арқылы `AdvantageKit` ішкі кестесіне жарияланған өрістер тек шығысқа арналған және өңделмейді. Дегенмен пайдаланушылар AdvantageScope арқылы баптауға болатын өрістерді пайдаланушы кодынан жариялай алады. **NetworkTables ішінде «/Tuning» кестесіне жарияланған кез келген өрістер «NetworkTables (AdvantageKit)» тікелей дереккөзін пайдаланған кезде «Tuning» кестесінің астында пайда болады.**

Мысалы, бапталатын санды [`LoggedNetworkNumber`](https://docs.advantagekit.org/data-flow/recording-inputs/dashboard-inputs) класын пайдаланып жариялауға болады:

```java
LoggedNetworkNumber tunableNumber = new LoggedNetworkNumber("/Tuning/MyTunableNumber", 0.0);
```

:::warning
`NetworkInputs` ішкі кестесін **өңдеуге болмайды**, өйткені оны AdvantageKit журналдау және қайта ойнату үшін желілік мәндерді жазуға пайдаланады. Нақты уақытта желілік енгізулермен өзара әрекеттесу үшін `Tuning` кестесін пайдаланыңыз.
:::
