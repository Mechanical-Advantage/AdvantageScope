# 🪐 WPILOG көмегімен әмбебап журналдау

WPILOG — бүкіл WPILib экожүйесінде қолданылатын стандартты ашық журнал пішімі. AdvantageScope көмегімен WPILOG бірнеше журнал файлдары мен пішімдеріне арналған әмбебап контейнер ретінде қызмет ете алады. Бұл дегеніміз, бір `.wpilog` файлы AdvantageScope қолдайтын кез келген пішімде, соның ішінде CSV, өндірушілерге тән журналдар немесе қосымша WPILOG файлдары түрінде кодталған бірнеше деректер ағынын қамти алады.

Бұл мүмкіндік **роботтың барлық диагностикалық деректерін бір әмбебап журнал файлына** жинау арқылы диагностиканы жеңілдетуге арналған; тіпті үшінші тарап кітапханаларынан немесе сыртқы қызметтерден деректер жинаған кезде де бір матчтан бірнеше журнал файлын жүктеп алудың, байланыстырудың немесе синхрондаудың қажеті жоқ. Мысалы, бір WPILOG файлы келесілерді қамти алады:

- WPILib `Telemetry` API немесе NetworkTables арқылы жарияланған стандартты робот телеметриясы.
- Өндіруші кітапханалары тіркеген жоғары жиілікті құрылғы сигналдары.
- CSV немесе WPILOG пішімінде тіркелген қосалқы процессорлар мен сыртқы қызметтердің күй деректері.
- ...және тағы басқалар!

Осы деректердің барлығы AdvantageScope қолданбасында бірыңғай ағаш құрылымында көрсетіледі, бұл төменде бірнеше өндіруші тіркеген құрылғы сигналдарын қамтитын WPILOG мысалында көрсетілген.

:::note
Systemcore жүйесінде [URCL](https://github.com/Mechanical-Advantage/URCL) орнына ресми REV [күй тіркеушісі](https://docs.revrobotics.com/revlib/logs) келді. AdvantageScope көмегімен әмбебап журналдау ресми күй тіркеушісіне барлық REV құрылғыларынан деректерді бір WPILOG файлына жазуға мүмкіндік береді (URCL-ге ұқсас).
:::

:::

## Эксперименттік: Өндірушілерді журналдау {#experimental-vendor-logging}

Көптеген робот жобалары бір уақытта бірнеше журнал файлын жасайды: WPILib/AdvantageKit телеметриясына арналған стандартты WPILOG файлымен қатар өндіруші кітапханаларынан меншікті файлдар. Әмбебап журналдау осы өндіруші журналдарын тікелей негізгі `.wpilog` файлына енгізу арқылы бұл бөлінуді жояды. WPILib және AdvantageKit үшін төмендегі нұсқауларды қараңыз.

:::warning
Бұл тәсілді өндірушілер ресми түрде қолдамайтындықтан, қолдау сұрауларын AdvantageScope [мәселелер бетіне](https://github.com/Mechanical-Advantage/AdvantageScope/issues) немесе software@team6328.org мекенжайына жіберу керек. Диагностика үшін бастапқы журнал файлдарын экспорттау туралы толығырақ [Өндіруші деректерін экспорттау](#exporting-vendor-data) бөлімінен қараңыз.
:::

[`VendorLogCapture.java`](https://github.com/Mechanical-Advantage/AdvantageScope/blob/main/docs/snippets/VendorLogCapture.java) класын жүктеп алып, робот жобаңызға орналастырыңыз. Бұл класс өндіруші журналдарындағы деректерді белсенді `DataLog` ағынына автоматты түрде жазып алады және төменде көрсетілгендей `Robot` конструкторында бапталуы тиіс. Жазып алу кезінде өндіруші журналдарын уақытша орналастыру үшін қолайлы каталогты таңдауыңыз керек (`/home/systemcore/logs/` ұсынамыз). Толығырақ [Қалай жұмыс істейді](#how-it-works) бөлімінен қараңыз.

```java
public Robot() {
  // WPILib DataLogManager-ді әдеттегідей іске қосыңыз
  DataLogManager.start();

  // Уақытша каталогтан өндіруші журналдарын жазып алуды қосыңыз
  // USB дискісін пайдаланғанда да өндіруші журналдарын ішкі жадта уақытша сақтауды
  // ұсынамыз (өндіруші журналдары жазып алынғаннан кейін сақталмайды)
  VendorLogCapture.start(DataLogManager.getLog(), "/home/systemcore/logs/");

  // Журналды жазып алу қосылғаннан КЕЙІН өндіруші тіркеушісін іске қосыңыз
  // Баптауға болатын болса, шығыс каталогы жоғарыдағы жолға сәйкес келуі тиіс
  VendorLogger.setPath("/home/systemcore/logs/");
  VendorLogger.start();
}
```

Жазып алу кезінде өндіруші журналдарын уақытша орналастыру үшін қолайлы каталогты таңдауыңыз керек (`/home/systemcore/logs/` ұсынамыз). Толығырақ [Қалай жұмыс істейді](#how-it-works) бөлімінен қараңыз.

```python
class Robot(wpilib.TimedRobot):
    def robotInit(self):
        # WPILib DataLogManager-ді әдеттегідей іске қосыңыз
        wpilib.DataLogManager.start()

        # Уақытша каталогтан өндіруші журналдарын жазып алуды қосыңыз
        # USB дискісін пайдаланғанда да өндіруші журналдарын ішкі жадта уақытша сақтауды
        # ұсынамыз (өндіруші журналдары жазып алынғаннан кейін сақталмайды)
        VendorLogCapture.start(wpilib.DataLogManager.get_log(), "/home/systemcore/logs/")

        # Журналды жазып алу қосылғаннан КЕЙІН өндіруші тіркеушісін іске қосыңыз
        # Баптауға болатын болса, шығыс каталогы жоғарыдағы жолға сәйкес келуі тиіс
        VendorLogger.set_path("/home/systemcore/logs/")
        VendorLogger.start()
```

Кейбір өндіруші тіркеушілері сәйкес құрылғы класы (мысалы, `SparkMax`) даналанған кезде _бірден_ деректер жаза бастайтынын ескеріңіз. Журналдардың жазып алынуын қамтамасыз ету үшін аппараттық нысандарды даналауды `Robot` конструкторының соңына дейін кейінге қалдыруды ұсынамыз.

### Қалай жұмыс істейді {#how-it-works}

1. **Жазып алу:** Робот бағдарламасы өндіруші тіркеушілерімен қатар стандартты WPILib журналдауын іске қосады. Жеңіл көмекші өндіруші тіркеушілері жазған жаңа деректерді мерзімді түрде оқып, өңделмеген бөліктерді тікелей белсенді `DataLog` ағынына буып-түйеді.
2. **Сақтау:** Бүкіл біріктірілген журнал бір `.wpilog` файлына сақталады (мысалы, Systemcore-ға қосылған USB флеш-дискіге). Роботта жасалған уақытша өндіруші журнал файлдары қайта жүктеулер арасында сақталмайды, бұл жадтың толып кетуіне жол бермейді.
3. **Визуализация:** AdvantageScope `.wpilog` файлын ашқанда, ол кез келген ендірілген журнал жазбаларын автоматты түрде тауып, мазмұнын декодтайды және барлық өрістерді стандартты телеметриямен бірге бүйірлік тақта ағашына біріктіреді.
4. **Шығарып алу:** Қолдау немесе кеңейтілген диагностика үшін өндіруші журналын ашу қажет болса, бастапқы өндіруші журнал файлдарын [Өндіруші деректерін экспорттау](#exporting-vendor-data) бөлімінде сипатталғандай `.wpilog` файлынан жоғалтусыз шығарып алуға болады.

Сыртқы журнал деректері WPILOG пішімінде түр жолы `log:<пішім>` конвенциясына сәйкес келетін өңделмеген жазба арқылы сақталады. Осы өрістердің бірін талдаған кезде AdvantageScope сол жазбаның барлық екілік жазбаларын хронологиялық ретпен біріктіреді және алынған жүктемені көрсетілген пішімдегі дербес журнал ретінде декодтайды. Содан кейін декодталған сигналдар негізгі өрістер ағашына біріктіріледі және қолданыстағы деректермен автоматты түрде синхрондалады.

:::tip
WPILOG көмегімен әмбебап журналдау тек өндіруші журналдарымен шектелмейді; AdvantageScope-пен үйлесімді кез келген журналдау пішімін сол конвенцияны пайдаланып WPILOG ішіне ендіруге болады.
:::

### Өндіруші деректерін экспорттау {#exporting-vendor-data}

Өндіруші журналдарындағы деректерді тікелей AdvantageScope ішінде қарауға болатынына қарамастан, кейде бастапқы кітапхана жасаған түпнұсқа журналды шығарып алу қажет болуы мүмкін (мысалы, өндірушіге тән утилиталарда тексеру үшін).

Жеке еншілес журналды тікелей AdvantageScope ішінен экспорттау үшін бүйірлік тақтадағы еншілес журнал жазбасын тінтуірдің оң жақ батырмасымен басып, **Бастапқы журналды экспорттау...** тармағын таңдаңыз.

Топтап шығарып алу үшін бір немесе бірнеше `.wpilog` не `.wpilogxz` файлдарынан барлық біріктірілген өндіруші журналдарын іздеп, оларды бөлек файлдарға экспорттайтын [`extract_vendor_logs.py`](https://github.com/Mechanical-Advantage/AdvantageScope/blob/main/docs/snippets/extract_vendor_logs.py) Python скриптін де пайдалануға болады:

```bash
pip3 install robotpy-wpiutil # Қажетті тәуелділік
python3 extract_vendor_logs.py path/to/source.wpilog
```
