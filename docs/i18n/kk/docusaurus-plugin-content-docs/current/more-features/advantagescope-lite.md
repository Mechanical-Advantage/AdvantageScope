# 💡 AdvantageScope Lite

AdvantageScope Lite — бұл FIRST Driver Station және Systemcore веб-интерфейсінен қолжетімді AdvantageScope бағдарламасының браузерлік нұсқасы. AdvantageScope жұмыс үстелі қолданбасының негізгі мүмкіндіктерінің көпшілігі AdvantageScope Lite құрамына кіреді. Дегенмен, үйлесімділік шектеулеріне байланысты кейбір мүмкіндіктер алынып тасталған (соның ішінде кейбір қойынды түрлері, журналдау пішімдері және олармен байланысты мүмкіндіктер).

## Орнату және активтер

Systemcore арналған AdvantageScope Lite бағдарламасын GitHub шығарылымдар бетінен AdvantageScope бағдарламасының «Systemcore» нұсқасын жүктеп алу арқылы орнатуға және жаңартуға болады. Пакетті роботқа жүктеп салу үшін Systemcore веб-интерфейсіндегі «Add Package» карточкасын таңдаңыз.

Актив файлдарын (мысалы, алаң/робот үлгілері) «Файл» > «Активті жүктеп салу» таңдау арқылы жүктеп салуға болады. Таңдалған файл жеке активке арналған zip файлы немесе бірнеше активтердің zip файлдарын қамтитын zip файлы болуы мүмкін. Актив пішімдері туралы қосымша ақпарат алу үшін [таңдамалы активтер](/more-features/custom-assets/) бетін қараңыз.

:::info
Төмендегі сілтемелерді басу арқылы жалпы активтер жиынтығын қамтитын zip файлдарын жүктеп алуға болады:

- [**Әдепкі FRC активтері**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFRC.zip): FRC алаңдары, FRC мысал роботтары және барлық джойстик орналасулары.
- [**Әдепкі FTC активтері**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFTC.zip): FTC алаңдары, FTC мысал роботтары және барлық джойстик орналасулары.
- [**FRC 6328 активтері**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsFRC6328.zip): AdvantageScope бағдарламасының [6328 командасының дистрибуциясына](/overview/installation#6328-downloads) ғана тән активтер.

:::

:::tip
FIRST Driver Station ішінде AdvantageScope Lite пайдалану үшін орнату талап етілмейді. Тікелей қосылу немесе журнал файлдарын қарау үшін http://localhost:6768/ascope мекенжайына өтіңіз.
:::
