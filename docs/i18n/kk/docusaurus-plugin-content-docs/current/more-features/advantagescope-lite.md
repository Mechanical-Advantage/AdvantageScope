# 💡 AdvantageScope Lite {#advantagescope-lite}

AdvantageScope Lite — FIRST Driver Station бағдарламасынан және Systemcore веб-интерфейсінен қолжетімді AdvantageScope қолданбасының браузерлік нұсқасы. AdvantageScope жұмыс үстелі қолданбасының негізгі мүмкіндіктерінің көбі AdvantageScope Lite нұсқасында да бар. Дегенмен үйлесімділік шектеулеріне байланысты кейбір мүмкіндіктер (соның ішінде жекелеген қойынды түрлері, журнал пішімдері және олармен байланысты функциялар) қамтылмаған.

## Орнату және активтер {#installation-and-assets}

Systemcore жүйесіне арналған AdvantageScope Lite нұсқасын орнату және жаңарту үшін GitHub шығарылымдар бетінен AdvantageScope қолданбасының «Systemcore» нұсқасын жүктеп алыңыз. Пакетті роботқа жүктеп салу үшін Systemcore веб-интерфейсіндегі «Add Package» карточкасын таңдаңыз.

Актив файлдарын (мысалы, алаң не робот үлгілерін) `Файл` > `Активті жүктеп салу` тармағы арқылы жүктеп салуға болады. Таңдалған файл жеке активке арналған zip файлы немесе бірнеше актив zip файлын қамтитын ортақ zip файлы болуы мүмкін. Актив пішімдері туралы қосымша ақпарат алу үшін [таңдамалы активтер](/more-features/custom-assets/) бетін қараңыз.

:::info
Төмендегі сілтемелерді басып, жиі қолданылатын активтер жинағы бар zip файлдарын жүктеп алуға болады:

- [**Әдепкі FRC активтері**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFRC.zip): FRC алаңдары, FRC мысал роботтары және барлық джойстик орналасулары.
- [**Әдепкі FTC активтері**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFTC.zip): FTC алаңдары, FTC мысал роботтары және барлық джойстик орналасулары.
- [**FRC 6328 активтері**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsFRC6328.zip): AdvantageScope бағдарламасының [6328 командасының дистрибуциясына](/overview/installation#6328-downloads) ғана тән активтер.

:::

:::tip
FIRST Driver Station қолданбасында AdvantageScope Lite нұсқасын пайдалану үшін бөлек орнату қажет емес. Тікелей қосылу немесе журнал файлдарын қарау үшін http://localhost:6768/ascope мекенжайына өтіңіз.
:::
