# ⏱️ Уақыт белгілері {#timestamps}

AdvantageScope барлық көріністерде, соның ішінде хронологияда, 📉 [Сызықтық графикте](/tab-reference/line-graph), 🔢 [Кестеде](/tab-reference/table) және 💬 [Консольде](/tab-reference/console) уақыт белгілерін көрсетудің реттелетін опцияларын қолдайды.

## Көрсету режимдері {#display-modes}

Уақыт белгісін көрсету режимін баптаулар терезесінде конфигурациялауға болады:

- **Нөлден бастау (Әдепкі):** Журналдағы ең ерте деректер нөлден (`+0,0 с`) басталуы үшін барлық уақыт белгілерін ығыстырады. Бұл режимде көрсетілетін уақыт белгілері деректер басталғаннан бері өткен уақытты көрсету үшін `+` белгісімен басталады.
- **Бастапқы:** Робот коды қолданатын нақты мәндерге сәйкес келетін журнал файлында жазылған бастапқы сандық мәндерді пайдаланып уақыт белгілерін көрсетеді.

:::info
WPILib 2027 нұсқасынан бастап, уақыт белгілері Systemcore және симуляцияда құрылғы қосылғаннан (boot) бергі уақыт арқылы өлшенеді. Өңделмеген уақыт белгілері кездейсоқ үлкен сандардан басталуы мүмкін болғандықтан, **Нөлден бастау** неғұрлым интуитивті визуализация опциясы ретінде берілген.
:::

## Бірнеше журналды синхрондау {#multi-log-synchronization}

[Бірнеше журнал файлы бір уақытта ашылғанда](/overview/log-files/#opening-logs), AdvantageScope олардың уақыт белгілерін синхрондайды және туралайды. **Нөлден бастау** режимінде нөлдік нүкте жүктелген барлық файлдар бойынша ең ерте уақыт белгісіне орнатылады. **Бастапқы** режимінде уақыт белгілері бірінші ашылған журналдың уақыт базасы арқылы көрсетіледі, ал кез келген қосымша журналдар оған туралану үшін жылжытылады.

## Баптау {#customization}

Уақыт белгісін көрсету режимін өзгерту үшін `Қолданба` > `Баптауларды көрсету...` (Windows/Linux) немесе `AdvantageScope` > `Баптаулар...` (macOS) басу немесе `Ctrl+,` / `Cmd+,` пернелерін басу арқылы баптаулар терезесін ашыңыз. **Уақыт белгілері** параметрін қажетті опцияға жаңартыңыз.
