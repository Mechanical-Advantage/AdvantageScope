# ⏱️ Уақыт белгілері {#timestamps}

AdvantageScope барлық көріністе — соның ішінде хронологияда, 📉 [Сызықтық графикте](/tab-reference/line-graph), 🔢 [Кестеде](/tab-reference/table) және 💬 [Консольде](/tab-reference/console) — уақыт белгілерін көрсетудің реттелетін параметрлерін қолдайды.

## Көрсету режимдері {#display-modes}

Уақыт белгілерін көрсету режимін баптаулар терезесінде баптауға болады:

- **Нөлден бастау (Әдепкі):** Журналдағы ең ерте деректер нөлден (`+0,0 с`) басталуы үшін барлық уақыт белгісін ығыстырады. Бұл режимде деректер басталғаннан бергі өткен уақытты білдіру үшін уақыт белгілерінің алдына `+` таңбасы қойылады.
- **Бастапқы:** Робот коды пайдаланатын нақты мәндерге сәйкес, уақыт белгілерін журнал файлында жазылған бастапқы сандық мәндері күйінде көрсетеді.

:::info
WPILib 2027 нұсқасынан бастап уақыт белгілері Systemcore жүйесінде және симуляцияда құрылғы іске қосылғаннан (boot) бергі уақыт бойынша өлшенеді. Бастапқы уақыт белгілері кездейсоқ үлкен сандардан басталуы мүмкін болғандықтан, **Нөлден бастау** режимі неғұрлым түсінікті көрсету тәсілі ретінде ұсынылған.
:::

## Бірнеше журналды синхрондау {#multi-log-synchronization}

[Бірнеше журнал файлы бір уақытта ашылғанда](/overview/log-files/#opening-logs), AdvantageScope олардың уақыт белгілерін өзара синхрондайды және сәйкестендіреді. **Нөлден бастау** режимінде нөлдік нүкте жүктелген барлық файл арасындағы ең ерте уақыт белгісіне қойылады. **Бастапқы** режимінде уақыт белгілері бірінші ашылған журналдың уақыт базасы бойынша көрсетіледі, ал қосымша журналдар соған сәйкестендіріліп ығыстырылады.

## Баптау {#customization}

Уақыт белгілерін көрсету режимін өзгерту үшін `Қолданба` > `Параметрлерді көрсету...` (Windows/Linux) немесе `AdvantageScope` > `Параметрлер...` (macOS) тармағын басып, не `Ctrl+,` / `Cmd+,` пернелер тіркесімін қолданып, баптаулар терезесін ашыңыз. Содан кейін **Уақыт белгілері** параметрін қажетті мәнге ауыстырыңыз.
