# 👋 Сәлем, телеметрия!

AdvantageScope қолданбасына қош келдіңіз! Телеметрия мен деректерді журналдау — робот кодын түсіну, ақауларды анықтау және алаңда да, одан тыс жерде де шешімдерді іске асыру қабілетіңізді жақсартатын қуатты мүмкіндіктер. Бұл оқулықтар AdvantageScope мүмкіндіктерін толық пайдалану үшін телеметриямен жұмысты бастауға көмектесуге арналған.

Бұл оқулықта сіз мыналарды үйренесіз:

- Java WPILib жобасында негізгі робот телеметриясын баптауды.
- AdvantageScope қолданбасында тікелей деректер ағындарына қосылуды.
- Кейінірек қарау үшін деректерді журнал файлдарына жазуды.
- AdvantageScope көмегімен телеметрия деректерін визуализациялауды.

:::tip Басқа нәрсе іздеп жүрсіз бе?

- **FTC командалары:** Қолданыстағы FIRST Tech Challenge басқару жүйесін пайдалансаңыз, ✴️ [FTC үйлесімділігі](/more-features/ftc-compatibility) нұсқаулығын қараңыз.
- **Веб-интерфейс:** AdvantageScope қолданбасының браузерлік нұсқасы тікелей FIRST Driver Station және Systemcore веб-интерфейсінде қолжетімді. Толығырақ 💡 [AdvantageScope Lite](/more-features/advantagescope-lite) бетінен қараңыз.
- **AdvantageKit:** Симуляцияда детерминистік қайта ойнатуға арналған кеңейтілген журналдау фреймворгы. Толығырақ [құжаттамадан](https://docs.advantagekit.org) қараңыз. Төменде сипатталған WPILib кірістірілген телеметрия API-інен бастауды ұсынамыз.
  :::

## 1. Жаңа WPILib жобасын жасаңыз

Бастау үшін VS Code бағдарламасында жаңа WPILib Java жобасын жасаңыз:

1. VS Code бағдарламасын ашыңыз.
2. Жоғарғы оң жақтағы WPILib белгішесін басыңыз (немесе `Ctrl+Shift+P` / `Cmd+Shift+P` пернелерін басып, **WPILib: Create a new project** деп теріңіз).
3. **Template** > **Java** > **Command v3 Robot** (немесе **Command v2 Robot**) тармағын таңдаңыз.
4. Қалтаны таңдап, жобаңызға атау беріңіз (мысалы, `HelloTelemetry`) және команда нөміріңізді енгізіңіз.
5. **Enable Desktop Support** құсбелгісін қойып, **Create Project** батырмасын басыңыз.

<img src="/img/tutorials/hello-telemetry-1.webp" alt="VS Code бағдарламасында WPILib Project Creator арқылы жаңа WPILib Java жобасын жасау." />

_Жоғарыда ағылшын тіліндегі интерфейс көрсетілген._

## 2. Деректерді журналдауды инициализациялаңыз

WPILib `DataLogManager` арқылы кірістірілген деректерді журналдауды ұсынады. Іске қосылған кезде ол барлық телеметрияны, NetworkTables жазбаларын және Driver Station кірістерін автоматты түрде `.wpilog` файлдарына жазады.

:::info Ұсыныс
Журналдарды Systemcore ішкі жадына сақтауға болатынына қарамастан, ішкі флеш-жад шектеулі. Systemcore USB порттарының біріне стандартты **FAT32 пішіміндегі USB флеш-дискісін** қосуды қатаң ұсынамыз. `DataLogManager` дискіні анықтап, барлық журналдарды автоматты түрде тікелей USB дискіге жазады.
:::

`src/main/java/first/robot/Robot.java` файлын ашып, `Robot()` конструкторы ішінде `DataLogManager` инициализациялаңыз:

```java
public class Robot extends OpModeRobot {
  // ...

  public Robot() {
    // Барлық телеметрияны USB дискісіндегі .wpilog файлына жазу үшін DataLogManager іске қосыңыз
    DataLogManager.start();

    // Driver Station деректерін де жазыңыз (джойстиктер, OpMode, қосылу күйі)
    DriverStation.startDataLog(DataLogManager.getLog());
  }

  // ...
}
```

## 3. Телеметрия деректерін жариялаңыз

WPILib `Telemetry` класы өрістерді иерархиялық кестелерге реттей отырып, бір жол кодпен деректерді жариялауға мүмкіндік береді. Бұл API сандық мәндерді, булевтік мәндерді, жолдарды, массивтерді және WPILib [геометрия түрлерін](https://docs.wpilib.org/en/stable/docs/software/advanced-controls/geometry/index.html) қоса алғанда, деректер түрлерінің кең ауқымын қолдайды.

:::info
WPILib жүйесіндегі `Telemetry` класы FTC SDK ішіндегі `Telemetry` класынан өзгеше. WPILib `Telemetry` класы робот бағдарламасынан бақылау тақталарына, жөндеу құралдарына немесе журнал файлдарына ақпарат жібереді. Кірістірілген Driver Station экранын жаңарту үшін WPILib `DriverStationDisplay` класын пайдаланыңыз.
:::

`src/main/java/first/robot/ExampleTeleop.java` файлын жаңартыңыз:

```java
@Teleop
public class ExampleTeleop implements OpMode {
  // ...

  @Override
  public void periodic() {
    double currentTime = Timer.getTimestamp();
    double sineWave = Math.sin(currentTime * 2.0);

    // Telemetry API көмегімен телеметрия мәндерін жариялаңыз
    Telemetry.log("Time", currentTime);
    Telemetry.log("SineWave/Value", sineWave);
    Telemetry.log("SineWave/Low", sineWave < 0.5);
  }
}
```

Кодты роботқа жүктеңіз (немесе VS Code ішінен `WPILib: Simulate Robot Code` іске қосыңыз). Симуляцияда `Teleoperated` > `ExampleTeleop` > `Enable` басыңыз.

<img src="/img/tutorials/hello-telemetry-2.webp" alt="Симулятор интерфейсінде ExampleTeleop OpMode режимін қосу." height="200" />

_Жоғарыда ағылшын тіліндегі интерфейс көрсетілген._

:::tip
Жаңа телеметрия деректері тек `Telemetry.log` шақырылғанда ғана жарияланады. `Robot` класындағы, OpMode режимдеріндегі, ішкі жүйелердегі және механизмдердегі мерзімді әдістер әртүрлі жағдайларда белсенді болуы мүмкін; журналдау шақыруларын қайда орналастыру керектігін таңдағанда API құжаттамасын мұқият тексеріңіз.
:::

## 4. AdvantageScope-ты тікелей қосыңыз

AdvantageScope жұмыс үстелі қолданбасын іске қосыңыз. Жоғарғы мәзірден `Файл` > `Роботқа қосылу` > `NetworkTables` тармағын таңдаңыз (немесе симуляция жасап жатсаңыз, `Файл` > `Симуляторға қосылу`). Қосылғаннан кейін сол жақ бүйірлік тақта `NT:/Telemetry` астында жарияланған өрістермен толтырылады.

:::tip Пернетақта тіркесімдері
Роботқа жылдам қосылу үшін `Ctrl+K` / `Cmd+K` пернелерін, ал симуляторға қосылу үшін `Ctrl+Shift+K` / `Cmd+Shift+K` пернелерін басыңыз.
:::

<img src="/img/tutorials/hello-telemetry-3.webp" alt="Бүйірлік тақта ағашында тізімделген өрістермен тікелей робот ағынына қосылған AdvantageScope." />

_Жоғарыда ағылшын тіліндегі интерфейс көрсетілген._

## 5. Телеметрия деректерін визуализациялаңыз

### Сызықтық график

📉 [Сызықтық график](/tab-reference/line-graph) — AdvantageScope қолданбасындағы әдепкі қойынды және сандық әрі дискретті мәндердің нақты уақыттағы графигін салуды қамтамасыз етеді.

1. Сол жақ бүйірлік тақтада `Telemetry` > `SineWave` астына қараңыз.
2. `Value` өрісін басқару тақтасындағы «Сол жақ ось» аймағына сүйреп апарыңыз.
3. `Low` өрісін басқару тақтасындағы «Дискретті өрістер» аймағына сүйреп апарыңыз.
4. «Дискретті өрістер» жанындағы үш нүктені басып, «Робот режимін көрсету» тармағын таңдаңыз.

Деректер түскен сайын синусоида мен робот күйінің нақты уақытта жаңартылғанын көресіз!

:::info Графикпен өзара әрекеттесу

- **Кідірту / Жылжыту:** Өткен деректерді көру үшін көлденеңінен айналдырыңыз немесе график бойымен басып сүйреңіз. Жоғарғы оң жақтағы қызыл көрсеткі тікелей автоайналдырудың кідіртілгенін білдіреді. Тікелей автоайналдыруды ауыстыру үшін көрсеткіні басыңыз немесе `L` пернесін басыңыз.
- **Масштабтау:** График үстінде жоғары/төмен айналдырыңыз немесе белгілі бір уақыт терезесін үлкейту үшін `Shift` пернесін басып тұрып сүйреңіз.
- **Мәндерді тексеру:** Уақыт курсорын қою және шартты белгіде нақты мәндерді көру үшін графиктің кез келген жерін басыңыз.
  :::

<img src="/img/tutorials/hello-telemetry-4.webp" alt="Синусоида сигналын сызатын сызықтық график." />

_Жоғарыда ағылшын тіліндегі интерфейс көрсетілген._

### Кесте

🔢 [Кесте](/tab-reference/table) қойындысы күй мен мән өзгерістерінің хронологиялық кестесін көрсетеді, бұл ауысулар мен оқиғалар тізбегін диагностикалауға өте ыңғайлы.

1. Жоғарғы қойындылар жолағындағы **+** батырмасын басып, **Кесте** таңдаңыз.
2. Бүйірлік тақтадан `NT:/Telemetry/SineWave/Value` және `NT:/Telemetry/Low` өрістерін кесте көрінісіне сүйреп апарыңыз.
3. Көрсетілген кез келген өрістің мәні өзгерген сайын жаңа жол автоматты түрде қосылады.
4. Барлық ашық қойындыларды сол нақты уақыт мезетіне бірден ауыстыру үшін кез келген жолды басыңыз!

:::tip
Қойындыларды қойынды жолағы арқылы қайта реттеуге және атауын өзгертуге болады. Қойындыны бөлек қалқымалы терезеде ашу және бірнеше қойындыны қатар көру үшін тақырып жолағындағы терезе батырмасын басыңыз.
:::

### Статистика

📊 [Статистика](/tab-reference/statistics) қойындысы сандық мәндердің гистограммасын көрсетіп, бір немесе бірнеше өріс деректеріне егжей-тегжейлі шолу жасайды.

1. Жоғарғы қойындылар жолағындағы **+** батырмасын басып, **Статистика** таңдаңыз.
2. Бүйірлік тақтадан `NT:/Telemetry/SineWave/Value` өрісін «Өлшемдер» бөліміне сүйреп апарыңыз.
3. «Деректер ауқымы» мәнін `-1` және `1`, ал «Қадам өлшемі» мәнін `0,1` етіп орнатыңыз.
4. Гистограмма мен жиынтық статистиканы пайдаланып деректерді қараңыз.
5. Қамтылатын деректер ауқымын реттеу үшін жоғарғы жақтағы хронологияны айналдырыңыз.

## 6. Журнал файлдарын жүктеп алыңыз және ашыңыз

Сынақтан немесе матчтан кейін деректерді кейінірек қарау үшін роботтан `.wpilog` файлдарын жүктеп алуға болады:

1. Мәзір жолағында `Файл` > `Журналдарды жүктеп алу...` тармағын таңдаңыз.
2. AdvantageScope роботқа қосылып, барлық жазылған журнал файлдарын көрсетеді (ең жаңалары жоғарғы жағында).
3. Тексергіңіз келетін журнал файл(дар)ын таңдап, жүктеп алу (↓) белгішесін басыңыз және компьютеріңізден қалтаны таңдаңыз.
4. Жүктеп алынған файлды `Файл` > `Журнал(дар)ды ашу...` арқылы немесе `.wpilog` файлын тікелей AdvantageScope ішіне сүйреп апару арқылы ашыңыз.

<img src="/img/overview/log-files/open-file-2.webp" alt="Робот жадындағы қолжетімді WPILOG файлдарын көрсететін жүктеп алу терезесі." height="350" />

_Жоғарыда ағылшын тіліндегі интерфейс көрсетілген._

## Әрі қарай не істеу керек?

Енді негізгі телеметрия мен журналдау жұмыс істеп тұрғандықтан, визуализацияны келесі деңгейге көтеріңіз:

- **🤖 [Алаңға: роботты визуализациялау](/tutorials/to-the-field):** FRC және FTC алаң үлгілерінде 2D/3D робот позицияларын, траекторияларды және механизмдерді визуализациялауды үйреніңіз.
- **[Шолу](/category/overview):** Файлдарды басқару, шарлау тіркесімдері және тікелей трансляция параметрлері туралы толық нұсқаулық.
- **[Өлшем бірліктерін қолдау](/tab-reference/line-graph/units):** Дәлірек визуализациялау үшін журналдарыңызға өлшем бірлігі метадеректерін қалай қосуға болады.
- **💬 [Консоль](/tab-reference/console):** WPILib `DataLogManager` сақтаған мәтіндік журналдарды визуализациялаңыз.
- **🔍 [Метадеректер](/tab-reference/metadata):** Журнал файлдарын анықтау және санаттау үшін қосымша ақпаратты сақтаңыз.
- **[Epilogue](https://docs.wpilib.org/en/stable/docs/software/telemetry/robot-telemetry-with-annotations.html):** Аннотацияларды пайдаланып Java тілінде телеметрияны тіркеңіз.
