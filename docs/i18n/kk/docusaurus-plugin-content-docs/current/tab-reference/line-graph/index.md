## Қарау тақтасы {#viewer-pane}

Масштабтау үшін меңзерді негізгі графиктің үстіне қойып, жоғары немесе төмен айналдырыңыз. `Shift` пернесін басып тұрып басу және сүйреу арқылы ауқымды да таңдауға болады. Көлденең айналдыру арқылы (қолдау көрсетілетін құрылғыларда) немесе график бойынша басып сүйреу арқылы солға және оңға жылжытыңыз. Тікелей қосылған кезде, солға айналдыру ағымдағы уақыттан құлыпты ашады, ал оңға қарай соңына дейін айналдыру қайтадан ағымдағы уақытқа құлыптайды.

Графикті басу уақытты таңдайды, ал оң жақпен басу оны таңдаудан бас тартады. Осы уақыттағы әрбір өрістің мәні аңызда көрсетіледі. Таңдалған уақыт барлық қойындыларда синхрондалады, бұл басқа көріністерде осы орынды жылдам табуды жеңілдетеді.

:::tip
Таңдалған және меңзер апарылған уақыттар арасындағы дельта график үстінде көрсетіледі, бұл уақыт ауқымдарын өлшеуді жеңілдетеді. Уақыт белгілері [Уақыт белгілері](/more-features/timestamps) баптауына сәйкес пішімделеді.
:::

## Басқару тақтасы {#control-pane}

Жұмысты бастау үшін өрісті үш бөлімнің біріне сүйреңіз (сол жақ, оң жақ немесе дискретті). Өрісті X түймесін пайдаланып жойыңыз немесе көз белгішесін басу не өріс атауын екі рет басу арқылы уақытша жасырыңыз. Барлық өрістерді жою үшін ось тақырыбының жанындағы үш нүктені басып, содан кейін `Барлығын тазарту` тармағын таңдаңыз. Өрістерді басып сүйреу арқылы тізімде қайта орналастыруға болады.

Әрбір өрістің түсі мен сызық стилін түсті белгішені басу немесе өріс атауын оң жақпен басып баптауға болады. WPILib кітапханасының [тұрақты ескертулер](https://docs.wpilib.org/en/latest/docs/software/telemetry/persistent-alerts.html) API деректерін ескертулер тобын дискретті өріс ретінде қосу арқылы визуализациялауға болады. Мысал визуализациясы төменде көрсетілген.

### Осьтерді реттеу {#adjusting-axes}

Әдепкі бойынша, әрбір ось өзінің ауқымын көрінетін деректерге негізделіп реттейді. Автоматты ауқымдауды өшіру және ауқымды ағымдағы мин және макс мәндеріне құлыптау үшін ось тақырыбының жанындағы үш нүктені басып, содан кейін `Осьті құлыптау` тармағын таңдаңыз. Ауқымды қолмен реттеу үшін `Диапазонды өңдеу` тармағын таңдап, қажетті мәндерді енгізіңіз.

### Интегралдау және дифференциалдау {#integration-and-differentiation}

Мәндер AdvantageScope арқылы автоматты түрде интегралдануы немесе дифференциалдануы мүмкін. Уақыт дельтасы әрқашан секундпен өлшенеді. Ось тақырыбының жанындағы үш нүктені басып, содан кейін `Дифференциалдау` немесе `Интегралдау` таңдаңыз.

:::info
Туындылар көршілес іріктемелердің [соңғы айырымын](https://en.wikipedia.org/wiki/Finite_difference) пайдалану арқылы есептеледі. Интегралдар [трапециялар интегралдауын](https://en.wikipedia.org/wiki/Trapezoidal_rule) пайдаланып есептеледі.
:::
