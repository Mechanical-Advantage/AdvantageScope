## Қарау тақтасы {#viewer-pane}

Масштабтау үшін меңзерді негізгі графиктің үстіне апарып, жоғары немесе төмен айналдырыңыз. Сондай-ақ `Shift` пернесін басып тұрып шертіп сүйреу арқылы ауқымды таңдауға болады. Солға және оңға жылжу үшін көлденең айналдырыңыз (қолдау көрсетілетін құрылғыларда) немесе графикті басып сүйреңіз. Тікелей режимде қосылған кезде, солға айналдыру ағымдағы уақытқа бекітуді ажыратады, ал оңға қарай соңына дейін айналдыру ағымдағы уақытқа қайта бекітеді.

Графикті шертсеңіз уақыт таңдалады, ал тінтуірдің оң жақ батырмасын бассаңыз таңдау алынып тасталады. Сол мезеттегі әрбір өрістің мәні шартты белгілерде көрсетіледі. Таңдалған уақыт барлық қойындыларда синхрондалады, сондықтан басқа көріністерден де сол сәтті оңай табуға болады.

:::tip
Таңдалған уақыт пен меңзер апарылған уақыт арасындағы айырма (дельта) графиктің үстінде көрсетіледі, бұл уақыт аралықтарын өлшеуді жеңілдетеді. Уақыт белгілері [Уақыт белгілері](/more-features/timestamps) баптауына сәйкес пішімделеді.
:::

## Басқару тақтасы {#control-pane}

Жұмысты бастау үшін өрісті үш бөлімнің біріне (сол жақ, оң жақ немесе дискретті) сүйреп апарыңыз. Өрісті X батырмасы арқылы жойыңыз, ал уақытша жасыру үшін көз белгішесін шертіңіз немесе өріс атауын екі рет басыңыз. Барлық өрісті жою үшін ось тақырыбының жанындағы үш нүктені басып, `Барлығын тазарту` тармағын таңдаңыз. Тізімдегі өрістердің ретін басып сүйреу арқылы өзгертуге болады.

Әрбір өрістің түсі мен сызық стилін түсті белгішені басу немесе өріс атауын тінтуірдің оң жақ батырмасымен шерту арқылы баптауға болады. WPILib кітапханасының [тұрақты ескертулер](https://docs.wpilib.org/en/latest/docs/software/telemetry/persistent-alerts.html) API деректерін ескертулер тобын дискретті өріс ретінде қосу арқылы визуализациялауға болады. Мысал төменде көрсетілген.

### Осьтерді реттеу {#adjusting-axes}

Әдепкі бойынша әрбір ось өз ауқымын көрінетін деректерге қарай автоматты түрде реттейді. Автоматты ауқымдауды өшіріп, ауқымды ағымдағы ең төменгі және ең жоғарғы мәндерге бекіту үшін ось тақырыбының жанындағы үш нүктені басып, `Осьті бекіту` тармағын таңдаңыз. Ауқымды қолмен реттеу үшін `Диапазонды өңдеу` тармағын таңдап, қажетті мәндерді енгізіңіз.

### Интегралдау және дифференциалдау {#integration-and-differentiation}

AdvantageScope мәндерді автоматты түрде интегралдай немесе дифференциалдай алады. Уақыт айырмасы әрқашан секундпен өлшенеді. Ось тақырыбының жанындағы үш нүктені басып, `Дифференциалдау` немесе `Интегралдау` тармағын таңдаңыз.

:::info
Туындылар көршілес өлшем нүктелерінің [ақырлы айырымын](https://en.wikipedia.org/wiki/Finite_difference) есептеу арқылы табылады. Интегралдар [трапеция әдісімен](https://en.wikipedia.org/wiki/Trapezoidal_rule) есептеледі.
:::
