# 🦀 Swerve {#swerve}

Swerve қойындысы төрт swerve модулінің күйін, соның ішінде жылдамдық векторларын, бастапқы (бос жүріс) күйлерін, роботтың бұрылуын және шасси жылдамдықтарын көрсетеді.

<img src="/img/tab-reference/swerve-1.webp" alt="Swerve қойындысының шолуы" />

_Жоғарыда ағылшын тіліндегі интерфейс көрсетілген._

<details>
<summary>Хронологияны басқару элементтері</summary>

Хронология ойнату мен визуализацияны басқару үшін қолданылады. Хронологияны шертсеңіз уақыт таңдалады, ал тінтуірдің оң жақ батырмасын бассаңыз таңдау алынып тасталады. Таңдалған уақыт барлық қойындыларда синхрондалады, сондықтан басқа көріністерден де сол сәтті оңай табуға болады.

Сары бөліктер роботтың автономды режимін, көк бөліктер телеоперация режимін, ал сұр бөліктер утилита режимін білдіреді.

Масштабтау үшін меңзерді хронологияның үстіне апарып, жоғары немесе төмен айналдырыңыз. Сондай-ақ `Shift` пернесін басып тұрып шертіп сүйреу арқылы ауқымды таңдауға болады. Солға және оңға жылжу үшін көлденең айналдырыңыз (қолдау көрсетілетін құрылғыларда) немесе хронологияны басып сүйреңіз. Тікелей режимде қосылған кезде, солға айналдыру ағымдағы уақытқа бекітуді ажыратады, ал оңға қарай соңына дейін айналдыру ағымдағы уақытқа қайта бекітеді. Робот қосылып тұрған кезеңге масштабтау үшін `Ctrl+\` пернелер тіркесімін басыңыз.

## Дереккөздерді қосу {#adding-sources}

Жұмысты бастау үшін өрісті «Дереккөздер» бөліміне сүйреп апарыңыз. X түймесі арқылы дереккөзді жойыңыз, ал уақытша жасыру үшін көз белгішесін шертіңіз немесе өріс атауын екі рет басыңыз. Барлық дереккөзді жою үшін ось тақырыбының жанындағы қоқыс жәшігі белгішесін басып, `Барлығын тазарту` тармағын таңдаңыз. Тізімдегі дереккөздердің ретін басып сүйреу арқылы өзгертуге болады.

**Әрбір дереккөзді баптау үшін түсті белгішені шертіңіз немесе өріс атауын тінтуірдің оң жақ батырмасымен басыңыз.** AdvantageScope дереккөздің үш түрін қолдайды:

- **Модуль жылдамдықтары:** Диаграммада векторлар ретінде көрсетілетін төрт swerve модулі күйлерінің жиынтығы.
- **Робот жылдамдықтары:** Диаграмманың ортасында көрсетілетін сызықтық және бұрыштық жылдамдықтар.
- **Айналу:** Диаграмманы бұру үшін қолданылатын бұрыштық күй.

## Деректер пішімі {#data-format}

Деректер `SwerveModuleVelocity[]`, `ChassisVelocities`, `Rotation2d` немесе `Rotation3d` түрлерінде байтпен кодталған struct немесе protobuf пішімінде жариялануы тиіс.

Көптеген кітапханалар, соның ішінде WPILib және AdvantageKit struct пішімін қолдайды. Төмендегі мысал кодында Java тілінде swerve модулінің күйлерін қалай журналдау керектігі көрсетілген.

<Tabs groupId="library">
<TabItem value="wpilib" label="WPILib" default>

```java
SwerveModuleVelocity[] states = new SwerveModuleVelocity[] {
  new SwerveModuleVelocity(),
  new SwerveModuleVelocity(),
  new SwerveModuleVelocity(),
  new SwerveModuleVelocity()
};

Telemetry.log("MyStates", states);
```

</TabItem>
<TabItem value="advantagekit" label="AdvantageKit">

:::note
2027 жылы бұл деректер құрылымының атауы `SwerveModuleState` түрінен `SwerveModuleVelocity` болып өзгертілді.
WPILib 2027 және Systemcore нұсқаларына дейін жасалған журнал файлдарындағы ескі `SwerveModuleState` түрлері визуализацияда әлі де қолдау табады.
:::

## Конфигурация {#configuration}

Келесі конфигурация параметрлері қолжетімді:

- **Максималды жылдамдық:** Модульдердің қол жеткізе алатын ең жоғарғы жылдамдығы; векторлардың өлшемін реттеу үшін қолданылады.
- **Жақтау өлшемі:** Сол-оң және алдыңғы-артқы swerve модульдері арасындағы қашықтықтар. Робот диаграммасының тараптар арақатынасын өзгертеді.
- **Бағдары:** Робот диаграммасы бағытталған бұрышты реттейді. Бұл параметр поза деректерімен үйлестіру немесе матч бейнелеріне сәйкестендіру үшін жиі қолданылады.
