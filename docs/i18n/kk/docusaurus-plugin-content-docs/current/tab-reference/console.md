# 💬 Консоль {#console}

Консоль көрінісі консоль деректері бар жалғыз жолдық өрісті қарауға арналған. Кейбір ұсынылатын өрістер төменде келтірілген.

- **DS:/Dscomm/Console** - FIRST Driver Station сақтаған.
- **messages** - [`DataLogManager.log`](<https://github.wpilib.org/allwpilib/docs/release/java/edu/wpi/first/wpilibj/DataLogManager.html#log(java.lang.String)>) әдісіне шақырулар негізінде WPILib кірістірілген журналындауы сақтаған.
- **/RealOutputs/Console** - Робот жұмысы кезінде AdvantageKit автоматты түрде сақтаған (әдеттегідей `System.out.println` пайдаланыңыз).
- **/ReplayOutputs/Console** - Журналды қайталау кезінде AdvantageKit автоматты түрде сақтаған (әдеттегідей `System.out.println` пайдаланыңыз).

Жұмысты бастау үшін қажетті өрісті негізгі көрініске сүйреңіз. Әрбір жол өрістің жаңартылуын білдіреді. WPILib журналдары үшін сақталған әрбір жол үшін жаңа жол жасалады. AdvantageKit журналдары үшін әрбір цикл үшін жаңа жол жасалады.

<img src="/img/tab-reference/console-1.png" alt="Консоль көрінісі" />

:::info
Ескерту мен қате хабарларын бөлектеуді қосу/өшіру үшін түстер палитрасы белгішесін басыңыз. WPILib және AdvantageKit журналдары үшін, егер хабарларда «warning» немесе «error» мәтіні болса, олар бөлектеледі.
:::

Басқару элементтері 🔢 [Кесте](../tab-reference/table) қойындысына ұқсас. Таңдалған уақыт барлық қойындыларда синхрондалады. Жолды таңдау үшін оны басыңыз немесе оны кез келген көрінетін қалқымалы терезеде алдын ала қарау үшін меңзерді жолдың үстіне апарыңыз. ↓ түймесін басу таңдалған уақытқа (немесе ұяшыққа енгізілген уақытқа) өтеді.

Тек сүзгі мәтіні бар жолдарды көрсету үшін «Сүзгі» енгізу өрісіне мәтінді енгізіңіз. «Сүзгі» енгізу өрісін жылдам таңдау үшін `Ctrl+F` басыңыз. Сәйкес келетін хабарларды негізгі көріністен _қоспау_ үшін сүзгі мәтінінің басына «!» қосыңыз.

:::tip
Консоль деректерін мәтіндік файлға экспорттау үшін сақтау белгішесін басыңыз.
:::
