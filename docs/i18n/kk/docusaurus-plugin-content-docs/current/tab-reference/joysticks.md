# 🎮 Джойстиктер {#joysticks}

Джойстиктер қойындысы алтыға дейін қосылған контроллердің күйін көрсетеді. Төмендегі суретте екі Xbox контроллері мен бір әмбебап джойстик орналасуының мысалы көрсетілген. Әрбір түйме басылғанда бөлектеледі, сондай-ақ джойстиктер мен басқа осьтердің күйі көрсетіледі.

_Жоғарыда ағылшын тіліндегі интерфейс көрсетілген._

<details>
<summary>Хронологияны басқару элементтері</summary>

Хронология ойнату мен визуализацияны басқаруға арналған. Хронологияны шертсеңіз, уақыт таңдалады, ал тінтуірдің оң жақ батырмасын бассаңыз, таңдау алынып тасталады. Таңдалған уақыт барлық қойындыларда синхрондалады, сондықтан бұл сәтті басқа көріністерден жылдам табу оңай.

Сары бөліктер роботтың автономды режимде, көк бөліктер телеоперация режимінде, ал сұр бөліктер утилита режимінде болған уақытын көрсетеді.

Масштабтау үшін меңзерді хронологияның үстіне апарып, тінтуір дөңгелегін жоғары немесе төмен айналдырыңыз. Сондай-ақ `Shift` пернесін басып тұрып, шертіп сүйреу арқылы уақыт ауқымын таңдауға болады. Солға және оңға жылжу үшін көлденең айналдырыңыз (қолдау көрсетілетін құрылғыларда) немесе хронологияны басып сүйреңіз. Тікелей қосылым кезінде солға қарай айналдыру ағымдағы уақытқа бекітуді ашады, ал оңға қарай соңына дейін айналдыру қайтадан ағымдағы уақытқа бекітеді. Робот қосулы болған кезеңді масштабтау үшін `Ctrl+\` пернелер тіркесімін басыңыз.

## Басқару тақтасы {#control-pane}

Қойындының төменгі жағындағы кестеден джойстик түрлерін таңдаңыз. Джойстик идентификаторлары 0-ден 5-ке дейінгі аралықта болады және Driver Station мен WPILib жүйесіндегі идентификаторларға сәйкес келеді. Джойстиктер туралы толығырақ [WPILib құжаттамасынан](https://docs.wpilib.org/en/stable/docs/software/basic-programming/joystick.html) оқи аласыз.

AdvantageScope құрамында жиі қолданылатын джойстиктер жиынтығы бар, соның ішінде барлық түймелері, осьтері және POV қосқыштары тор түрінде орналасқан «Әмбебап джойстик» (жоғарыда көрсетілген). Арнайы джойстикті қосу үшін [Пайдаланушы активтері](/more-features/custom-assets) бетін қараңыз.

:::warning
**Джойстик деректері стандартты WPILib қолданатын NetworkTables қосылымы арқылы қолжетімді ЕМЕС.** Оның орнына WPILib журнал файлдарына ([джойстикті журналдау қосылған](https://docs.wpilib.org/en/stable/docs/software/telemetry/datalog.html#logging-joystick-data)), AdvantageKit журналдарына және AdvantageKit трансляциясына қолдау көрсетіледі.
:::
