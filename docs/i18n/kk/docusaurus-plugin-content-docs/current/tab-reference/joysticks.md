# 🎮 Джойстиктер {#joysticks}

Джойстиктер қойындысы алтыға дейінгі қосылған контроллердің күйін көрсетеді. Төмендегі суретте екі Xbox контроллері және негізгі джойстигі бар мысал орналасуы көрсетілген. Әрбір түйме басылғанда бөлектеледі және джойстиктер мен басқа осьтердің күйлері көрсетіледі.

<summary>Хронологияны басқару элементтері</summary>

Хронология ойнату мен визуализацияны басқару үшін пайдаланылады. Хронологияны басу уақытты таңдайды, ал оң жақпен басу оны таңдаудан бас тартады. Таңдалған уақыт барлық қойындыларда синхрондалады, бұл басқа көріністерде осы орынды жылдам табуды жеңілдетеді.

Сары бөлімдер роботтың автономды режимін, көк бөлімдер телеоперация режимін, ал сұр бөлімдер утилита режимін көрсетеді.

Масштабтау үшін меңзерді хронологияның үстіне қойып, жоғары немесе төмен айналдырыңыз. `Shift` пернесін басып тұрып басу және сүйреу арқылы ауқымды да таңдауға болады. Көлденең айналдыру арқылы (қолдау көрсетілетін құрылғыларда) немесе хронологияны басып сүйреу арқылы солға және оңға жылжытыңыз. Тікелей қосылған кезде, солға айналдыру ағымдағы уақыттан құлыпты ашады, ал оңға қарай соңына дейін айналдыру қайтадан ағымдағы уақытқа құлыптайды. Робот қосылған кезеңге масштабтау үшін `Ctrl+\` басыңыз.

## Басқару тақтасы {#control-pane}

Қойындының төменгі жағындағы кестеде джойстик түрлерін таңдаңыз. Джойстик ID нөмірлері 0-ден 5-ке дейінгі аралықта болады және Driver Station мен WPILib кітапханасындағы ID нөмірлеріне сәйкес келеді. Джойстиктер туралы қосымша ақпаратты [WPILib құжаттамасынан](https://docs.wpilib.org/en/stable/docs/software/basic-programming/joystick.html) табуға болады.

AdvantageScope стандартты джойстиктер жиынтығын қамтиды, соның ішінде тор форматындағы барлық түймелері, осьтері және POV қосқыштары бар «Негізгі джойстик» (жоғарыда көрсетілген). Таңдамалы джойстикті қосу үшін [Таңдамалы активтер](/more-features/custom-assets) бөлімін қараңыз.

:::warning
**Джойстик деректері стандартты WPILib бар NetworkTables қосылымы арқылы қолжетімді ЕМЕС.** WPILib журнал файлдары ([джойстикті журналындау қосылған](https://docs.wpilib.org/en/stable/docs/software/telemetry/datalog.html#logging-joystick-data)), AdvantageKit журналдары және AdvantageKit трансляциясы қолдау тапқан.
:::
