# 🔢 Кесте {#table}

Кесте көрінісі өрістер жиынтығы үшін нақты мән өзгерістерін егжей-тегжейлі көрсетуге арналған. Өрісті қосу үшін оны негізгі көрініске сүйреңіз. Өрісті жою үшін оның атауының жанындағы «X» түймесін басыңыз. Өрістерді басып сүйреу арқылы қайта орналастыруға болады.

<img src="/img/tab-reference/table-1.webp" alt="Шолу" />

**Көрсетілген өрістердің кез келгеніндегі әрбір өзгеріс үшін жаңа жол жасалады.** Қайталанатын жолдар көрсетілмейді. Мысалы, матч кезіндегі робот күйін көрсететін кесте мынадай болады:

<img src="/img/tab-reference/table-2.webp" alt="Робот күйінің кестесі" />

Кестеде таңдалған уақыт барлық қойындылар бойынша синхрондалады. Жолды таңдау үшін оны басыңыз немесе кез келген көрінетін қалқымалы терезеде алдын ала қарау үшін меңзерді жолдың үстіне апарыңыз. ↓ түймесін басу таңдалған уақытқа (немесе өріске енгізілген уақытқа) өтеді.
