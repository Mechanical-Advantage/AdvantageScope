# 🔢 Кесте {#table}

Кесте көрінісі таңдалған өрістердегі нақты мән өзгерістерін егжей-тегжейлі көрсетуге арналған. Өрісті қосу үшін оны негізгі көрініске сүйреп апарыңыз. Өрісті жою үшін оның атауының жанындағы «X» түймесін басыңыз. Өрістердің ретін басып сүйреу арқылы өзгертуге болады.

<img src="/img/tab-reference/table-1.webp" alt="Шолу" />

_Жоғарыда ағылшын тіліндегі интерфейс көрсетілген._

**Көрсетілген өрістердің кез келгенінде мән өзгерген сайын жаңа жол қосылады.** Қайталанатын жолдар көрсетілмейді. Мысалы, матч кезіндегі робот күйін көрсететін кесте мынадай болады:

<img src="/img/tab-reference/table-2.webp" alt="Робот күйінің кестесі" />

Кестеде таңдалған уақыт барлық қойындыларда синхрондалады. Жолды таңдау үшін оны шертіңіз немесе ашық тұрған қалқымалы терезелерде алдын ала қарау үшін меңзерді жолдың үстіне апарыңыз. ↓ түймесін бассаңыз, таңдалған уақытқа (немесе өріске енгізілген уақытқа) өтеді. Уақыт белгілері мен өту өрісіне енгізілетін мәндер [Уақыт белгілері](/more-features/timestamps) баптауына сәйкес пішімделеді.
