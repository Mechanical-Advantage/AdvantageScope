# 🎬 Бейне

Бейне қойындысы журнал деректерін бөлек жазылған матч бейнесімен қатар салыстыруға мүмкіндік береді. Төмендегі қадамдар бейнені қалай жүктеуді және оны журналмен қалай синхрондауды көрсетеді.

## Бейнені жүктеу

AdvantageScope бейнені жүктеу үшін үш опцияны ұсынады:

1. **Жергілікті файл:** Сұр файл белгішесін басыңыз, содан кейін жүктеу үшін бейне файлын таңдаңыз. Көптеген кең таралған бейне пішімдеріне қолдау көрсетіледі.
2. **YouTube:** YouTube сілтемесін алмасу буферіне көшіріңіз, содан кейін қызыл алмасу буфері белгішесін басыңыз. Бірнеше секундтан кейін бейне жүктеле бастайды.
3. **The Blue Alliance:** Журнал файлы негізінде матч бейнесін автоматты түрде жүктеу үшін көк TBA белгішесін басыңыз. Егер бірнеше бейне қолжетімді болса, қалқымалы мәзірден жүктейтін бейнені таңдаңыз. Бұл мүмкіндік TBA үшін API кілтін талап етеді, оны [thebluealliance.com/account](https://www.thebluealliance.com/account) сайтынан алып, AdvantageScope қалаулар бетіндегі «TBA API кілті» бөліміне көшіру керек.

<img src="/img/tab-reference/video-1.png" alt="Source chooser" />

Бейнені таңдағаннан кейін, төменгі оң жақтағы хронология кэштелген кадрларды көрсету үшін көк түске айнала бастайды (бұл қадам біркелкі ойнату үшін қажет). Бұл мүмкіндік кадрды түрлендіру талап етілетіндіктен, тек матч ұзақтығындағы бейнелерге арналған.

:::warning
YouTube және TBA бейнелерін жүктеп алу YouTube серверлеріндегі өзгерістерге байланысты күтпеген жерден сәтсіз аяқталуы мүмкін. Мәселе туындаған жағдайда, AdvantageScope жаңартып көріңіз немесе оның орнына жергілікті бейне файлын пайдаланыңыз.
:::

:::info
AdvantageScope бейне файлдарын өңдеу үшін [FFmpeg](https://ffmpeg.org) құралын қажет етеді. Егер жүйеңіздің PATH жолында FFmpeg жарамды көшірмесі табылмаса, AdvantageScope бірінші рет бейнені жүктеген кезде интернеттен FFmpeg жүктеп алуды ұсынады. Автоматты FFmpeg орнату тек Windows және macOS жүйелерінде қолдау тапқан; Linux пайдаланушылары FFmpeg құралын қолмен орнатып, оны жүйелік PATH жолына қосуы қажет болуы мүмкін.
:::

## Бейне бойынша навигация

Бейне бастапқыда жүктелгенде және журнал деректерімен әлі синхрондалмаған кезде, бейне мен журналды ойнатуды басқару элементтері әлі де тәуелсіз болады. Бейнені ойнатуды басқару үшін төменгі оң жақтағы хронология мен түймелерді пайдаланыңыз. Келесі пернетақта жарлықтары да қолдау табады:

- / = ойнатуды ауыстыру
- → = бір кадрға алға жылжу
- ← = бір кадрға артқа жылжу
- \> = бес секундқа алға өткізу
- < = бес секундқа артқа өткізу

## Автоматты синхрондау

Матчтың көптеген бейнелері матчтың автономды кезеңінің кадрлары жүктелгеннен кейін көп ұзамай журналмен автоматты түрде синхрондалады. Ешқандай әрекет талап етілмейді; егер синхрондау сәтті аяқталса, бейнені басқару элементтері автоматты түрде құлыпталады (төмендегі «Ойнату» бөлімін қараңыз).

:::warning
Автоматты синхрондау тек ұпайлар оверлейлері бар матч бейнелерінде жұмыс істейді және барлық жағдайда сәтті болмауы мүмкін. Барлық кадрлар жүктелгеннен кейін бейнені басқару элементтері автоматты түрде құлыпталмаса, қолмен синхрондау талап етіледі.
:::

## Қолмен синхрондау

Алдымен, бейнені басқару элементтерін пайдаланып, автономды кезеңнің басы сияқты матчтағы белгілі орынға өтіңіз. Содан кейін, журнал файлында бейненің ағымдағы кадрымен теңесетін уақытты таңдаңыз.

:::tip
Хронологиядағы меңзер матч кезеңдерінің басына және соңына бекітіледі, бұл матчтың басын дәл таңдауды жеңілдетеді.
:::

Бейне мен журнал теңестірілгеннен кейін, бейне хронологиясының жанындағы құлып белгішесін басыңыз (немесе **↑ немесе ↓** басыңыз). Бейнені басқару элементтері енді өшіріледі. Бейнені ойнату құлпын ашу үшін құлып белгішесін қайтадан басыңыз.

## Ойнату

Құлыпталғаннан кейін бейнені ойнату журналда таңдалған уақытпен теңесіп тұрады. Журналды синхрондауды қолдау үшін бастапқы бейне кадр бойынша ұсынысқа түрлендірілетіндіктен, дыбысты ойнатуға қолдау көрсетілмейтінін ескеріңіз.

<details>
<summary>Хронологияны басқару элементтері</summary>

Хронология ойнатуды және визуализацияны басқару үшін пайдаланылады. Хронологияны басу уақытты таңдайды, ал оң жақ түймені басу таңдауды болдырмайды. Таңдалған уақыт барлық қойындылар бойынша синхрондалады, бұл басқа көріністерде осы орынды жылдам табуды жеңілдетеді.

Сары бөлімдер роботтың автономды режимін, көк бөлімдер роботтың телеоперациялық режимін, ал сұр бөлімдер роботтың утилита режимін көрсетеді.

Масштабтау үшін меңзерді хронология үстіне қойып, жоғары немесе төмен айналдырыңыз. Диапазонды сонымен қатар `Shift` пернесін басып тұрып сүйреу арқылы таңдауға болады. Көлденең айналдыру (қолдау көрсетілетін құрылғыларда) немесе хронологияны басып сүйреу арқылы солға және оңға жылжытыңыз. Тікелей қосылған кезде, солға айналдыру ағымдағы уақыттан құлыпты ашады, ал оң жаққа дейін айналдыру қайтадан ағымдағы уақытқа құлыптайды. Робот қосылып тұрған кезеңге масштабтау үшін `Ctrl+\` басыңыз.
