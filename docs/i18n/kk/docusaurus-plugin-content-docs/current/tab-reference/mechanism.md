# ⚙️ Механизм

Механизм қойындысы бір немесе бірнеше [Mechanism2d](https://docs.wpilib.org/en/stable/docs/software/dashboards/glass/mech2d-widget.html) объектілері арқылы жасалған топсалы механизмді көрсетеді.

<img src="/img/tab-reference/mechanism-1.png" alt="Overview of mechanism tab" />

<details>
<summary>Хронологияны басқару элементтері</summary>

Хронология ойнатуды және визуализацияны басқару үшін пайдаланылады. Хронологияны басу уақытты таңдайды, ал оң жақ түймені басу таңдауды болдырмайды. Таңдалған уақыт барлық қойындылар бойынша синхрондалады, бұл басқа көріністерде осы орынды жылдам табуды жеңілдетеді.

Сары бөлімдер роботтың автономды режимін, көк бөлімдер роботтың телеоперациялық режимін, ал сұр бөлімдер роботтың утилита режимін көрсетеді.

Масштабтау үшін меңзерді хронология үстіне қойып, жоғары немесе төмен айналдырыңыз. Диапазонды сонымен қатар `Shift` пернесін басып тұрып сүйреу арқылы таңдауға болады. Көлденең айналдыру (қолдау көрсетілетін құрылғыларда) немесе хронологияны басып сүйреу арқылы солға және оңға жылжытыңыз. Тікелей қосылған кезде, солға айналдыру ағымдағы уақыттан құлыпты ашады, ал оң жаққа дейін айналдыру қайтадан ағымдағы уақытқа құлыптайды. Робот қосылып тұрған кезеңге масштабтау үшін `Ctrl+\` басыңыз.

## Механизмдерді қосу

Бастау үшін `Mechanism2d` объектісін басқару тақтасына сүйреңіз. X түймесін пайдаланып механизмді жойыңыз немесе көз белгішесін басу не өріс атауын екі рет басу арқылы оны уақытша жасырыңыз. Барлық механизмдерді жою үшін ось тақырыбының жанындағы қоқыс жәшігін басып, содан кейін «Барлығын тазарту» түймесін басыңыз. Механизмдерді тізімде басып сүйреу арқылы қайта орналастыруға болады.

## Деректерді жариялау

<Tabs groupId="library">
<TabItem value="wpilib" label="WPILib" default>

WPILib арқылы механизм деректерін жариялау үшін NetworkTables жүйесіне `Mechanism2d` объектісін жіберіңіз (төменде көрсетілген). Егер деректерді журналдау қосылған болса, механизмдерді жасалған WPILOG файлы негізінде де қарауға болады.

```java
Mechanism2d mechanism = new Mechanism2d(3, 3);
SmartDashboard.putData("MyMechanism", mechanism);
```

</TabItem>
<TabItem value="advantagekit" label="AdvantageKit">

AdvantageKit арқылы механизм деректерін жариялау үшін `Mechanism2d` объектісін шығыс өрісі ретінде жазып алыңыз (төменде көрсетілген). Бұл шақыру `Mechanism2d` ағымдағы күйін тек жазып алатынын ескеріңіз, сондықтан оны объект жаңартылғаннан кейін әрбір цикл сайын шақыру керек.

```java
LoggedMechanism2d mechanism = new LoggedMechanism2d(3, 3);
Logger.recordOutput("MyMechanism", mechanism);
```

</TabItem>
