# 🗺 2D алаңы {#2d-field}

2D алаңы қойындысы алаң картасының үстінде роботтың 2D визуализациясын көрсетеді. Сонымен қатар ол камера арқылы нысанаға алу күйі мен анықтамалық позалар сияқты қосымша деректерді де көрсете алады.

_Жоғарыда ағылшын тіліндегі интерфейс көрсетілген._

<details>
<summary>Хронологияны басқару элементтері</summary>

Хронология ойнату мен визуализацияны басқаруға арналған. Хронологияны шертсеңіз, уақыт таңдалады, ал тінтуірдің оң жақ батырмасын бассаңыз, таңдау алынып тасталады. Таңдалған уақыт барлық қойындыларда синхрондалады, сондықтан бұл сәтті басқа көріністерден жылдам табу оңай.

Сары бөліктер роботтың автономды режимде, көк бөліктер телеоперация режимінде, ал сұр бөліктер утилита режимінде болған уақытын көрсетеді.

Масштабтау үшін меңзерді хронологияның үстіне апарып, тінтуір дөңгелегін жоғары немесе төмен айналдырыңыз. Сондай-ақ `Shift` пернесін басып тұрып, шертіп сүйреу арқылы уақыт ауқымын таңдауға болады. Солға және оңға жылжу үшін көлденең айналдырыңыз (қолдау көрсетілетін құрылғыларда) немесе хронологияны басып сүйреңіз. Тікелей қосылым кезінде солға қарай айналдыру ағымдағы уақытқа құлыптауды ашады, ал оңға қарай соңына дейін айналдыру қайтадан ағымдағы уақытқа құлыптайды. Робот қосулы болған кезеңді масштабтау үшін `Ctrl+\` пернелер тіркесімін басыңыз.

## Камераны басқару элементтері {#camera-controls}

Масштабты үлкейту немесе кішірейту үшін меңзерді алаңның үстіне қойып, жоғары не төмен айналдырыңыз. Алаң бойынша жылжу үшін басып сүйреңіз. Келесі опциялары бар камера мәзірін ашу үшін алаңның кез келген жерін тінтуірдің оң жақ батырмасымен басыңыз:

- **Құлпы ашылған**: Жылжу және масштабтау қолмен орындалады.
- **Роботқа құлыпталған**: Камера роботты бақылап отыру үшін автоматты түрде жылжиды.
- **Робот пен айналуға құлыпталған**: Камера роботты және оның бұрылуын бақылап отыру үшін автоматты түрде жылжиды әрі бұрылады.

Кез келген құлыпталған режимде камераны роботтан еркін жылжытып алуға болады. Ал басқару тақтасындағы бағдарлау түймелерін кез келген режимде камераны бұру үшін пайдалана аласыз.

## Нысандарды қосу {#adding-objects}

Жұмысты бастау үшін өрісті «Позалар» бөліміне сүйреп апарыңыз. Нысанды жою үшін «X» түймесін басыңыз, ал уақытша жасыру үшін көз белгішесін басыңыз немесе өріс атауын екі рет шертіңіз. Барлық нысандарды өшіру үшін ось тақырыбының жанындағы себет белгішесін басып, «Барлығын тазарту» пәрменін таңдаңыз. Тізімдегі нысандардың ретін басып сүйреу арқылы өзгертуге болады.

**Әрбір нысанды баптау үшін түсті белгішені басыңыз немесе өріс атауын тінтуірдің оң жақ батырмасымен шертіңіз.** AdvantageScope көптеген нысан түрлерін қолдайды және олардың басым бөлігін баптауға болады (мысалы, түсін өзгерту). Кейбір нысандар бұрыннан бар нысанға еншілес элемент ретінде қосылуы тиіс.

:::tip
Қолдау көрсетілетін нысан түрлерінің толық тізімін көру үшін `?` белгішесін басыңыз. Бұл тізімде қолдау көрсетілетін деректер түрлері және нысандарды еншілес элемент ретінде қосу қажет пе, жоқ па — соның бәрі көрсетілген.
:::

## Деректер пішімі {#data-format}

Геометрия деректері байтпен кодталған struct немесе protobuf пішімінде жариялануы керек. Әртүрлі 2D және 3D геометрия түрлеріне, соның ішінде `Pose2d`, `Pose3d`, `Translation2d`, `Translation3d` және т.б. түрлерге қолдау көрсетіледі.

Көптеген кітапханалар, соның ішінде WPILib және AdvantageKit, struct пішімін қолдайды. Төмендегі мысал коды Java тілінде 2D поза деректерін журналдауды көрсетеді.

<Tabs groupId="library">
<TabItem value="wpilib" label="WPILib" default>

```java
Pose2d poseA = new Pose2d();
Pose2d poseB = new Pose2d();

Telemetry.log("MyPose", poseA);
Telemetry.log("MyPoseArray", new Pose2d[] {poseA, poseB});
```

</TabItem>
<TabItem value="advantagekit" label="AdvantageKit">

Pose2d poseA = new Pose2d();
Pose2d poseB = new Pose2d();

Logger.recordOutput("MyPose", poseA);

Logger.recordOutput("MyPoseArray", new Pose2d[] {poseA, poseB});

```java
// Бұл хаттама заманауи struct пішімін қолдамайды, бірақ поза

// өрістер арқылы жариялауға болады (төменде көрсетілгендей):

// Басқа телеметрия мәндерін осында қосыңыз...

FtcDashboard.getInstance().sendTelemetryPacket(packet)

// Балама ретінде, MultipleTelemetry және стандартты SDK телеметриясын пайдаланыңыз:
// OpMode Init кезінде:

telemetry.addData("Pose y", 2.8); // Дюйм
telemetry.addData("Pose heading", 3.14); // Радиан

// немесе...
telemetry.addData("Pose heading (deg)", 180.0); // Градус

// Басқа телеметрия мәндерін осында қосыңыз...
telemetry.update();
```

## Конфигурация {#configuration}

- **Алаң:** Пайдаланылатын алаң кескіні. Соңғы FRC және FTC ойындарының барлығына қолдау көрсетіледі. Таңдамалы алаң кескінін қосу үшін [Таңдамалы активтер](/more-features/custom-assets) бетін қараңыз.
- **Бағдар:** Қарау тақтасындағы алаң кескінінің бағдары.
- **Өлшемі:** Робот жағының ұзындығы (FRC үшін 30/27/24 дюйм, FTC үшін 18/16/14 дюйм).

:::info
Бұл қойындыда пайдаланылатын координаттар жүйесін баптауға болады. Толық мәліметтерді [координаттар жүйесі](/more-features/coordinate-systems) бетінен қараңыз.
:::
