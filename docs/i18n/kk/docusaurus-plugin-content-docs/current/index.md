#

<img src="/img/banner-ltr.webp" alt="AdvantageScope" />

AdvantageScope — бұл [6328 командасы](https://littletonrobotics.org) әзірлеген FIRST командаларына арналған робот диагностикасы, журналдарды қарау/талдау және деректерді визуализациялау қолданбасы. Ол WPILOG, DS log, Hoot (CTRE), REVLOG (REV Robotics), Road Runner, CSV және RLOG файл пішімдеріндегі журналдарды оқиды, сондай-ақ NT4, Phoenix, RLOG немесе FTC Dashboard трансляциясы арқылы нақты уақыттағы робот деректерін қарауды қолдайды. AdvantageScope кез келген WPILib жобасымен пайдаланылуы мүмкін, сонымен қатар біздің [AdvantageKit](https://docs.advantagekit.org) журналды қайта ойнату фреймворгімен пайдалану үшін оңтайландырылған. Ескерту: **AdvantageScope қолданбасын пайдалану үшін AdvantageKit қажет емес**.

AdvantageScope келесі құралдарды қамтиды:

- Икемді графиктер мен диаграммалардың кең таңдауы
- Бапталатын CAD негізіндегі роботтары бар поза деректерінің 2D және 3D алаң визуализациясы
- Бөлек жүктелген матч бейнесінен синхрондалған бейне ойнату
- Бапталатын контроллер визуализацияларында жүргізуші әрекеттерін көрсететін джойстик визуализациясы
- Swerve drive модулінің векторлық дисплейлері
- Консоль хабарламаларын қарау
- Журнал статистикасын талдау
- CSV және WPILOG қолдауы бар икемді экспорттау опциялары
