# Қолдау

AdvantageScope немесе AdvantageScope XR бойынша қолдау алу үшін төмендегі байланыс әдістерінің бірін пайдаланыңыз.

- Мүмкіндік сұраулары мен қате туралы хабарламалар үшін GitHub сайтында [мәселе ашыңыз](https://github.com/Mechanical-Advantage/AdvantageScope/issues).
- Барлық басқа сұраулар бойынша software@team6328.org мекенжайына хабарласыңыз.
