# 🔢 Tabla {#table}

La vista de tabla está pensada para mostrarte con detalle cada cambio de valor en un conjunto de campos. Para agregar un campo, arrástralo a la vista principal; para quitarlo, haz clic en el botón "X" junto a su nombre. También puedes reordenar los campos arrastrándolos.

<img src="/img/tab-reference/table-1.webp" alt="Descripción general" />

_En la imagen de arriba se muestra la interfaz en inglés._

**Cada vez que cambia alguno de los campos mostrados, se crea una nueva fila.** No se muestran filas repetidas. Por ejemplo, una tabla con el estado del robot durante un partido se vería así:

<img src="/img/tab-reference/table-2.webp" alt="Tabla de estado del robot" />

El tiempo seleccionado en la tabla se sincroniza en todas las pestañas. Haz clic en una fila para seleccionarla, o pasa el cursor sobre ella para previsualizar ese instante en cualquier ventana flotante visible. Al hacer clic en el botón ↓, la tabla salta al tiempo seleccionado (o al tiempo que escribiste en el recuadro). Tanto las marcas de tiempo como el campo para saltar a un instante usan el formato configurado en la preferencia [Marcas de tiempo](/more-features/timestamps).
