# Soporte {#support}

Para recibir soporte con AdvantageScope o AdvantageScope XR, usa cualquiera de estos medios de contacto:

- Para pedir nuevas funciones o reportar errores, [abre un issue](https://github.com/Mechanical-Advantage/AdvantageScope/issues) en GitHub.
- Para cualquier otra consulta, escribe a software@team6328.org.
