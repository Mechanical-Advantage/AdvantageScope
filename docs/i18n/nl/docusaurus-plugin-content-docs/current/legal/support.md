# Ondersteuning {#support}

Voor ondersteuning bij AdvantageScope of AdvantageScope XR kun je een van de onderstaande contactmethoden gebruiken.

- Voor functieverzoeken en foutmeldingen kun je [een issue openen](https://github.com/Mechanical-Advantage/AdvantageScope/issues) op GitHub.
- Neem voor alle overige vragen contact op via software@team6328.org.
