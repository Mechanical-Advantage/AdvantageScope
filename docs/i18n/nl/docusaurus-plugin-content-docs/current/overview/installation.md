# 📦 Installatie {#installation}

De officieel ondersteunde versie van AdvantageScope haal je rechtstreeks bij Team 6328 of via het WPILib-installatieprogramma. Daarnaast bestaan er een aantal onofficiële distributies.

## Team 6328 {#team-6328}

### Downloads: [Stabiel](https://github.com/Mechanical-Advantage/AdvantageScope/releases/latest), [Prerelease](https://github.com/Mechanical-Advantage/AdvantageScope/releases) {#6328-downloads}

Als je AdvantageScope rechtstreeks bij Team 6328 downloadt, profiteer je van:

- De nieuwste functies en bugfixes, nog voordat ze via andere kanalen beschikbaar zijn.
- Een melding in de app zodra er een nieuwe versie klaarstaat om te downloaden.
- Een ingebouwde verzameling recente robotmodellen van Team 6328 voor het tabblad 👀 [3D-veld](/tab-reference/3d-field).

:::info
Elke hoofdversie van AdvantageScope komt in januari uit, nog vóór de FRC-kickoff, met het jaartal als versienummer (v26.0.0 verscheen bijvoorbeeld in januari 2026). In de maanden daarvoor zijn er soms al bèta- en alfaversies beschikbaar voor teams die nieuwe functies willen uitproberen en feedback willen geven. **Gebruik je zo'n prerelease, houd er dan rekening mee dat je problemen en bugs kunt tegenkomen die niet in stabiele releases zitten.**
:::

## WPILib {#wpilib}

### Installatie: [WPILib-documentatie](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/wpilib-setup.html) {#wpilib-installation}

In het WPILib-installatieprogramma zit een recente release van AdvantageScope, al kan die iets achterlopen op de nieuwste versie die je direct kunt downloaden. Hoe je AdvantageScope start vanuit de WPILib-versie van VS Code lees je [hier](https://docs.wpilib.org/en/stable/docs/software/dashboards/advantagescope.html).

## Onofficiële distributies {#unofficial-distributions}

Via verschillende andere bronnen zijn ook onofficiële versies van AdvantageScope te vinden. Die worden niet officieel ondersteund door de ontwikkelaars van AdvantageScope of WPILib en kunnen achterlopen op de officiële releases. Loop je ergens tegenaan, neem dan rechtstreeks contact op met de beheerders.

- [**AdvantageScope Lite voor REV Control System:**](https://github.com/j5155/AdvantageScope-Lite-FTC) Een aanpassing van [AdvantageScope Lite](/more-features/advantagescope-lite) voor het bestaande (pre-Systemcore) FTC-besturingssysteem.
- [**Homebrew-installatieprogramma:**](https://formulae.brew.sh/cask/advantagescope) Een Homebrew-cask om AdvantageScope op macOS via de opdrachtregel te installeren.
- [**Arch User Repository:**](https://aur.archlinux.org/packages/advantagescope) Een alternatieve installatiemethode voor de pakketbeheerder pacman (een officiële Arch-distributie van AdvantageScope vind je [hier](#6328-downloads)).
