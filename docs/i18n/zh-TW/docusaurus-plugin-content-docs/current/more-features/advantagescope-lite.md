# 💡 AdvantageScope Lite {#advantagescope-lite}

AdvantageScope Lite 是 AdvantageScope 的網頁版，可從 FIRST Driver Station 與 Systemcore 網頁介面存取。AdvantageScope 桌面應用程式的大多數基本功能都包含在 AdvantageScope Lite 中。但是，由於相容性限制，省略了一些功能（包括某些分頁類型、日誌格式與相關功能）。

## 安裝與資源 {#installation-and-assets}

用於 Systemcore 的 AdvantageScope Lite 可以透過從 GitHub releases 頁面下載 AdvantageScope 的「Systemcore」版本來進行安裝與更新。在 Systemcore 網頁介面上選擇「Add Package」卡片，將套件上傳到機器人。

資源檔案（例如場地/機器人模型）可以透過選擇 `檔案` > `上傳資源` 來上傳。選取的檔案可以是單個資源的 zip 檔案，也可以是包含多個資源 zip 檔案的 zip 檔案。有關資源格式的更多資訊，請參閱[自訂資源](/more-features/custom-assets/)頁面。

:::info
包含常用資源集合的 Zip 檔案可以透過點擊下方連結進行下載：

- [**預設 FRC 資源**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFRC.zip)：FRC 場地、FRC 範例機器人與所有搖桿佈局。
- [**預設 FTC 資源**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFTC.zip)：FTC 場地、FTC 範例機器人與所有搖桿佈局。
- [**FRC 6328 資源**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsFRC6328.zip)：AdvantageScope [6328 團隊發行版](/overview/installation#team-6328)獨有的資源。

:::

:::tip
在 FIRST Driver Station 中使用 AdvantageScope Lite 無需進行任何安裝。導覽至 http://localhost:6768/ascope 以進行即時連線或檢視日誌檔案。
:::
