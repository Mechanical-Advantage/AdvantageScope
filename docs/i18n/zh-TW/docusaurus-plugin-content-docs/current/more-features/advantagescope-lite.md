# 💡 AdvantageScope Lite {#advantagescope-lite}

AdvantageScope Lite 是 AdvantageScope 的網頁版，可直接從 FIRST Driver Station 和 Systemcore 網頁介面開啟。它保留了桌面版大部分的基本功能，不過受限於相容性，部分功能並未提供（包含特定分頁類型、日誌格式與相關功能）。

## 安裝與資源 {#installation-and-assets}

若要在 Systemcore 上安裝或更新 AdvantageScope Lite，請先從 GitHub releases 頁面下載「Systemcore」版本的 AdvantageScope，接著在 Systemcore 網頁介面中選擇「Add Package」卡片，將套件上傳到機器人。

若要上傳資源檔案（例如場地或機器人模型），請選擇 `檔案` > `上傳資源`。你可以選擇單一資源的 zip 檔案，或是包含多個資源 zip 檔案的壓縮檔。更多資源格式說明，請參閱[自訂資源](/more-features/custom-assets/)頁面。

:::info
你可以點擊下方連結，下載包含常用資源的 zip 檔案：

- [**預設 FRC 資源**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFRC.zip)：FRC 場地、FRC 範例機器人與所有搖桿佈局。
- [**預設 FTC 資源**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsDefaultFTC.zip)：FTC 場地、FTC 範例機器人與所有搖桿佈局。
- [**FRC 6328 資源**](https://github.com/Mechanical-Advantage/AdvantageScopeAssets/releases/download/bundles-v1/AllAssetsFRC6328.zip)：AdvantageScope [Team 6328 發行版](/overview/installation#team-6328)專屬的資源。

:::

:::tip
在 FIRST Driver Station 中使用 AdvantageScope Lite 不需要另外安裝。只要前往 http://localhost:6768/ascope，就能進行即時連線或檢視日誌檔案。你也可以直接將外部駕駛站日誌檔案拖放到視窗中開啟。
:::
