# 鍵盤快捷鍵

AdvantageScope 包含多個鍵盤快捷鍵，可實現更快的導覽。在 macOS 上，使用 `ctrl` 鍵的快捷鍵被 ⌘ 鍵取代。

### 資料來源

<table>
<tr><td>`Ctrl+O`</td><td>開啟一個或多個日誌檔案</td></tr>
<tr><td>`Ctrl+Shift+O`</td><td>新增一個或多個日誌檔案到目前視覺化中</td></tr>
<tr><td>`Ctrl+K`</td><td>連線到機器人作為即時來源</td></tr>
<tr><td>`Ctrl+Shift+K`</td><td>連線到模擬器作為即時來源</td></tr>
<tr><td>`Ctrl+Option+Shift+K`</td><td>連線到駕駛站作為即時來源</td></tr>
<tr><td>`Ctrl+D`</td><td>從機器人下載日誌檔案</td></tr>
</table>

### 資料匯出

<table>
<tr><td>`Ctrl+E`</td><td>匯出日誌資料</td></tr>
<tr><td>`Ctrl+P`</td><td>將日誌資料發布到機器人上的 NetworkTables 伺服器</td></tr>
<tr><td>`Ctrl+Shift+P`</td><td>將日誌資料發布到模擬中的 NetworkTables 伺服器</td></tr>
<tr><td>`Option+Ctrl+P`</td><td>停止發布到 NetworkTables</td></tr>
</table>

### 視窗控制

<table>
<tr><td>`Ctrl+N`</td><td>建立新視窗</td></tr>
<tr><td>`Ctrl+Shift+N`</td><td>關閉目前視窗</td></tr>
<tr><td>`Ctrl+Comma`</td><td>開啟偏好設定視窗</td></tr>
<tr><td>`Ctrl+Period`</td><td>切換側邊欄可見度</td></tr>
<tr><td>`Ctrl+Slash`</td><td>切換控制面板可見度</td></tr>
</table>

### 分頁控制

<table>
<tr><td>`Ctrl+T`</td><td>開啟下拉式選單以新增分頁</td></tr>
<tr><td>`Ctrl+Shift+T`</td><td>為目前分頁建立新彈出視窗</td></tr>
<tr><td>`Ctrl+Left` 與 `Ctrl+Right`</td><td>切換分頁</td></tr>
<tr><td>`Ctrl+[` 與 `Ctrl+]`</td><td>重新排列分頁</td></tr>
<tr><td>`Ctrl+W`</td><td>關閉目前分頁</td></tr>
</table>

### 播放

<table>
<tr><td>`Space`</td><td>切換播放</td></tr>
<tr><td>`Left` 與 `Right`</td><td>單步瀏覽日誌檔案</td></tr>
<tr><td>`L` 或 `Ctrl+L`</td><td>檢視即時資料時切換鎖定</td></tr>
<tr><td>`Ctrl+\`</td><td>縮放時間軸至已啟用範圍</td></tr>
</table>
