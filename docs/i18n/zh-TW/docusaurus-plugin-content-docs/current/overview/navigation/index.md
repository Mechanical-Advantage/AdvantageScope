# 🧭 應用程式導覽 {#app-navigation}

下圖顯示了 AdvantageScope 主視窗的主要元素。實際外觀會依作業系統而有所不同。

<img src="/img/overview/navigation/navigation-1.webp" alt="導覽圖解" />

_上圖所示為英文介面。_

- 紅色區域是[側邊欄](#sidebar)，列出可用的欄位。
- 棕色區域是[分頁列](#tab-bar)，用來控制應用程式並切換不同檢視。
- 藍色區域是[檢視器面板](#viewer-pane)，用來顯示資料。
- 綠色區域是[控制面板](#control-pane)，用來調整視覺化設定。

:::tip
若要同時檢視多個日誌檔案，請點擊 `檔案` > `新視窗`。
:::

## 側邊欄 {#sidebar}

左側是列出可用表格與欄位的側邊欄。可選取的欄位會以*斜體*顯示，內建表格（來自 WPILib 或 AdvantageKit）則帶有<u>底線</u>。點擊箭頭可展開巢狀表格。你可以**拖曳單一欄位**來選取它，或**按住 Cmd/Ctrl** 依序點擊多個欄位來選取一組欄位，接著開始拖曳這組欄位即可完成選取。

若要搜尋欄位，只要在搜尋框中開始輸入文字，系統就會顯示欄位的下拉式選單；選取後，該欄位會在側邊欄中醒目提示並自動捲動至可見範圍。

:::info
點擊並拖曳右側邊緣可調整側邊欄大小或將其隱藏；雙擊則可切換顯示／隱藏。
:::

## 分頁列 {#tab-bar}

使用分頁列（藍色）在不同檢視之間切換。點擊左側的 📖 圖示即可隨時開啟這份文件。若要匯出目前的分頁佈局（及相關設定），請點擊 `檔案` > `匯出佈局...`；若要從檔案匯入佈局，請點擊 `檔案` > `匯入佈局...`。

:::info
你可以點擊並拖曳來重新排列分頁，或在分頁上按右鍵並選擇 `重新命名...`。
:::

頂端的導覽按鈕（綠色）用於管理分頁與控制播放：

- **加號按鈕**：開啟下拉式選單以建立新分頁。
- **視窗按鈕：** 為目前分頁建立獨立的彈出視窗，方便同時檢視多個分頁的資料。
- **X 按鈕：** 關閉目前分頁。
- **播放按鈕：** 開始與停止即時播放。_按右鍵可變更播放速度或啟用循環播放。_

## 檢視器面板 {#viewer-pane}

檢視器面板會根據每個分頁的類型呈現資料。各分頁檢視器面板的詳細說明，請參閱分頁參考文件。點擊分頁列上的彈出按鈕，即可將此檢視移至獨立視窗。

## 控制面板 {#control-pane}

控制面板用來選取要視覺化的欄位並管理其他選項。各分頁可用選項的詳細說明，請參閱分頁參考文件。

:::info
點擊並拖曳頂部邊緣可調整控制面板大小或將其隱藏；雙擊則可切換顯示／隱藏。
:::
