# 🧭 應用程式導覽

下方螢幕截圖顯示了 AdvantageScope 主視窗的重要元素。在不同作業系統之間的確切外觀會有所不同。

<img src="/img/overview/navigation/navigation-1.png" alt="導覽圖解" />

:::tip
要同時檢視多個日誌檔案，請點擊 `檔案` > `新視窗`。
:::

## 側邊欄

左側是包含可用表格與欄位清單的側邊欄。可選擇的欄位以*斜體*顯示，內建表格（來自 WPILib 或 AdvantageKit）有<u>底線</u>。點擊箭頭可展開巢狀表格。**拖曳單一欄位**以選擇它，或**按住 Cmd/Ctrl** 並點擊每個欄位以選擇欄位集合。開始拖曳欄位集合即可完成選擇。

要搜尋欄位，請在搜尋方塊中開始輸入。將顯示欄位的下拉式選單，然後選取的欄位將在側邊欄中高亮顯示並滾動到視圖中。

:::info
點擊並拖曳右側邊緣可調整大小或隱藏側邊欄。按雙擊可切換側邊欄的可見度。
:::

## 分頁列

使用分頁列（藍色）在不同視圖之間切換。點擊左側的 📖 圖示隨時可以使用此文件。要匯出目前分頁佈局（及相關設定），請點擊 `檔案` > `匯出佈局...`。要從檔案匯入佈局，請點擊 `檔案` > `匯入佈局...`。

:::info
可以透過點擊並拖曳來重新排列分頁，或透過按右鍵並選擇 `重新命名...` 來重新命名分頁。
:::

頂部的導覽按鈕（綠色）用於管理分頁與控制播放。

- **加號按鈕**：開啟下拉式選單以建立新分頁。
- **視窗按鈕：** 建立包含該分頁的新彈出視窗。此功能可用於同時檢視來自多個分頁的資料。
- **X 按鈕：** 關閉目前分頁。
- **播放按鈕：** 開始與停止實時播放。_按右鍵可變更播放速度或啟用循環播放。_

## 檢視器面板

檢視器面板是為每個分頁類型呈現資料的地方。請查看分頁參考文件，瞭解每個分頁的檢視器面板詳細資訊。透過點擊分頁列中的彈出按鈕，可以將此視圖移動到獨立視窗。

## 控制面板

控制面板用於選擇欄位以進行視覺化並管理其他選項。請查看分頁參考文件，瞭解每個分頁可用的選項詳細資訊。

:::info
點擊並拖曳頂部邊緣可調整大小或隱藏控制面板。按雙擊可切換控制面板的可見度。
:::
