# 📊 統計資料 {#statistics}

統計資料分頁提供數值欄位的進階統計分析，著重於整體分佈趨勢而非隨時間的變化，並透過直方圖與多種標準統計指標來分析所選欄位。

_上圖所示為英文介面。_

## 控制面板 {#control-pane}

將欄位拖曳到「測量值」區段即可開始使用。點擊 X 按鈕可移除欄位，點擊眼睛圖示或雙擊欄位名稱則可暫時隱藏。若要移除所有欄位，請點擊標題旁的垃圾桶圖示，再選擇 `全部清除`。在清單中拖曳欄位即可重新排序。

若要分析欄位之間的差異，請將其中一個欄位切換為「參考」模式，並將其他欄位加入為子項目；子項目可在「相對誤差」與「絕對誤差」模式之間切換。

:::info
點擊彩色圖示或在欄位名稱上按右鍵，即可自訂各欄位的顏色。
:::

### 設定 {#configuration}

**時間範圍**選項決定要分析日誌的哪個區段：

- _可見範圍：_ 分析目前時間軸上顯示的時間範圍。
- _完整日誌：_ 分析整個日誌檔案的完整時間範圍。
- _已啟用：_ 僅分析機器人處於啟用狀態的時間範圍。
- _自動階段：_ 僅分析機器人處於自動階段的時間範圍。
- _遙控階段：_ 僅分析機器人處於遙控階段的時間範圍。
- _即時：30 秒：_ 分析最近 30 秒的資料（需連線至即時來源）。
- _即時：10 秒：_ 分析最近 10 秒的資料（需連線至即時來源）。

**資料範圍**選項可設定直方圖顯示的最小值與最大值。超出此範圍的資料不會繪製在直方圖上，但仍會納入統計指標的計算。

**組距**選項可設定直方圖每個分箱 (bin) 的寬度。較小的數值能呈現更細緻的圖表，但也會顯示較多雜訊。

## 檢視器面板 {#viewer-pane}

### 直方圖 {#histogram}

直方圖會顯示落在指定範圍內各個組距的取樣數量。請注意，超出指定範圍的資料會直接略過（不會另外歸類到單獨的分箱中）。

### 統計測量值 {#statistical-measures}

統計測量值表格會列出所選欄位的各項計算結果，各指標說明如下：

#### 摘要 {#summary}

- **計數：** 產生的離散取樣數量。
- **最小值：** 資料中的最小值。
- **最大值：** 資料中的最大值。

#### 中心 {#center}

- [**平均數：** ](https://zh.wikipedia.org/zh-tw/%E7%AE%97%E8%A1%93%E5%B9%B3%E5%9D%87%E6%95%B8)資料的算術平均數（即一般平均值）。
- [**中位數：** ](https://zh.wikipedia.org/zh-tw/%E4%B8%AD%E4%BD%8D%E6%95%B8)資料的「中間」值，也就是第 50 百分位數。
- [**眾數：** ](<https://zh.wikipedia.org/zh-tw/%E7%9C%BE%E6%95%B8_(%E6%95%B8%E5%AD%B8)>)資料中最常出現的數值。
- [**幾何平均：** ](https://zh.wikipedia.org/zh-tw/%E5%B9%BE%E4%BD%95%E5%B9%B3%E5%9D%87%E6%95%B8)以所有數值的乘積而非總和計算的集中趨勢指標，適合用於測量*指數成長率*（例如各週期之間的百分比變化）。
- [**調和平均：** ](https://zh.wikipedia.org/zh-tw/%E8%AA%BF%E5%92%8C%E5%B9%B3%E5%9D%87%E6%95%B8)以所有數值倒數的總和計算的集中趨勢指標，適合用於測量*速率或速度*。
- [**平方平均 (RMS)：** ](https://zh.wikipedia.org/zh-tw/%E5%9D%87%E6%96%B9%E6%A0%B9)以所有數值的平方計算的集中趨勢指標，適合用於測量同時包含*正值與負值*的資料（例如週期性運動）。

#### 分佈 {#spread}

- [**標準差：** ](https://zh.wikipedia.org/zh-tw/%E6%A8%99%E6%BA%96%E5%81%8F%E5%B7%AE)最常見的變異程度統計指標，數值越低代表資料越集中。在常態分佈的資料中，約 68% 的資料會落在平均數的正負一個標準差範圍內。
- [**絕對中位差 (MAD)：** ](https://zh.wikipedia.org/zh-tw/%E4%B8%AD%E4%BD%8D%E6%95%B8%E7%B5%95%E5%B0%8D%E5%81%8F%E5%B7%AE)各數值與中位數之間絕對偏差的中位數，相比標準差更能抵抗離群值的影響。
- [**四分位距：** ](https://zh.wikipedia.org/zh-tw/%E5%9B%9B%E5%88%86%E4%BD%8D%E8%B7%9D)第三四分位數與第一四分位數（第 75 與第 25 百分位數）之間的差值，受離群值的影響比標準差小。
- [**偏度：** ](https://zh.wikipedia.org/zh-tw/%E5%81%8F%E5%BA%A6)衡量資料分佈不對稱程度的指標。負值代表左偏（左側長尾），正值代表右偏（右側長尾），零則代表對稱分佈。

#### 百分位數 {#percentiles}

[百分位數](https://zh.wikipedia.org/zh-tw/%E7%99%BE%E5%88%86%E4%BD%8D%E6%95%B8)用來表示有多少比例的數值低於該數值。例如，10% 的資料會低於第 10 百分位數。以下百分位數也有常見的別稱：

- 第 25 百分位數 = 第一四分位數 (Q1)
- 第 50 百分位數 = 第二四分位數 (Q2) = 中位數
- 第 75 百分位數 = 第三四分位數 (Q3)
