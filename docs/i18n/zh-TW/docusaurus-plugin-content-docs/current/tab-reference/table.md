# 🔢 表格 {#table}

表格分頁可用於詳細檢視一組欄位的具體數值變化。將欄位拖曳至檢視器面板即可新增，點擊欄位名稱旁的「X」按鈕即可移除，拖曳欄位名稱則可重新排列順序。

<img src="/img/tab-reference/table-1.webp" alt="概述" />

_上圖所示為英文介面。_

**只要任何一個顯示的欄位發生變化，就會建立一列新資料**，不會重複顯示相同的列。例如，顯示比賽期間機器人狀態的表格如下：

<img src="/img/tab-reference/table-2.webp" alt="機器人狀態表格" />

表格中選取的時間會在所有分頁間同步。點擊某一列即可選取該時間點，將游標懸停在列上則可在其他可見的彈出視窗中預覽。點擊 ↓ 按鈕可跳至選取的時間（或輸入框中指定的時間）。時間戳記與跳轉輸入的格式會依據[時間戳記](/more-features/timestamps)偏好設定而定。
